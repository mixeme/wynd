## Где мы сейчас

Версия `0.10.x`, до 1.0. Продукт целиком работает на тестовом сервере: круги, журнал, дни, сетка, карта, поиск, приглашения, офлайн-очередь, пуши, квота и архив, панель администратора, оплата, бэкап и восстановление. Идёт проверка на телефонах и планшете и правка по ней.

## До публичного релиза

Кроме обычных ворот (`scripts/test.bat`, см. [DEVELOPMENT.md](DEVELOPMENT.md)), первый публичный релиз требует:

- [ ] **Повторного прохода аудита безопасности** по всему изменённому с 2026-09-27 — правила в [SECURITY.md](SECURITY.md).
- [ ] **Зеркала на GitHub.** Репозиторий по адресу `version.SourceURL` существует и совпадает с Gitea (`git ls-remote` обоих remote дают один `HEAD`), теги `vX.Y.Z` отправлены туда же, ссылка «исходный код» в клиенте открывается. Пока зеркала нет, адрес отвечает 404 — это ожидаемо (DEVELOPMENT.md, «Исходники: Gitea и GitHub»).
- [ ] **Сверки документов с кодом** — план [43](docs/plans/43-docs-drift.plan.md): где `stack.html` и `wynd.html` разошлись с кодом, решить, что правда, и поправить.

## Открытые вопросы

Решения ещё нет — сначала нужно понять, как продуктом пользуются.

- **Перенос круга на другой сервер.** Отложен сознательно; глобальные идентификаторы под него уже заложены.
- **Общие ярлыки групп кругов.** Сейчас группы и пины на улочке живут только на устройстве. Общие между устройствами — когда станет ясно, сколько кругов бывает у человека.
- **Удаление профиля и стирание имён.** Кто инициирует — сам участник или администратор по внешнему обращению; на весь инстанс или по кругам.
- **Зум карты** при точках, разбросанных от дачи до другой страны.

## Возможно позже — по реальному запросу

- **UnifiedPush** — если Web Push не хватит (Android без сервисов Google).
- **Нативная оболочка для фоновой загрузки видео** (Capacitor и WorkManager). PWA не умеет надёжно дожимать загрузку в фоне, но в WebView нет Push API — пуши пришлось бы переделывать. Не в 0.x.

## Не планируется

| Что | Почему |
|---|---|
| Сквозное шифрование | Убивает серверный поиск и превью, ключ не из чего вывести при входе по коду ([SECURITY.md](SECURITY.md)) |
| Федерация, ActivityPub | Серверы не знают друг о друге — это свойство продукта; круги собирает клиент |
| Нативные клиенты iOS и Android | Двойная разработка всех экранов; PWA достаточно |
| PostgreSQL | Домашний масштаб, один процесс — SQLite хватает |
| Перекодирование медиа на сервере | Нагрузка на дешёвый VPS; сжимает телефон |
| Шифрование секретов в базе | Ключ пришлось бы хранить рядом с базой |

Почему отвергнуто остальное — [docs/stack.html](docs/stack.html), «Отвергнутые альтернативы».
