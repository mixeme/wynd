## [0.10.7] — 2026-09-28

### Изменено

- Планшет: колонка приложения шире — до 720 пикселей вместо 480 на экранах от 600 пикселей, серые поля по бокам почти исчезли. Диалоги подтверждения остаются телефонной ширины.

### Исправлено

- Мёртвая ссылка приглашения (отозвана, истекла, использована, круг удалён): вместо формы входа с «Загрузка…» и ошибкой в самом низу — экран «Приглашение не действует» с причиной и кнопкой «На главную». Если сервер просто не ответил, об этом сказано отдельно.

## [0.10.6] — 2026-09-28

### Исправлено

- Подсказки, в которые попали заметки из макета и язык разработчика, переписаны для людей: тип приглашений в настройках круга («не какой чип предвыбран… 6.6»), право менять настройки у участника, упоминание в записи, поиск, «Позвать из других кругов», уведомления круга.
- Окно правок в настройках круга: вместо пяти строк — две. Сколько времени запись можно править и что новое правило касается только новых записей.

## [0.10.5] — 2026-09-28

### Добавлено

- Просмотр экрана загрузки: `/?loading` держит его на стартовой странице, `?loading` у ленты круга — в круге. На быстром сервере иначе его не разглядеть.

## [0.10.4] — 2026-09-28

### Изменено

- Экран загрузки: вместо строки «Загрузка…» в левом верхнем углу — знак Wynd по центру, он покачивается в цвете круга. Знак появляется с короткой задержкой, чтобы быстрая загрузка не мигала; при «уменьшить движение» стоит неподвижно. Так грузятся список кругов, лента, «Дни», день, альбом, «Сетка» и «Карта».

### Исправлено

- Запуск приложения у вошедшего: перед переходом к кругам мелькала форма входа — теперь экран загрузки.
- Открытие круга: пока круг читался, экран был пустым — теперь экран загрузки.

## [0.10.3] — 2026-09-27

### Исправлено

- Строка ввода в круге: кнопка «Фото» делала то же, что шеврон, — открывала пустой экран записи. Теперь она сразу открывает выбор снимков, и экран записи открывается уже с ними.
- Экраны круга при переходе монтировались дважды: второй экземпляр терял то, что успел забрать первый, а данные экрана грузились два раза. Теперь экран создаётся один раз.
- «Добавить сервер» в «Серверах»: «Назад» на экране «Без приглашения» уводил в список кругов — теперь возвращает в «Серверы».

## [0.10.2] — 2026-09-27

### Исправлено

- Приглашение в круг: QR-код вылезал за свою рамку (и на `/admin/access` тоже), а длинная ссылка обрезалась в поле — теперь код вписан в рамку, ссылка переносится и видна целиком.
- Приглашение в круг, где разрешены только одноразовые ссылки: вместо подсказки для людей там был текст из макета про «чипы», которых нет. Теперь подсказка одна — что ссылка несёт адрес сервера и токен; про лимит многоразовых — только когда их можно выбрать.

## [0.10.1] — 2026-09-27

Повторный проход аудита безопасности по изменённому с 0.7.1: одна средняя находка в клиенте и две низкие, все исправлены.

### Исправлено

- Клиент принимал от сервера любой адрес исходников и ставил его в ссылку «поднимите свой» / «исходный код»; чужой сервер, у которого экран «Присоединиться» спрашивает данные, мог подсунуть `javascript:` — теперь принимаются только веб-адреса.
- Исключённый из круга участник получал карточку круга (настройки приглашений, окно правки, своё лицо) — теперь 403, как лента и дни.
- Локальный запуск для сети (`scripts\run.bat`, `make run LAN=1`): сервер при старте предупреждает, что он без TLS виден всей сети и годится только для доверенной.

### Изменено

- Документация: повторный проход аудита безопасности по изменённому с 0.7.1 — [`docs/security-audit-2026-09-27.md`](docs/security-audit-2026-09-27.md); план 44 закрыт. Справочник клиента: правило схемы для полей сервера, попадающих в `href`/`src`/`{@html}`.
- Документация: версии клиентской базы IndexedDB (1–3) и правило отката записаны в справочник клиента; jsQR — в списке разрешённых зависимостей.
- План: настольное приложение для установки Wynd на свой сервер — для тех, кто впервые держит сервер (Windows и Linux, Debian/Ubuntu на сервере). `install.sh` и Docker остаются для администраторов.

## [0.10.0] — 2026-09-27

Сканер QR-кода приглашения, потолок кэша на устройстве, «Присоединиться», обновление списка кругов жестом. Минорная версия — из-за новых возможностей и подъёма клиентского хранилища.

### Добавлено

- Список кругов обновляется жестом вниз — со знаком Wynd, как лента круга.
- Сканер QR-кода приглашения: «Присоединиться» → «Сканировать QR-код» — камера считывает код и сразу открывает приглашение. «Фото с QR-кодом» теперь работает и в Firefox (раньше: «сканер недоступен»).
- У кэша фото и видео на устройстве есть потолок — по умолчанию 2 ГБ, меняется в «Настройки → Приложение» (1, 2, 5 ГБ или своё до 100). Сверх него удаляются давно не открытые файлы; раньше кэш рос без предела. Цифра «свободно на устройстве» убрана: браузер сообщает не свободное место на диске, а сколько отводит сайту.

### Исправлено

- Обновление ленты круга жестом вниз: Firefox на Android показывал своё обновление страницы (кружок со стрелкой) вместо знака Wynd, который дорисовывается по мере жеста.
- Меню плюса и меню строки круга не закрывались тапом мимо.
- Знак при обновлении ленты прилипал к шапке круга — теперь над ним отступ, как в кадре 3.5.

### Изменено

- Вход: в карточке сервера — только адрес, без непонятного «принимает вход».
- В меню плюса (удержание) — «Присоединиться»: куда положить присланную ссылку, когда круги уже есть.
- «У меня есть приглашение» на пустом списке кругов открывает экран, куда вставить присланную ссылку или выбрать фото с QR-кодом. Раньше кнопка вела на «Без приглашения».

### Оператору

- Миграций сервера нет, схема v16.
- Клиентское хранилище (IndexedDB в браузере) поднимается до версии 3: у кэша появляются метаданные для потолка. Откат образа на 0.9.x оставит в браузерах базу версии 3, которую старый клиент не откроет, — людям придётся очистить данные сайта. Откатывать без нужды не стоит.
- Новая зависимость клиента — jsQR (Apache-2.0), в THIRD_PARTY_LICENSES.
