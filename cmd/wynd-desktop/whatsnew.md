# Что нового в Wynd Настольном

Раздел на каждую версию — пишется в том же коммите, где поднята версия программы
(`desktop.Version` в `internal/desktop/version.go` и версии в
`cmd/wynd-desktop/build/windows/info.json`; их равенство сверяет тест). Программа «Wynd Подпись»
(кадр 12в) берёт раздел версии выпуска из этого файла в его теге и кладёт
текстом выпуска на GitHub. Строки — «- …», простыми словами, для тех, кто
устанавливает программу.

## 0.5.4

- Вход по коду завершается: раньше после верного кода окно возвращало на экран входа.
- Окно больше не закрывается, если переход (например, открытие ссылки приглашения сразу после запуска) отменил загрузку ответа.

## 0.5.3

- На экране «Войти в Wynd» можно подключиться по коду: «Фото с QR-кодом» подставит адрес сервера и почту, а ссылку подключения можно вставить прямо в поле.
- Окно больше не обрамлено вертикальными полосами по краям: интерфейс сервера — один бумажный лист.

## 0.5.2

- В «Сетке» и «Днях» фото и видео появляются по мере готовности: плитки и карточки видны сразу, экран больше не ждёт последние картинки.
- Обновления предлагаются сразу после публикации: отлёжка 72 часа снята до 1.0.0; подпись и версия проверяются всегда.

## 0.5.1

- Иконка приложения — со скруглёнными углами: в панели задач, меню «Пуск» и на рабочем столе больше нет квадратной бумажной плитки.

## 0.5.0

- Впервые есть Linux-версия приложения: Ubuntu 24.04 и Debian 12, установка пакетом `.deb` или запуск AppImage.
- На Linux работают значок в трее с меню «Открыть»/«Выход», уведомления рабочего стола, автозапуск и ссылки приглашений `wynd:`; входы сохраняются в системном хранилище.
- Строка автозапуска теперь называется «Запускать при входе в систему» — одинаково на всех платформах.
- Самообновления в Linux-версии пока нет: новую версию ставят пакетом или заменой AppImage.
- Копии архивов по расписанию: приложение само сохраняет архивы кругов в выбранную папку — каждый день, каждую неделю, каждый месяц или через свой интервал; старые копии удаляются по настройке (последние N на круг или не старше N дней). Работает, пока приложение запущено (окно можно закрыть); экран — «Настройки → Приложение → Копии по расписанию».
- Вертикальные зазоры экранов сведены к шагам 4/8/16 — экран входа и настройки стали плотнее.
- Меню значка в области уведомлений теперь в стиле Wynd: «Открыть» и «Выход» крупными строками, без системного меню.

## 0.4.5

- Меню значка в области уведомлений теперь в стиле Wynd: «Открыть» и «Выход» крупными строками, без системного меню.

## 0.4.4

- Копии архивов по расписанию: приложение само сохраняет архивы кругов в выбранную папку — каждый день, каждую неделю, каждый месяц или через свой интервал; старые копии удаляются по настройке (последние N на круг или не старше N дней). Работает, пока приложение запущено (окно можно закрыть); экран — «Настройки → Приложение → Копии по расписанию».
- Вертикальные зазоры экранов сведены к шагам 4/8/16 — экран входа и настройки стали плотнее.

## 0.4.3

- Токены входов хранятся в учётных записях Windows (Credential Manager): сессия переживает очистку профиля приложения, прежние входы переезжают при первом запуске сами.
- Приложение показывает системные уведомления Windows от имени «Wynd Настольный»: новые записи в кругах и новая версия приложения — когда интерфейса не видно. Когда интерфейс на виду, приложение молчит.
- Общая горячая клавиша `Ctrl+Alt+W` показывает приложение из любой программы.
- Приглашение, открытое в браузере, можно продолжить в приложении — кнопкой «Открыть в приложении» на странице приглашения; приложение откроет нужный сервер и экран приглашения.
- Оборванное скачивание архива продолжается с места обрыва, а не начинается заново.

## 0.4.2

- Со стрелки «Назад» на экране входа можно вернуться к вводу адреса сервера; введённый адрес остаётся в поле.

## 0.4.1

- Работа не останавливается, когда приложение спрятано в значок: записи и загрузки сами уходят на сервер и догружаются, а при обрыве повторяются без ожидания.
- Повторный запуск больше не открывает второе окно: поднимается уже открытое.
- При обрыве связи приложение показывает понятную сетевую ошибку, а не «сервер не отвечает».

## 0.4.0

- В области уведомлений появился значок Wynd Настольного: «Открыть» показывает окно, «Выход» закрывает программу.
- Закрытие окна больше не закрывает программу: она остаётся работать в значке. Полностью закрыть — «Выход» в меню значка.
- Если программа запускается вместе с Windows, окно больше не открывается само: она ждёт в значке.

## 0.3.1

- Служебный локальный порт отвечает только самому приложению: чужая страница в браузере, перебравшая порты компьютера, больше не сможет читать его ответы. На работу с серверами это не влияет.

## 0.3.0

- Приложение сообщает о новой версии полосой поверх интерфейса: версия, «Обновить и перезапустить», «Позже» и «Что нового». Обновление ставится только по подписи; «Позже» скрывает полосу до следующего запуска.
- В заголовке окна видны название программы и версия.
- Если подпись не сошлась, установка гаснет; «Позже» и «Что нового» остаются.

## 0.2.0

- Сервер, открывающий интерфейс, теперь выбирается отдельно от серверов, на которые вы вошли.
- При добавлении сервера приложение проверяет адрес и сразу показывает название и состояние сервера.
- Можно добавить сервер только для интерфейса, не входя в учётную запись и не переключая текущий экран.
- Неактивный источник интерфейса удаляется крестиком с подтверждением; сохранённые входы остаются на месте.
- Версии 0.1.x обновляются вручную: скачайте новый файл и запустите вместо прежнего.

## 0.1.1

- Окно открывается по ширине интерфейса: без пустых полей по бокам, и его можно сузить.
- Связь с сервером стала надёжнее: новые сообщения и изменения появляются в приложении сразу.
- Приложение больше не показывает старый интерфейс из кэша: после обновления сервера новые экраны видны сразу.
- Обновление вручную: скачайте новый файл и запустите вместо прежнего.
