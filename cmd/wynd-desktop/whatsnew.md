# Что нового в Wynd Настольном

Раздел на каждую версию — строки «- …» простыми словами, для тех, кто ставит окно.

## 0.1.1

- Окно открывается по ширине интерфейса: без пустых полей по бокам, и его можно сузить.
- Связь с сервером стала надёжнее: новые сообщения и изменения приходят в окно сразу.
- Окно больше не показывает старый интерфейс из кэша: после обновления сервера новые экраны видны сразу.
- Обновление вручную: скачайте новый файл и запустите вместо прежнего.
