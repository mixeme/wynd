# Что нового в Wynd Настольном

Раздел на каждую версию — пишется в том же коммите, где поднят номер окна
(`desktop.Version` в `internal/desktop/version.go` и `productVersion` в
`cmd/wynd-desktop/wails.json`; их равенство сверяет тест). Окно «Wynd Подпись»
(кадр 12в) берёт раздел версии выпуска из этого файла в его теге и кладёт
текстом выпуска на GitHub. Строки — «- …», простыми словами, для тех, кто
ставит окно.

## 0.2.0

- Сервер, открывающий интерфейс, теперь выбирается отдельно от серверов, на которые вы вошли.
- При добавлении сервера окно проверяет адрес и сразу показывает название и состояние сервера.
- Можно добавить сервер только для интерфейса, не входя в учётную запись и не переключая текущий экран.
- Неактивный источник интерфейса удаляется крестиком с подтверждением; сохранённые входы остаются на месте.
- Версии 0.1.x обновляются вручную: скачайте новый файл и запустите вместо прежнего.

## 0.1.1

- Окно открывается по ширине интерфейса: без пустых полей по бокам, и его можно сузить.
- Связь с сервером стала надёжнее: новые сообщения и изменения приходят в окно сразу.
- Окно больше не показывает старый интерфейс из кэша: после обновления сервера новые экраны видны сразу.
- Обновление вручную: скачайте новый файл и запустите вместо прежнего.
