# C66 — проверка механизмов настольного клиента

Протокол 2026-10-28–29, без продуктовой реализации. Текущая работа — [план 55](../plans/55-desktop-client.plan.md). Автоматическая проверка не заменяет перенос мышью из Проводника и настоящий вход Windows.

## Результаты

| Проверка | Результат |
|---|---|
| Несколько серверов, 2026-10-28 | Прямой запрос из WebView2 к другому серверу блокируется CORS; через Go-прокси работает. Код — [первый образец](c66/46-c66-prototype.go.txt). |
| Окно Wails v2, 2026-10-29 | Изолированный production-бинарник запускается, открывает `http://wails.localhost` в защищённом контексте. Профиль WebView2 отдельный, данные Wynd не используются. |
| Регистрация команды автозапуска | Временное значение `WyndC66Probe_20261029` в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` записано и прочитано обратно. Команда содержит полный путь в кавычках и аргумент `--from-startup`. |
| Команда запуска вне папки программы | Сохранённая команда запустила exe из папки с пробелами; рабочая папка — `C:\Windows\System32`, специальных переменных C66 нет, журнал подтвердил загрузку страницы и готовность окна. |
| Уборка проверки | Запущенный сценарием процесс остановлен, пробная запись Run удалена в `finally`; отсутствие записи проверено отдельно. |
| Настоящий вход в Windows | **Не проверен:** сессия владельца не завершалась. Проверка команды не выдаётся за проверку входа. |
| Получение файлов в WebView2 | **Пройдено автоматически через CDP:** одиночный и множественный drop, `isTrusted=true`, содержимое и SHA-256 совпадают в JavaScript и Go; проверены три нативных callback и обычное поле выбора файла. |
| Мышью из Проводника | **Не проверено:** инструмент Windows читает дерево доступности, но снимок окна падает по таймауту; ввод — `coordinate input geometry is unavailable`. CDP обходит Windows-ввод, а не проверяет его. |

Механизм Run сверён с [документацией Microsoft](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys): запись действует при входе пользователя, Windows может отложить её запуск. Наличие записи не доказывает немедленный старт при входе.

## Образец для оставшейся проверки

Исходники вне продуктовой сборки: [окно и журнал](c66/46-c66-desktop-probe.go.txt), [сценарий автозапуска](c66/46-c66-startup-probe.ps1.txt). Они собираются в отдельной временной папке из уже установленных зависимостей корневых `go.mod` и `go.sum`. `go build -tags desktop,production -ldflags '-H windowsgui'` прошёл.

Окно одновременно проверяет обычный `DataTransfer.files` и получение путей через Wails (`DragAndDrop.EnableFileDrop`, `runtime.OnFileDrop` на стороне Go и JavaScript). Для каждого файла записываются имя, размер и SHA-256. Файлы никуда не загружаются. Настоящий DOM drop должен иметь `isTrusted=true`; программно созданное событие не считается живой проверкой.

Тестовые файлы по 23 байта:

- `c66-one.txt`: `e965f84d10eb8950fb884293b9d002110c7ce3628f71ff24a21d76d935997826`.
- `c66-two.txt`: `3937ce7632f9d41eca73dcace88053b4c8dcdc96f9fa3dcadb9238001522e85a`.

**Автоматическая проверка 2026-10-29:** [сценарий CDP](c66/46-c66-cdp-check.mjs.txt) отправил `Input.dispatchDragEvent` с настоящими путями тестовых файлов, сначала один, затем два. WebView2 создал доверенные drop-события; Go получил три пути через штатный Wails callback. Имя, размер и SHA-256 сверены автоматически между источником, JavaScript и Go. Поле выбора проверено через `DOM.setFileInputFiles` после сброса значения, как в клиентском FilePicker. Страница осталась на `http://wails.localhost/`.

Для диагностического порта понадобилась временная копия Wails: загрузчик go-webview2 очищает `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS`. В `setupChromium` копии добавлена только строка `if port := os.Getenv("C66_DEBUG_PORT"); port != "" { chromium.AdditionalBrowserArgs = append(chromium.AdditionalBrowserArgs, "--remote-debugging-port="+port) }`; временный модуль подключён через `replace`, файлы установленной зависимости не менялись. Политика CORS и обработчики drop не менялись. Номер порта лежит в `cdp.port`, журнал — `cdp-drop.jsonl`, файлы — в `fixtures/` рядом со сценарием. Команда: `node cdp-check.mjs`.

Снимок WebView2 и JSON с результатами сохранены локально в `dev/c66-evidence/`; сценарий — в репозитории. Собственный процесс остановлен, диагностический порт закрыт. Проверка мышью из Проводника остаётся ручным пунктом перед выпуском.
