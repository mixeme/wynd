# C71: «Загрузить начало» в полном выводе сборки — принятая вёрстка (2026-11-20)

Основа — принятые кадры C71 (C71.1–C71.3, 2026-11-05) и экран «Сборка Wynd
завершилась с кодом N» (Мастерская 0.4.4). Новое в кадре — одна строка-ссылка
**«Загрузить начало»** под рядом «Повторить / К серверу», над «Полным выводом
сборки». Она появляется только когда журнал обрезан (больше 256 КБ) и
догружает предыдущие 256 КБ с сервера порциями, пока не дойдёт до начала;
служебная строка «начало вывода не сохранено» после догрузки скрывается.
Остальное — принятые экраны без изменений.

**Владелец принял 2026-11-20 («Да»)** после правки отступа: ссылка стояла
вплотную к кнопкам, добавлен верхний отступ 16 px (`9038632a`).

- `log-earlier-window.png` — окно 1024×760 целиком (принятый кадр).
- `log-earlier-gallery.png` — страница стенда с подписью сцен (для проверки,
  что снято из настоящего рендера `gallery.html?scene=7d2-log-truncated`).

Стенд: `cmd/wynd-workshop/frontend/gallery.html?scene=7d2-log-truncated`
(сцена `7d2-log-truncated` в `src/gallery/scenes.ts`), Edge headless
1024×760, светлая тема. Реализация — `ecc55949` (журнал на сервере, мост
`BuildLogChunk`, кнопка догрузки). SHA-256 — в `checksums.sha256`;
повторную приёмку неизменённого кадра не проводить.
