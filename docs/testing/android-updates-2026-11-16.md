# Android: подготовка канала APK, 2026-11-16

Статус: код канала и локальный отрицательный прогон подготовлены; сквозная
установка и публичный выпуск **не завершены**. Вшивание интерфейса — следующий
шаг после проверки канала, сейчас интерфейс по-прежнему приходит с dev-сервера.

## Решение и реализация

Решение владельца: 72 часа для всех приложений, «Скачивать сразу» для разработки.
Windows-обновления не менялись. Android использует `mixeme/wynd`, опубликованные
теги `android-vX.Y.Z`, `wynd-android.apk` и его SHA-256. Время выдержки — HTTP Date
каталога, а не часы телефона. Debug или системные настройки разработчика дают
переключатель; по умолчанию он выключен. Он отменяет только выдержку времени.
В обычном APK разработчик получает тот же пакет и ключ, что и остальные люди.

Нативный мост объявляет протокол и возможности и доступен только главному фрейму
выбранного origin. URL/путь APK страница не задаёт. Ограничены хосты, редиректы,
размеры и время чтения. До PackageInstaller проверяются SHA-256, подпись Android,
совпадение сертификатов с установленным приложением, пакет и новая версия.
Системное подтверждение сохраняется. Сеансы установщика различаются по ID;
системный отказ проверки не объявляется отменой пользователем.

CI и локальная подпись описаны в [android/README.md](../../android/README.md).
Постоянный ключ владельца ещё не создан/не выбран. Подготовлены отдельные
скрипты создания ключа и локальной подписи attested unsigned APK из черновика.
Они пока проверены по синтаксису, а не настоящим выпуском. Ключ не передаётся
GitHub. `releaseReady=false`: первый запуск обычного APK ещё не реализован,
публиковать его как готовое приложение нельзя. Теги, push и публикация не делались.

## Проверки

- JVM: 15 тестов (origin, политика выпусков, настоящий локальный HTTP-транспорт).
  Проверяются точная граница 72 часов, выключение обхода, draft/prerelease,
  версии, адреса, серверное время, лимит тела и запрещённый редирект.
- Android: строгий lint debug/release, сборки debug и unsigned release.
- Web: Svelte check без предупреждений, UI guard, ESLint изменённых файлов,
  три теста моста, production build. Общий прогон: 495 тестов прошли в sandbox;
  оставшийся тест лицензий требовал записи Go cache вне workspace и прошёл
  отдельным повышенным запуском (два теста файла). Всего 496 тестов проекта.
  Предупреждения сборки о qrcode, theme_color и размере chunk существовали ранее.
- Физический OPPO CPH1931, Android 10/API 29, WebView 130.0.6723.107,
  debug-пакет `mixeme.wynd.debug`; realme 8 и API 21 не проверены.
- Локальный fixture на `127.0.0.1:7697` через adb reverse. Подготовлены debug
  0.1.0/0.1.1 с одним тестовым ключом, APK с чужой подписью и повреждённый APK
  с соответствующей ему контрольной суммой. Это **не** доказательство загрузки
  из публичного GitHub или работоспособности CI.

`scripts/test-android-update.mjs aa8d50d0 prepare` подтвердил девять проверок:
молодой выпуск ждёт; draft/prerelease игнорируются; включение переключателя
снимает выдержку; выключение возвращает её; зрелый выпуск доступен без обхода;
плохая сумма, чужая подпись и повреждённый APK отвергнуты до установщика;
корректный APK 0.1.1 проверен и подготовлен. Результат оставлен вне репозитория:
`D:\android-env\test-releases\device-result.json`.

Установщик запущен штатно из строки настроек. Разрешение установки дано только
Wynd. Android показал подтверждение обновления, после него Play Защита запросила
отправку нового APK Google. На момент записи установлен всё ещё 0.1.0-debug,
сеанс ждёт решения; отправка без отдельного согласия владельца не выполняется.
Повторный запуск приложения во время этого запроса может сорвать проверку;
поэтому `finish` сначала проверяет установленную версию без запуска Activity.
Ранняя попытка закончилась INSTALL_FAILED_VERIFICATION_FAILURE; это не успешное
обновление. Сохранение localStorage/IndexedDB **после обновления ещё не проверено**.

После сборки тестовых APK код уточнён: корреляция сеансов, нейтральный текст
отказа Android и доступ к обходу в обычном APK при системном режиме разработчика.
Эти уточнения покрыты сборкой/lint/проверкой политики; полный повторный прогон
именно окончательного APK на телефоне ещё нужен.

Окончательная локальная сборка: debug 0.1.0-debug, SHA-256
`33bfeab97e49dcf897e3f08e398d28162af19cea1dd40e95448ae4b4b5108246`;
unsigned release 0.1.0, SHA-256
`1f07c7c8905ca990e1bb8a31cadc5cae01b246a69fe03c3ef2a84157cebbdb41`.
Она также сбрасывает выбранный молодой выпуск, если режим разработки выключен
в системных настройках перед загрузкой/установкой. Во время ожидающей проверки
Play Защиты новое APK поверх установленного через ADB не ставилось.
