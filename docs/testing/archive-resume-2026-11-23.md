# Докачка архива участника — 23 ноября 2026

Функция 5 плана [66](../plans/66-desktop-functions.plan.md): оборванное скачивание архива продолжается с середины, а не начинается заново.

## Реализация

- **`Range` на `/archive/download` и по одноразовой ссылке** (`internal/api/archive.go`): архив собирается потоком на каждый запрос, но сборка детерминирована (Store без времени, порядок постов из журнала, аватары сортированы) — поэтому продолжение отдаётся повторной сборкой с пропуском уже скачанного (`skipWriter`, контракт `io.Writer` соблюдён: возвращается длина всего буфера). Поддерживается только открытый диапазон `bytes=N-`; прочие формы — полный ответ 200, как велит спецификация.
- **ETag — версия архива** (`"<круг>|<отсечка>|<max_seq>|<размер>"`): новое событие круга меняет `max_seq`, `If-Range` расходится — браузер начинает заново, а не клеит половины разных архивов. `Accept-Ranges: bytes` в полном ответе.
- **Одноразовая ссылка (C38) осталась одноразовой по результату**: снимается, когда архив у клиента целиком (полный ответ или доклеенный хвост), а не на первом байте. Оборванная на середине отдача продлевает срок — «продолжить» в браузере придёт тем же адресом; отказ до первого байта (занято, нет доступа) ссылку по-прежнему тратит.
- **Отсечка архивации** фиксируется, когда архив у участника целиком, включая доклеенный хвост (ARC-8).

## Границы

- **Полный архив круга — без докачки:** ссылка одноразовая по конструкции, шифрование age недетерминировано (случайный ключ потока) — Range потребовал бы кэша готового файла на сервере. Это отдельное решение, если понадобится.
- Обрыв на середине (продление ссылки) вживую не смоделировать: в тестах покрыты 206, 416, `If-Range` и снятие ссылки; продление — по коду и тесту busy-семантики.

- Полный архив: 200, `ETag: "…|2026-11-24|3|77641"`, `Accept-Ranges: bytes`, 77 641 байт.
- `Range: bytes=4096-` → **206**, `Content-Range: bytes 4096-77640/77641`, 73 545 байт; **склейка первых 4 КБ полного ответа с хвостом побайтово равна полному файлу** (`cmp` — совпадение).
- `bytes=77641+` → **416**; чужой `If-Range` → **200** полным телом.
- Ссылка: Range-хвост → 206, следующий запрос → 404 (ссылка отработала); полный по ссылке → 200, затем 404.
