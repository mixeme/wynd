# Высота шапок Wynd

19 ноября 2026. Ревизия по замечанию к редактору новой записи
в [плане 50](../plans/50-android-wrapper.plan.md).

Измерены общие компоненты в настоящем рендере Svelte через Vite dev
и Edge Headless. База `83b09aec`, с рабочей поправкой редактора в
копии. Области просмотра 360 × 728 и 1000 × 728 CSS px, DPR 2,
светлая тема, обычный размер шрифта. Шапки собраны из тех же компонентов,
что и соответствующие страницы. На обеих ширинах результаты совпали.
Это набор типовых состояний. Длинные подзаголовки и увеличенный шрифт
могут увеличить измеренную высоту.

| Экран или состояние | Компонент | Высота, CSS px |
| --- | --- | ---: |
| Улочка, поиск и настройки справа | `AppBar` | 48 |
| Настройки со стрелкой назад | `BackBar` | 45,64 |
| Общий поиск с полем в шапке | `BackBar compact` | 56,56 |
| Экран круга без вкладок | `CircleBar` | 60 |
| Круг с пятью вкладками | `CircleBar` | 92,56 |
| Альбом с однострочной подписью | `CircleBar` | 78,13 |
| Вступление в круг | `FormLayout circleTitle` | 58 |
| Участники при вступлении с именем круга под заголовком | `FormLayout` с цветом и подзаголовком | 78,13 |
| Новая запись | `FormLayout compose compact` | 60 → 52 |
| Правка, черновик из очереди, обложка дня | `FormLayout compose` | 60 |
| Панель администратора | `AdminBar` | 55 |
| Заголовок настольного окна | `TitleBar` | 34 |

Основы из `docs/visual/screens.html` (`825921cc`): `e2-1` улочка,
`e7-46` настройки, `e2-19` поиск, `e6-2` экран круга без вкладок,
`e3-1` круг с вкладками, `e1-4` вступление и `e4-2` редактор.
Настольная основа редактора с импортом — `#pc6` в
`docs/plans/55-desktop-frames.svelte.txt` (`54ecac07`).
Системные полосы Android в замеры веб-шапок не входят.

У однотипных экранов высоту задаёт общий компонент. Основная строка
сохраняет размеры и положение действий при смене состояния. Высота
растёт из-за поля, подзаголовка или вкладок. Если однострочную шапку
нужно уплотнить, первым проверяется свободный отступ под строкой.
Это правило закреплено в [справочнике Wynd UI](../reference/ui-components.md#chrome).
Уже принятые варианты других экранов пересматриваются по отдельным кадрам.

У новой записи сокращён только нижний отступ 12 → 4 CSS px.
Сокращение отступа сохраняет высоту строки действий. Обычный «+» и импорт
из Android или Настольного используют один маршрут.
[Сопоставимые кадры и замеры редактора](android-compose-header-2026-11-19.md).
