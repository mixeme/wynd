# OPPO 24.11.2026 — настоящая почта и C99/C108 на HTTPS

OPPO CPH1931, Android 10, Firefox 132. Сервер — тестовый
`wynd2.mixfed.ru` 0.53.6. Тестовый ящик — из `myenv/Wynd/credentials`
(доступ по IMAP проверен; адрес и пароль в репозиторий не записываются).
Обычная сессия Firefox на wynd2 с прошлых проверок не трогалась: письма и
архив проверялись отдельным тестовым аккаунтом.

## Почта wynd2

Почтовый ящик был пуст (только письма от 19.09). На wynd2 исходящая почта не
была настроена вовсе: `/admin/smtp` отдавал `configured: false`, `admin_email`
пустой. По `myenv/Wynd/credentials` заданы SMTP selfpost и «Письма
администратору» — тестовый ящик. Проверочное письмо пришло
(«Проверка почты Wynd», 20:51:58Z).

### A10 — «Просят место для круга»

В панели wynd2 создано одноразовое приглашение, тестовый ящик принял его и
получил код входа (20:52:40Z); учётка создана. От её имени создан круг
«Тест OPPO», квота круга временно 4096 байт, запрошено 10 МБ. Письмо
**«Просят место для круга»** доставлено на настоящий ящик
(20:54:58Z, от `Wynd · wynd2 <noreply@wynd.mixfed.ru>`). Это закрывает
недостающую часть A10 — настоящую почту вместо локального SMTP. Основной
`wynd.mixfed.ru` и его ежедневная диагностика не трогались.

### Письмо о готовом архиве

У круга «Тест OPPO» запущена полная сборка без пароля. Письмо
**«Архив круга готов»** пришло 21:03:32Z, ссылка в нём ведёт на
`/circles/{id}/quota/full` (та же, что разбиралась 22.11 на локальном SMTP).
Заголовки писем — [mail-headers.txt](mail-headers.txt).

## C99/C108 — HTTPS/PWA

В обычной сессии Firefox на wynd2 прогрета лента «А26-проверки»
([w2-feed-warm.png](w2-feed-warm.png)), затем Wi-Fi выключен, Firefox
остановлен и `/circles` открыт заново:

- 6 с — пустой экран загрузки;
- 13 с — улочка из снимка: «А26-проверка» на месте, полоса «Нет сети. Новое
  уйдёт само, когда связь появится» ([offline-cached-street-13s.png](offline-cached-street-13s.png));
- 20 с — то же ([offline-cached-street-20s.png](offline-cached-street-20s.png)).

«Ни одного круга» нет. Ветка C108 «прогрев из ленты → холодный запуск»
на 0.53.6/HTTPS больше не воспроизводится. Причина первого пустого списка из
C99 (самый первый запуск без снимков) этим прогоном не покрыта.

## Граница проверки

Ссылку из письма «без входа» проверить в чистом контексте телефона не удалось:
других браузеров на OPPO нет, а приватная вкладка Firefox помечает окно
`FLAG_SECURE` — снимки экрана пустые, содержимое страницы не попадает и в
`uiautomator dump` (видны только заголовок и адрес). Сам путь «ссылка → вход →
сразу Архив круга» подтверждён 22.11 на локальном SMTP; здесь подтверждена
доставка настоящего письма со ссылкой.

## Состояние после прогона

Wi-Fi включён. `admin_email` на wynd2 возвращён в пустое значение; SMTP
оставлен настроенным — API не принимает пустой хост, а исходящая почта
тестовому серверу полезна. На wynd2 остались тестовая учётка (ящик из
`myenv`), круг «Тест OPPO» с двумя записями, готовый архив и одна заявка на
место в панели — тестовые данные, не удалялись.
