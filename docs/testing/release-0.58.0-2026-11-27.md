## Грабли

- **Android-тег и `paths`.** В `android.yaml` у push перечислены `paths`; для
  тега GitHub сверяет изменения коммита тега, поэтому docs-only коммит
  `9169da3b` не запустил сборку. Тег `android-v0.1.9` переставлен на
  `0e4247f7` (там `android/version.properties` и `android/whatsnew.md`) —
  прогон `45986015695`; остальные теги остались на `9169da3b`.
- **Перестановка тегов.** Сначала теги указывали на `0e4247f7`; до старта
  tag-прогонов они переставлены на `9169da3b` после правки выписки.
  `gh release view` перед перестановкой проверен — черновиков ещё не было;
  Gitea и зеркало обновлены force-push.
- **Чужая несохранённая правка на воротах.** Ворота шли на дереве, где
  другая сессия держала несохранённый `web/src/lib/styles/ui.css`
  (значок загрузки в широком окне). В выпуск он не вошёл (путь не в
  коммите); позже его закоммитили отдельно (`c64e4bd6`).
- **`## [Unreleased]` в середине CHANGELOG.** Старый блок с уже вышедшими
  клиентскими разделами (0.4.9, 0.5.1, 0.1.4 и старше) остаётся долгом
  прежних волн; в 0.58.0 перенесены только записи этой волны.
