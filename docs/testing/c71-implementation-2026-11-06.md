## Что сделано

- Сборка идёт без `docker build -q`: `--progress=plain`, строки BuildKit попадают в поток окна.
- Под шагом сборки показывается последняя непустая строка вывода (`StepState.latest`) и её давность (`latest_note`): «Последнее сообщение — сейчас», затем «Последняя строка вывода — N минут назад». ANSI, CR и управляющие символы вычищаются; частичные строки учитываются.
- Журнал одной команды ограничен **256 КБ** вместо 8 КБ. Если начало не поместилось, в журнале явно написано «начало вывода не сохранено»; хвост не выдаётся за полный вывод.
- При ошибке в журнал добавляется отдельная строка «Сборка завершилась с кодом N», а последняя строка вывода и этап остаются в шаге.
- UI: раскрытие «Полный вывод сборки» показывает журнал именно сборки, а не все SSH-команды; по умолчанию закрыто, не запускает команду повторно. Экран ошибки обновления показывает этапы с последней строкой.
- Полоса с выдуманным процентом на экране обновления убрана: показываются этапы, текущий шаг и вывод.
- Шаг сборки называется «Собираем образ Wynd»; при скачивании готового образа остаётся «Wynd <версия>».

## Границы

- **Нативный снимок C71 не получен.** Для него нужна живая сборка на сервере, а тег/образ 0.49.0 на GitHub и в реестре ещё не опубликованы. Владелец подтвердил: снимок — после публикации и выпуска. Браузерные кадры C71 уже приняты; снимок реализации не выдаётся за проверенный.
