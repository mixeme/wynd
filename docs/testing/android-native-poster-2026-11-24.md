# Android: нативная очередь 5.5 — кадр ролика и снятие C48 (24.11.2026)

Последний шаг этапа 5 плана [50](../plans/50-android-wrapper.plan.md): кадр
ролика снимает телефон, временная серверная съёмка (C48) удалена.

## Что сделано

- **Native.** `PosterExtractor` через `MediaMetadataRetriever` берёт первый
  кадр (с 1 с, иначе с 0), уменьшает до 1024 px по большей стороне и пишет
  JPEG. `NativeQueueWorker` делает это для ролика без клиентского кадра до
  загрузки и добавляет кадр отдельной aux-частью; существующий кадр клиента
  не заменяется. После загрузки кадр уходит в media как
  `video_poster_blob_id`.
- **Сервер.** Убраны `internal/poster`, поле `Server.Posters`, вызовы
  `FillPost`/`Backfill`, ffmpeg из `deploy/docker/Dockerfile`. Исключение
  «сервер снимает кадр» удалено из `ARCHITECTURE.md`, `stack.html` и
  `server-reference.md`. **C48 закрыт.** PWA/Firefox без кадра по-прежнему
  показывает ролик без постера; сервер его больше не создаёт.
- **Валидация клиентского кадра** (`video_poster_blob_id`: JPEG, свой блоб)
  осталась: это не серверная съёмка.

## Ворота

- Go: `go build ./...`, `go test ./internal/api` — зелёные. Тесты серверной
  съёмки удалены; проверка отказа чужого/не-JPEG кадра осталась.
- Android: `NativeQueueTest` — 10 (добавлен aux-постер), NativeQueueSender 6,
  ArchiveStore 1, lint, сборка — зелёные.
- Web не менялся (652 теста, svelte-check 0/0 — с прошлого шага).

## Живой прогон на OPPO

OPPO CPH1931, Android 10, debug APK из текущего дерева; стенд 7677 (0.53.6,
SERVER без poster-кода) на `dev/c92/data2`. MP4 960×540, 3 766 394 байта
передан через `__wyndQueue` с `media_meta [{kind:"video"}]` — **без кадра**.
Стенд был остановлен; native до загрузки снял кадр:

- в очереди появилась aux-часть `poster.jpg`, 36 789 байт, `media_index=0`,
  `field=video_poster`;
- после подъёма стенда запись ушла при невидимой активности; в ленте media
  `sample.mp4` 3 766 394 байта и `video_poster_blob_id`;
- скачанный кадр — JPEG 960×540, 36 789 байт. Серверный код кадров в этой
  сборке отсутствует, значит кадр сделал телефон.

**Границы:** живой прогон через мост, не через кнопку публикации; ролик без
кадра в PWA/Firefox теперь остаётся без постера — это след снятия C48. Кадр
клиента native не заменяет (проверка в коде; отдельный живой прогон не
делался). Образ Docker без ffmpeg не пересобирался — это будет в следующем
серверном выпуске (0.53.7).
