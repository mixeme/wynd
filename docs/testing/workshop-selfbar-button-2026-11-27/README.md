# Кнопка полосы обновления Мастерской обычного размера — 27.11.2026

Владелец 27.11 по снимку работающего окна 0.4.10: «Кнопка обновить великовата.
Почему не обычного размера?» В полосе «Вышла Мастерская 0.4.11» кнопка
«Обновить и перезапустить» была 47,5 px высотой против 36,8 px у «Перезапустить»
на пульте: поля 14 px, радиус 12 px, ширина из телефонных мерок `$ui`.

В утверждённом кадре 10г кнопка полосы — обычная кнопка окна: правило
`#workshop-storyboard .server-card .win .btn` даёт ей поля 8 × 14, радиус 7,
`font: 500 13px/1.45`, рамку `--c` и цвет `--on-c`. В собранном окне полоса
лежит вне `.ins`, поэтому правила `.ins-servers .ins .btn` на неё не действуют,
а `.selfbar .btn` снимал только `margin` — оставались телефонные значения
базового `.btn` из `$ui`: `padding: 14px`, `border-radius: 12px`,
`width: calc(100% - 32px)`, `font-weight: 600`.

## Изменение

Два правила в `cmd/wynd-workshop/frontend/src/app.css`, только полоса:

- `.selfbar .btn` — мерки обычной кнопки окна: `display: inline-block`,
  `width: auto`, `margin: 0`, `padding: 8px 14px`, `border-radius: 7px`,
  `font: 500 13px/1.45 var(--ui)`;
- `.selfbar .btn.c` — рамка `1px solid var(--c)` и цвет `var(--on-c)`, как в
  кадре 10г; у выключенной кнопки остаётся серая рамка `.btn.off`.

Полоса, её фон, зазоры, «Позже», «Что нового» и пульт не менялись: кадры без
полосы до и после побайтно одинаковы.
