## Что принято

- Кнопка **«Войти на другой сервер»** под подсказкой; в браузере и PWA её
  по-прежнему нет.
- Значки пунктов: «Сменить почту» — карандаш, «Принять круг» — приём вниз,
  «Выйти на этом устройстве» — выход, «Уйти с сервера насовсем» — корзина.
- У строки с адресом почты — конверт; текст и подпись встали в общую колонку
  с пунктами меню. Значок добавлен в общий набор `web/static/icons.svg`
  (`i-mail`).
- Центры значков сведены на одну ось: рисунки внутри 24×24 подведены к
  центру (`edit` +0,25/+0,5 px, `out` −1 px); контейнеры и раньше стояли
  ровно.
