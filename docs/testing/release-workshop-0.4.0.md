## Почему удалённого выпуска пока нет

`git fetch origin main --tags` через штатный HTTPS-remote Gitea вернул `remote: Failed to authenticate user`. Проверка без сохранённой учётной записи запросила вход. Проверка уже настроенного SSH с `BatchMode=yes`, `StrictHostKeyChecking=yes` и таймаутом завершилась `Connection timed out during banner exchange`; ключи доверия не менялись. В известных файлах настроек проекта нет Git-настройки Gitea; ключ подписи не открывался.

При следующей проверке 5 ноября неинтерактивный `ls-remote`, затем `fetch` успешно отработали с сохранённой учётной записью. Пользовательский Git-конфиг не менялся с 27 октября; прежний push 4 ноября выполнялся обычной командой через тот же origin. Причина предыдущего отказа не установлена; истечение токена не доказано. Совет удалять сохранённую запись отозван.

После восстановления чтения refs автоматическая проверка отклонила команду push: обновление общей main со всеми накопившимися локальными коммитами требует отдельного явного согласия. Команда не исполнялась. Проверка refs показала 31 локальный коммит сверх `origin/main`, включая параллельные изменения C71/C44. Локальный тег не отправлен. Удалённого выпуска и Workshop CI нет; прямой обход через GitHub не выполнялся. После отклонения приложения владельцем публикация остановлена независимо от доступа Git.
