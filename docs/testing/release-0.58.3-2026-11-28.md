## Форма метки карты

`2594c040` (C161) меняет вид метки: квадрат 44 × 44, рамка `#fff` 2 px,
радиуса нет — по слову владельца 28.11 «Форма метки — квадрат в белой рамке».
Настоящий рендер собранного клиента — [протокол формы](map-pin-shape-2026-11-28/README.md).
Точные пиксели (толщина и цвет рамки, скругление) формально ждут приёмки;
правка — одно правило в `web/src/lib/styles/map.css`. В выпуск форма включена,
потому что уже лежит в `main` и задана владельцем; CHANGELOG описывает её как
«Изменено».
