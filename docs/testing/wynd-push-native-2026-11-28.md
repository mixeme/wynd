# Добавление Wynd Push в нативном окне — 28.11.2026

Проверили сценарий добавления из окна Мастерской на Windows с WebView2.
Исходник `127cce69`, реализация `e75c295e`. Временная сборка была сделана
с тегами `desktop,production` и `-H=windowsgui`, с вшитым фронтендом.
Сценарий использовал реальные вызовы `main.App` через Wails и локальный
SSH-сервер с ответами из `push_apply_test.go`. Для проверки ответа сайта
и DNS в фабрику профиля подставили детерминированные ответы.

Профиль, ключ тестового SSH и WebView2 созданы в изолированном каталоге
в `dev/`. Внешние серверы и профили пользователя в проверке не участвовали.
По CDP на `127.0.0.1` проверили действия и состояние окна.

| Проверка | Результат |
| --- | --- |
| Подключение | Окно запросило подтверждение ключа локального SSH. После подтверждения и осмотра открылся пульт с обнаруженной установкой Wynd. |
| Форма | «Добавить» открыло ввод домена. Подсказка называет выбранный сервер. Замер DOM показал 8 CSS px от поля. |
| Неверный DNS | `elsewhere.net` получил отказ. Заглушка зафиксировала ноль операций записи. |
| План | После ввода `example.net` открылось «Что сделаем». До подтверждения по-прежнему ноль записей. |
| Отказ применения | Заглушка один раз вернула ошибку при пересоздании Wynd. `.env` и `Caddyfile` совпали с исходными байтами, Push остановлен, окно показало восстановление. |
| Повтор | Повторное подтверждение из плана прошло. Заглушка зафиксировала новый адрес в настройках, окно вернулось в пульт со статусом «Сервер уведомлений работает». |

Снимок нативного окна не получен. `capture-workshop-window.ps1` на двух
запусках не нашёл главного дескриптора окна. CDP использовался для проверки
поведения и замера DOM. Последние визуально сверенные кадры остаются
снимками галереи. [Сверка с утверждёнными кадрами](../visual/reviews/wynd-push-add-2026-11-28/README.md#проверка-реализации).

На рабочей машине нет Docker и Podman, установленного Linux-дистрибутива
WSL для прогона также нет. Для проверки контейнеров, настоящего DNS,
сертификата и доставки нужен отдельный тестовый стенд со своим Caddy и
двумя доменами. [Реестр живого прогона](pending-device-checks.md#32-wynd-push-в-мастерской-план-76).
