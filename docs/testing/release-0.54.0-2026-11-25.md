### Почему Android 0.1.4 остался черновиком (разбор 25.11, вечер)

- Подпись и загрузка прошли: `wynd-android.apk` и `.sha256` появились в
  черновике 25.11 в 16:19:28–35 UTC. Публикация — последний шаг того же прогона:
  одна команда ставит заголовок, текст из `android/whatsnew.md` 0.1.4, пояснение
  про файлы и `draft=false`.
- Публикация не применилась: тело черновика осталось заглушкой CI («Unsigned
  build…»), на момент осмотра `updated_at` выпуска — 16:19:38 UTC. Значит,
  прогон оборвался сразу после загрузки APK: запрос публикации либо не дошёл,
  либо был отклонён. Текст отказа нигде не сохранён (окно журнала не ведёт, в
  журнале Windows падения нет) — отличить эти случаи по состоянию нельзя.
- Проверено тем же кодом, что и окно, только чтение: `publishes=true`
  (`releaseReady=true` в теге `d7222935`, раздел 0.1.4 читается); APK в
  черновике подписан `CN=Wynd Android`, отпечаток
  `fb9ebd852b886bc38cd82d20b73c2ab2af17b6a423c25ab4fabf455f097d5f8b` совпадает
  с эталонным сертификатом тега, сумма файла сходится с assets `.sha256`
  (`3f8978d9…`). `gh release edit` этот черновик находит — проверочный вызов
  выставил тот же заголовок, содержимое не менялось.
- Повторить через «Подпись» нельзя: сторож видит уже подписанный APK и
  отказывается («не перезаписываю: прежняя подпись остаётся»). Так задумано
  против второй подписи, но пути «опубликовать уже подписанный черновик» в окне
  нет — тупик; нужен отдельный шаг с проверкой сертификата и тестом либо
  публикация вручную.
- Закончить вручную (ждёт слова владельца): `gh release edit android-v0.1.4
  -R mixeme/wynd --draft=false --title "Wynd Android 0.1.4" --notes-file …`;
  в файле — раздел 0.1.4 из `android/whatsnew.md` и пояснение `androidAssetNote`
  («Устанавливать нужно `wynd-android.apk`…»).
- После публикации 0.4.9 в main вошёл `16a274b7` «Шаги: три точки текущего шага
  по центру строки» — в уже опубликованную 0.4.9 он не входит; локальная
  «Подпись» пересобрана (`dist/wynd-signer.exe`), в следующую Мастерскую
  исправление войдёт. Сервер, Настольный и Android его не используют (StepList —
  только Мастерская и «Подпись»).
