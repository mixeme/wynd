# Повторы на OPPO, 21 ноября 2026

OPPO CPH1931, Android 10, портрет 720 × 1600 px, светлая тема. Для локальных
проверок веб-клиент и сервер Wynd 0.53.4 собраны из `2e2e7c10`, стенды
подключены к телефону по USB. Снимки получены через `adb exec-out screencap -p`.

## C108. Холодный запуск по HTTPS-ссылке

**Пройден после прямого открытия ссылки онлайн. После прогрева из ленты
дефект воспроизвёлся.** Проверили одну существующую тестовую запись
в круге «A26-проверка» на `https://wynd2.mixfed.ru`. API экземпляра сообщил
версию 0.53.4. Каждый раз останавливали Firefox, проверяли отсутствие процесса,
отключали Wi-Fi и мобильные данные и открывали один HTTPS-адрес через
Android `ACTION_VIEW`. Android подтвердил отсутствие сети в обоих прогонах.

| Как открыли обсуждение онлайн | После холодного открытия без сети | После возврата сети |
| --- | --- | --- |
| [Касанием записи в ленте](c108-https-warm.png) | [К 26,67 с открыт пустой список кругов](c108-https-offline.png), адрес изменился на `/circles`. | [На контрольном кадре открыт тот же список](c108-https-restored.png), полоса «Нет сети» исчезла. |
| [Отдельно по прямой ссылке](c108-https-direct-warm.png) | [К 13,89 с видно обсуждение с текстом и фото](c108-https-direct-offline-early.png). [К 26,25 с оно остаётся открытым](c108-https-direct-offline.png). | [Та же запись и тот же адрес](c108-https-direct-restored.png), полоса «Нет сети» исчезла без ручной перезагрузки. |

Прошлый USB-стенд останавливался на сетевой ошибке Firefox. В этом прогоне
по HTTPS приложение открылось в обоих случаях. Остаётся проверить сохранение
пути к обсуждению, ранее открытому только из ленты в рамках прогона.

[данные прямого открытия](c108-https-direct-result.json).
