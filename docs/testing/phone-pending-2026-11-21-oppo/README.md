# Повторы на OPPO, 21 ноября 2026

OPPO CPH1931, Android 10, портрет 720 × 1600 px, светлая тема. Для локальных
проверок веб-клиент и сервер Wynd 0.53.4 собраны из `2e2e7c10`, стенды
подключены к телефону по USB. Снимки получены через `adb exec-out screencap -p`.

## C114. «Сетка» в Firefox

**Пройдено в Firefox 132.0.** В отдельной тестовой вкладке первым открыли круг
с 11 записями. В этот раз [«Сетка» загрузилась](c114-firefox-grid-11.png)
и показала «11 записей с фото и видео из 11 записей». Проверили остальные
формы на таком же наборе синтетических кругов.
