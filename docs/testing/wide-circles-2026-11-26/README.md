## Изменение

- От 720 CSS px — две колонки: слева та же улочка, справа открытый круг. До 720 px всё как было.
- 720–1059 px: слева рейл 80 px — от кругов только аватары, имя в подсказке (`title` и `aria-label`). Непрочитанное: число новых записей — тёмный значок с белой цифрой и кантом бумаги на углу аватара; только новые отклики — точка там же. От 1060 px: полный список 340 px и круг 720.
- От 1060 px общая ширина — 1060 px (340 + 720) по центру окна; до 1060 — 800 px (80 + 720), тоже по центру.
- Открытый круг отмечен в списке подложкой и полоской своего цвета; без выбора справа `EmptyState` «Выберите круг».
- Сам круг не менялся: и на широком окне, и на планшете в книжной ориентации он 720 px — рейл отдаёт ему всю оставшуюся ширину.
- `/circles/new` и `/circles/{id}/join` остаются одноколоночными.
- **Одна лупа на экране.** В раскладке поиск по кругам из левой шапки убран: с открытым кругом остаётся единственная лупа — поиск в круге. Поиск по кругам — подписанная кнопка в пустой правой части, когда круг не выбран. В рейле поиска нет вовсе.
- Полоса прокрутки в левой колонке — только когда строки не помещаются. Причина лишней полосы: верхний отступ первого баннера схлопывался через обёртку списка, обёртка высотой 100 % уезжала вниз на 8 px и «переполняла» себя пустым местом; плюс Edge рисует полосу даже без переполнения. Исправлено `5babe847` (скрывать, пока нечего прокручивать) и `ab68244f` (`display: flow-root` у `.minh-full`).
