## Грабли

- **Теги из зеркала не запускают workflow.** Gitea-зеркало создало теги на
  GitHub без push-событий. После перестановки тега на новый коммит прямой
  `git push` тега событие дал (Desktop client `45950848950`), у Android —
  нет (сборка запущена `workflow_dispatch --ref android-v0.1.7`). Проверять
  появление прогонов и при необходимости запускать вручную на ref тега:
  условия черновика — `startsWith(github.ref, 'refs/tags/…')`.
- **Перестановка тега при живых прогонах.** Пока шли прогоны по старому
  тегу (`c0faee1a`), черновик Android успел собраться из него — со значками.
  Удостоверение (`sourceRepositoryDigest`) показало старый коммит; черновик
  удалён, сборка повторена от `b19b5867`. Перед подписью сверять источник
  по удостоверению, а не только по номеру версии.
- **`str.replace(old, new, 0)` в Python ничего не заменяет** — при подъёме
  версий это молча оставило VERSION/Go-константы прежними; сверять каждую
  версию после правки.
- **Тест «Что нового» сверяет запись с `web/package.json`** — версию пакета
  поднимать вместе с VERSION, иначе `notes.test.ts` падает.
- **OpenAPI-файлы содержат `info.version`** — `internal/version` требует
  равенства VERSION; обновлять оба `openapi-*.yaml`.
- В `web/node_modules` после удаления worktree остался пустой каталог —
  перед воротами нужен `npm ci`.
