# A26: предложение по медиа внутри карточки

**Статус: предложение, вёрстка не принята.** Код рабочего архива не менялся.

Решение владельца в этой сессии: просмотр фото/видео поверх страницы согласован **по смыслу**. Это отдельный вопрос от того, как карточка сообщает о нескольких вложениях. Вёрстку просмотрщика здесь не показываем и не считаем принятой.

- Текущий исходник для генерации: `17522f3208ab157eb6030ee30bfdff4e9a920253`; отклонённые плитки уже сняты реверсом `130295af`.
- Две тестовые записи из существующего `dev/archive-frame/main.go`: фото с роликом и двенадцать фото. Содержание в сравнении одинаковое; ссылки на медиа перенесены к локальным файлам кадра.
- Отклонённый кадр от 15 ноября не используется как утверждённая основа.

## Предлагаемое отличие

Фото и видео внутри карточки — одинаковые превью 88 × 88 с зазором 8 px. Первые шесть видны; ниже существующая текстовая кнопка «Ещё 6 фото». После нажатия следующие шесть появляются на месте, кнопка становится «Свернуть». У видео значок play. Повторяющиеся картинки — тестовые данные; картинка на видео условная, извлечение кадра ролика не реализовано этим прототипом.

Разметка превью получена **SSR настоящего `MediaTile`**, контейнер — `ThumbStrip`, действие — `TextButton`. CSS извлечён из `web/src/lib/styles/ui.css`. Внутри архивной карточки снят только внутренний отступ `ThumbStrip`, предназначенный для экрана создания записи: карточка уже имеет свои поля. Шапка архива и остальное оформление карточек из генератора сохранены. Порог шесть и текстовая кнопка — предложения, не принятые решения.

## Рендер и проверка

Настоящий HTML в headless Edge через существующий `dev/screens/cdp.mjs`. Окно **1040 × 900**, DPR 1, масштаб 100%, светлая тема, одинаково для исходного и нового кадра. Файлы `a26-card-*-desktop.png` — полные окна; `a26-card-proposal.png` и `a26-card-proposal-open.png` — снимки области самой колонки через Page.captureScreenshot, без перерисовки.

Осмотрены исходный и изменённый кадры: шапка, имя, дата, текст, поля и переносы сохранены; медиа не обрезают кнопку; после раскрытия все двенадцать видны, кнопка под сеткой. Геометрия шапки и блока автора первой записи одинакова. Все видимые плитки 88 × 88, изображения загружены, горизонтального переполнения нет. Нажатия «Ещё 6 фото» и «Свернуть» проверены в браузере. Просмотр поверх и переход к записи в этом изолированном предложении не реализованы; плитки не интерактивны.

Исходники и снимки относятся к одному коммиту, добавляющему этот каталог. SHA-256 — `sha256.json`.

## Повторение

Из корня репозитория (существующие тестовые инструменты и медиа в `dev/`):

```powershell
go run ./dev/archive-frame ./dev/archive-frame/a26-card-review dev/screens/dacha.jpg dev/archive-frame/sample.mp4
node docs/visual/build-a26-card-proposal.mjs dev/archive-frame/a26-card-review/archive/index.html
```

Затем из `dev/screens`:

```powershell
$env:CDP_PORT='9347'
$env:CDP_DIR='a26-card-review-edge'
node cdp.mjs ../../docs/testing/a26-card-proposal-2026-11-15/capture.json
```

`capture.json` содержит абсолютные file-адреса этой рабочей копии; в другой копии заменить префикс. Кадры пишутся в `dev/screens/shots/`, копии для сохранённой проверки находятся рядом с этим README. Временный выход генератора и отдельный профиль браузера после съёмки удалены.
