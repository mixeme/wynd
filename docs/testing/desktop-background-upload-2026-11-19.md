# Настольный: работа и дозагрузка при скрытом окне — 19 ноября 2026

Пункт C66 после трея: окно живёт в значке, и очередь отправки должна доходить сама. Проверка нашла три дефекта, каждый исправлен.

## Что мешало

1. **Недоступный сервер выглядел ответом API.** Прокси окна отвечал `502 Сервер не отвечает`; клиент (`isTransportError`) считает любой ответ API отказом по существу, а не сетевым сбоем — запись не вставала в очередь. Теперь `internal/desktop.Proxy` при ошибке до сервера **рвёт соединение** (hijack + close), как браузер без сети. Тест: `TestProxyAbortsWhenServerUnreachable`.
2. **Порт окна не разрешал загрузку кусками.** Загрузка шлёт и читает `Upload-Offset`, а CORS локального порта не разрешал этот заголовок и не открывал его странице: preflight проходил, а `PUT` браузер блокировал (`net::ERR_FAILED`). Добавлены `Upload-Offset` в `Access-Control-Allow-Headers` и `Upload-Offset, Upload-Length` в `Access-Control-Expose-Headers`; тест `TestCORSOnlyForWindowOrigins` проверяет оба.
3. **Очередь не повторяла сама.** Повтор запускался только внешним событием (`online`, переподключение потока, видимость). Теперь после слива планируется таймер на ближайший срок (`queueRetryDelayMs`, скрытая отправка — после `UPLOADING_STALE_MS`); прерванные отправки (`attempts=0`, но `uploading_at` есть) тоже повторяются. Экспорт `nextRetryDelay` и тесты в `queue.test.ts` (12 тестов).

Дополнительно: WebView2 скрытого окна не троттлит таймеры — `--disable-background-timer-throttling`, `--disable-backgrounding-occluded-windows`, `--disable-renderer-backgrounding` (`cmd/wynd-desktop/main.go`).
