## C18 — подгрузка старых записей

В круге 2 006 записей с фотографиями. В хронологии и «Сетке» прокрутили до конца первой порции. Firefox с телефона отправил по одному запросу с курсором из первой порции из 2 000 записей. В каждом случае сервер вернул оставшиеся шесть записей. После подгрузки в ленте видна самая старая запись.
