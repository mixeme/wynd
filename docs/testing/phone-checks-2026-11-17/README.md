# Проверки на телефоне по USB — 17 ноября 2026

Метод: телефон OPPO CPH1931 (Android 10) подключён по USB с отладкой; снимки — `adb exec-out screencap`, нажатия — `adb shell input tap`, системная «Назад» — `adb shell input keyevent 4`. Браузер — Firefox 132 (Chrome на телефоне нет; CDP недоступен, поэтому проверка чёрного ящика по снимкам). Сервер — wynd2 (0.53.0), учётная запись `a26-check@wynd.local`, круг «A26-проверка» (7 фото и ролик). Код входа — штатным режимом «код в журнал» (панель временно переводилась на `public_url=http://127.0.0.1:7676`, затем **возвращена** `https://wynd2.mixfed.ru` и проверена).

| --- | --- |
| Лента → запись → стрелка «Назад» | ✓ лента «A26-проверка» на том же месте, не список кругов |
| Лента → запись → системная «Назад» | ✓ лента, то же поведение, что у стрелки |
