## Проверка 3 (реестр 1.7): C92, год в поле периода — НАЙДЕН ДЕФЕКТ

Поиск в круге → «Период» → дата выбрана (17.11.2026): поле «с» показывает **«17.11.20…» — год обрезан**, вопреки исправлению 0.52.3. Поле «по» с пустым значением тоже теряет конец подсказки (`dd.mm.y`). Снимки: `13-period-empty.png`, `14-period-year-cut.png`, `15-period-year-cut-blur.png`.

Причина (по вёрстке): в поле даты Firefox Android оставляет свою кнопку календаря, а на текст остаётся ~105 dp — «17.11.2026» с кнопкой не помещается; в Chromium своя стрелка скрыта, поэтому там проверка проходила. Прогон приостановлен: правка CSS и проверка на этом же телефоне — после повторного подключения (adb в этот момент перестал видеть устройство).

На том же экране «Доступ» блок «Позвать на сервер» показывает адрес приглашения **по одному символу в строке** (узкая колонка ~50 px): поле не получает ширину, адрес не прочитать и не скопировать глазами (видно на `46-admin-return-to-access.png`).
