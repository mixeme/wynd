# Телефон: C97 и C99 на выпущенном клиенте 0.53.2 (2026-11-19)

Устройство: OPPO CPH1931, Android 10, Firefox 132 (PWA), экран 720×1560.
Сервер: wynd2.mixfed.ru (45.144.64.241) на 0.53.2, учётная запись
a26-check@wynd.local, круг «A26-проверка». Съёмка — `adb exec-out screencap`;
`screenrecord` на устройстве недоступен (`inaccessible or not found`), поэтому
разрешение по времени — шаг снимка 0,55–0,65 с, а не покадровое.

## Обновление клиента

Телефон держал 0.53.0 из кэша сервис-воркера (в «Настройках» подвал
«Wynd 0.53.0»). Скачанный воркер появился сам, применён вручную строкой
**«Перейти на новую версию»** — после этого подвал показывает **Wynd 0.53.2**.
Автоматическое применение «при следующем запуске» здесь не проверить: воркер
появился уже после того, как приложение закрывали.

## C97 — переход улочка ↔ круг без пустого экрана

Сценарий: список кругов → нажатие на «A26-проверка» → «Назад», дважды и после
паузы. Снимки берутся со смещением от нажатия (`(input tap …) & sleep d;
screencap`), содержимое кадра — состояние на момент начала захвата.

| Смещение | Что в кадре |
|---|---|
| 0,25 с | улочка (капчур начался раньше обработки нажатия) |
| 0,40 с | **шапка круга, вкладки, полоса «Написать в журнал…» уже на месте**; лента ещё пустая |
| 0,60 с | лента с записью и фото |
| «Назад», 0,45 с | улочка со строкой «A26-проверка» |

Итог: пустого экрана и невидимой заставки нет — новый экран встаёт шапкой, и
пустой остаётся только область ленты, которая догружается на 0,2–0,6 с. Шапка
круга на месте раньше, чем приходит сеть, — так и задумано в C97. Повтор
дважды и после паузы дал те же кадры. Снимки на этом компьютере:
`dev/screens/shots/release-0.53.2-phone-c97/` (`t0.25.png`, `t0.40.png`, `t0.60.png`,
`back0.45.png`), в git `dev/` не входит.

## C99 — холодный запуск без ожидания сети

Сценарий: `am force-stop org.mozilla.firefox` → открытие `/circles` при
скорости в статусной строке 0,25–16 КБ/с.

| Время от команды запуска | Что в кадре |
|---|---|
| 1,5 с | домашний экран телефона |
| 2,1–5,7 с | белая страница Firefox с полосой загрузки (документ ещё не отрисован) |
| 5,8 с | оболочка Wynd: фон, знак, — **строки ещё нет** |
| 6,4 с | улочка со строкой «A26-проверка» |

Итог: приложение не ждёт сети — оболочка появляется сразу, как только
отрисован документ, строка улочки — следующим кадром (≈0,5 с на этом
устройстве). Пустого белого экрана самого Wynd нет: белое время до 5,8 с —
это запуск Firefox, полоса загрузки принадлежит браузеру.

**Не подтверждено строго:** по снимкам нельзя отличить строку из снимка
IndexedDB от быстрого ответа сервера — оба варианта укладываются в кадр.
Холодный запуск совсем без сети проверить не удалось: с выключенным Wi-Fi
Firefox не отрисовал документ за 7 с (тест прерван, сеть включена обратно).
Числа «снимок вместо сети» остаются из стенда с задержкой API 150 мс —
[протокол C99](c99-cold-start-2026-11-19.md).

## Что ещё замечено

- Время до первой строки на телефоне (≈6 с от запуска до строки) почти целиком
  принадлежит запуску Firefox на этом устройстве; сравнение с прежним клиентом
  на телефоне не делалось, поэтому ускорение C99 здесь не измерено.
- Строка «Рекомендуем Chrome или Vivaldi» на улочке — прежняя подсказка, не
  относится к проверке.
