# Проверки на телефонах — 4 ноября 2026

## C75 — скачивание архива на iPhone: сбой

По инструкции владелец открыл Wynd через иконку на экране «Домой» и нажал скачивание своего архива. Результат: скачивание не началось, остался тот же экран, окно браузера не открылось. Модель iPhone и версия iOS не сообщены.

Проверены журнал HTTP на сервере и клиентский путь скачивания. В двух последних попытках (23:59:44 3 ноября и 00:00:40 4 ноября по Москве) POST выдачи ссылки завершился HTTP 200; последующего GET одноразового архива в журнале нет. Одноразовые токены в отчёт и вывод проверки не включались. На сервере работает 0.48.1.

Код открывал `_blank` после получения ссылки через сеть. Рабочая причина — потеря активации нажатия перед открытием окна; [описание механизма WebKit](https://webkit.org/blog/13862/the-user-activation-api/). Без инструментирования телефона конкретное решение блокировщика не подтверждено. Изменение подготовлено в main (`a6a1943a`), ещё не выпущено: окно открывается при нажатии, до запроса ссылки и асинхронной подготовки ключа; `opener` сразу обнуляется; ссылка передаётся после ответа. При ошибке окно закрывается; блокировка передаётся существующему обработчику ошибок. Если пользователь сам закрыл окно до получения ссылки, новое не открывается. Прошли 24 целевые проверки, Svelte check без ошибок/предупреждений, UI-сторож и целевой lint. Само поведение iPhone после исправления пока не проверено.

После выпуска нужна повторная проверка на iPhone: обычное скачивание и возврат, повторные нажатия/занятость, отказ запроса и закрытие окна. Для полного архива — готовый файл и «Скачать сразу», включая подготовку ключа. Компонентные тесты не являются подтверждением работы iPhone.
