# Первый кадр = конечный экран по высоте — три экрана (C125, 2026-11-24)

Продолжение C125. Настройки круга после возврата из «Архива» уже не едут
([протокол](settings-return-scroll-2026-11-23.md)); здесь — тот же класс на
экранах, где блок появлялся позже и вставал *над* уже показанным содержимым.
Владелец посмотрел состояния до/после на стенде `dev/scrollfix-run` (в git не
входит) и выбрал: «Пригласить» и «Присоединиться» — задерживать до ответа,
«Уведомления» — первый кадр целиком из снимка.

## Что изменено

- **«Пригласить в круг».** Ссылка создаётся запросом при открытии; до неё экран
  показывал чипы и подсказку, а затем QR (168 px) и карточка ссылки вставали над
  ними — подсказка уезжала на 184 px. Теперь до готовности ссылки (и списка
  кандидатов) — `Loading`; первый кадр с содержимым сразу полный. Побочно: в
  момент создания первой ссылки нажатия на чипы больше не теряются
  (`createLink` выходил при `creating`, а чип уже подсвечивался).
- **«Уведомления».** До ответа списка участников `soloCircle` был `false`, и в
  круге из одного участника строки «Новые записи», «Все комментарии», «Реакции»
  исчезали через ~0,2 с (сдвиг 50 px у строки «Комментарии к моим записям»).
  Теперь первый кадр берётся из снимка семейства настроек (участники и prefs уже
  в нём после C125); после сохранения снимок обновляется
  (`cacheNotifyPrefs`). Нет полного снимка — `Loading` до ответа.
- **«Присоединиться»** (по ссылке и с ожидающим входом). Заголовок «Круг
  отделён…» и полоса «Кто уже здесь» появлялись над формой после ответов.
  Теперь до ответа о приглашении — `Loading`; ошибка приглашения тоже приходит
  до первого кадра. Без приглашения (обычный вход) поведение прежнее.

Не тронуто: «Кто вы в этом круге» (сдвиг ~24 px от строки «убрать фото» у края),
«Встреча» (имя сервера заполняется внутри уже нарисованной плашки, высота та же).

## Метод

Стенд — `dev/scrollfix-run/` (в git не входит). Сервер из текущего дерева,
клиент вшит; прокси на 7879 → 7878 держит на 2,5 с ответы, из-за которых раньше
дорисовывался верх: `/invite_candidates`, POST `/circles/<id>/invites`,
`/members`, `/blobs/*`. Headless Edge 412×915 DPR 2, обход service worker.
Запись включается **до** скриптов приложения (`Page.addScriptToEvaluateOnNewDocument`)
и каждый кадр пишет: высоту `.form-body`, наличие QR, строки «Новые записи»,
кнопки «Войти в круг», текста «Добро пожаловать / Кто уже здесь». Первым кадром
с содержимым считается кадр, где появился опорный элемент экрана; дальше
сравниваются высота и состав.

## Результат

| Экран | Первый кадр с содержимым | Дальше | Итог |
| --- | --- | --- | --- |
| «Пригласить в круг» | QR уже есть | высота не меняется | PASS |
| «Уведомления» (круг из одного) | «Новые записи» уже нет | высота не меняется | PASS |
| «Присоединиться» | «Кто уже здесь» уже есть | высота не меняется | PASS |

Компонентные сторожа — `web/src/lib/circles/first-frame.svelte.test.ts`:
«Пригласить» до ссылки не показывает чипов и карточки; «Уведомления» рисует
строки из снимка, пока сеть не ответила.

## Что осталось

Повтор на телефоне после выпуска сервера: открыть «Пригласить» — QR и карточка
сразу, без скачка; «Уведомления» в круге из одного — без исчезающих строк;
«Присоединиться» по ссылке — заголовок и люди сразу. Строка — реестр проверок,
§10 (C125).
