`selfupdate.go` предлагает выпуск только через **72 часа** после публикации. 0.4.1 опубликован **2026-11-06 20:16:11 UTC**, значит полоса обновления появится не раньше **2026-11-09 20:16:11 UTC** (23:16 МСК). До этого проверка невозможна — это не ошибка.

- скрипт сам отказывается запускаться раньше 23:16 МСК 9 ноября, чтобы не получить ложный вывод;
- после обновления ожидаемый SHA-256 нового exe — `6989d29f758023c92a8bc410f4941ddd3be6a258b6467bdc24128877ac0e0d48`.
