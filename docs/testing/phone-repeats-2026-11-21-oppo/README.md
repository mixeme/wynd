# Повтор проверок Wynd на OPPO, 21 ноября 2026

OPPO CPH1931, Android 10, Firefox 132.0, портрет, светлая тема. Wynd 0.53.4
собран из `0046e808` и запущен на изолированном сервере с тестовыми учётными
записями и кругами по USB через `adb reverse`. Снимки телефона получены
через `adb exec-out screencap -p`, 720 × 1600 px.

## C104. Поиск по прямому адресу

**Пройдено.** Прогрели список кругов обычным входом. До начала проверки
целевая «Сводка 02» в этой вкладке отдельно не открывалась. Через Android
`ACTION_VIEW` открыли Firefox на прямом адресе общего поиска с
`q=opal`, обеими датами 21.11.2026, `photo=1` и `circle=<id>`.
[В общем поиске](c104-global.png) видны два совпадения в разных кругах.

Нажали «Этот круг». Прокси задержал ответы списка кругов и сведений
о целевом круге на 9 секунд. Уже на [снимке к 2,65 с](c104-early.png)
видны шапка поиска, запрос, выбранные «Этот круг», «Период» и «С фото»,
обе даты и одна запись с миниатюрой. [К 5,35 с](c104-held.png) вид тот же.
Ответы списка и круга ушли к 11,06 и 11,29 с. После них
[результат остался на экране](c104-late.png). Время от команды касания
включает задержку ADB и сохранение снимка. Кадры подтверждают показ
поиска до ответа сведений о круге. [Тайминг прокси и снимков](c104-timing.json).

## C110. Возврат из формы имени

**Пройден возврат к ожидающим приглашениям. Открыт возврат на страницу-источник прямой ссылки.**
С действующей тестовой сессией открыли два одноразовых приглашения
из отдельных страниц-источников вне Wynd в тех же вкладках Firefox.
[Источник первой ссылки](c110-source-a.png). Wynd принял каждое приглашение
до заполнения имени.

| Как открыли форму | Чем вернулись | Форма | Фактический экран после возврата |
| --- | --- | --- | --- |
| Прямая одноразовая ссылка A | Системная «Назад» | [Имя в круге A](c110-direct-system-form.png) | [Список кругов, приглашение A](c110-direct-system-back.png) |
| Прямая одноразовая ссылка B | Стрелка Wynd | [Имя в круге B](c110-direct-arrow-form.png) | [Список кругов, приглашения A и B](c110-direct-arrow-back.png) |
| Приглашение A из списка кругов | Системная «Назад» | [Имя в круге A](c110-list-system-form.png) | [Тот же список с приглашением A](c110-list-system-back.png) |
| Приглашение B из списка кругов | Стрелка Wynd | [Имя в круге B](c110-list-arrow-form.png) | [Тот же список с приглашением B](c110-list-arrow-back.png) |

На всех четырёх итоговых кадрах открыт список кругов со строкой
«Вас позвали — выберите имя». Экран «Приглашение не действует»,
который ранее открывался по «Назад», на итоговых кадрах не появился.
После прямой ссылки обе кнопки вели в `/circles`. Переход к странице,
с которой открыли ссылку, остаётся открытой частью C110 по плану 46.
В обоих случаях сервер показал ожидающее вступление, проверка уже
использованной одноразовой ссылки вернула HTTP 400. [Проверка API](c110-api.json).
