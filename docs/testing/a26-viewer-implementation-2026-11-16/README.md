# A26: реализация сетки превью и просмотра поверх — 16 ноября 2026

Реализация принятых кадров в рабочем генераторе `internal/archive` (карточка — [a26-card-proposal-2026-11-15](../a26-card-proposal-2026-11-15/README.md), просмотр — [a26-viewer-proposal-2026-11-15](../a26-viewer-proposal-2026-11-15/README.md)). Приёмки 15 и 16 ноября остаются в силе; этот протокол — проверка, что реализация им соответствует, а не новое согласование.

## Что сделано

- **Карточка записи.** Фото и ролики записи — одной сеткой `.thumbs`: плитки 88 × 88, зазор 8, радиус 8; первые шесть видны, остальные в `.extra` за текстовой кнопкой «Ещё N фото» / «Ещё N видео» / «Ещё N вложений» (смешанные), раскрытие на месте и «Свернуть». У ролика — кадр обложки (`video_poster_blob_id`, файл уже лежал в архиве) и значок воспроизведения; без обложки браузер показывает первый кадр ролика. Звук и файлы остаются строками и карточками, как были.
- **Просмотр поверх.** Тёмная оболочка `.lb` на всё окно: крестик и счётчик слева, скачивание справа, фото целиком без обрезки, стрелки по краям, точки и подпись «автор · дата и время UTC · W × H». Видео — с нативным управлением без автозапуска, с обложкой; останавливается при смене вложения и закрытии. Escape/крестик возвращают к исходной плитке с фокусом и прежней прокруткой. Листание — внутри записи.
- **Путь «лента → запись».** В ленте шапка карточки (аватар, имя, дата) — ссылка на `posts/<ID>.html`; на самой странице записи шапка не ссылка.
- **Офлайн без JS.** Плитка — `<a>` на сам файл (архив читается без скриптов); спрятанные плитки раскрывает `<noscript>`; «Ещё N» и просмотр — улучшение поверх.

## Границы проверки

Проверялся настольный браузер (Edge) через `file://`; телефон, Safari/Firefox и настоящие архивы с разных серверов этим протоколом не проверены. Порог «шесть» и тексты кнопки приняты на кадрах; для не-фото вложений текст сложен по правилам числительных («Ещё 3 видео», «Ещё 2 вложения»). Извлечение постера из ролика на сервере не добавлялось — используется обложка, которую приложение сняло при загрузке; без неё браузер показывает первый кадр.
