## Приглашение участника в оживлённый круг

23 ноября, 00:38–00:44. На экране итога оживлённой «Дачи» строка «Приглашения не отправлены» открыла «Участники» («В КРУГЕ · 1», кнопка «Пригласить»). «Пригласить» открыл экран приглашения с QR, ссылкой `http://127.0.0.1:7676/invite/…`, «Поделиться»/«Скопировать», выбором одноразовая/многоразовая и срока (1 час/72 часа/неделя/месяц/своё). Приглашённый (bob@example.com) вошёл по ссылке: журнал круга получил «Боб вступил в круг» с 00:44, счётчик «Участники» стал «В КРУГЕ · 2».

Примечание о среде: первая попытка входа приглашённого делалась curl с кириллическим телом и записала имя битыми байтами (после полуночи shell этой сессии начал отдавать кириллицу не в UTF-8); выход и повторный вход через python-urllib дали корректное «Боб». Это артефакт стенда, не Wynd: клиент шлёт UTF-8 всегда. Правило для стенда — кириллические тела API только через python.

Наблюдение: отдельный путь к «Участникам» после завершения потока оживления не найден (только из итога оживления/переноса); из «Настроек круга» строка «Пригласить» ведёт на экран приглашения, «Назад» из него возвращает в настройки.
