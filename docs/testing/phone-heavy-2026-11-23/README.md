# Тяжёлые ветки на OPPO — большой архив и соседние

23 ноября 2026 (00:14–…). OPPO CPH1931, Android 10, отладочный APK из HEAD 22.11, источник интерфейса — «Стенд OPPO А» (`http://127.0.0.1:7676`), вход Ани. Подготовка: квота круга «Дача» поднята админ-API до 1 ГБ, в круг опубликованы три записи с файлами по 30 МБ случайных данных (не сжимаются), собран полный архив без ключа (`POST /full_archive`, `delete_circle:false`, незашифрованный — ключ архива клиентский, API допускает сборку без него), скачан по одноразовой ссылке (94 468 238 байт) и установлен на телефон через `adb push` в «Загрузки».

## Большой архив — «Читаем файл…» и оживление

В «Серверы → Принять круг → Оживить из архива» файл выбирался в DocumentsUI (кириллическое имя в `input text` не вводится, выбор — DPAD-подсветка + Enter; пикер открывается в сохранённой папке `wynd-android-export-test`, наверх — тап по крошке «Загрузить»).

- 0,4 с после выбора файла: строка **«Читаем файл…»** на экране «Принять круг» — большой файл читается не молча ([reading-file](reading-file.png)).
- ~3,6 с: файл разобран — карточка «Дача · 3 записи · 1 участник · 90 МБ», «Архив собран 23 ноября 2026 на сервере 127.0.0.1:7676. Последняя запись — 23 ноября.» ([revive-card](revive-card.png)).
- «Оживить круг» → «Загружаем круг · 0 Б из 0 Б. Не закрывайте страницу, пока круг загружается.» ([loading](loading.png)).
- Итог через ~8 с: **«Круг на месте. 3 записи, 1 имя, 90 МБ — сверено с файлом архива, ничего не потерялось.»**, строка «Приглашения не отправлены», «Открыть круг» ([revived-verified](revived-verified.png)).

Подсветка выбранного файла в пикере — [archive-picked](archive-picked.png).

Строка «Читаем файл…» подтверждена на настоящем большом файле; оживление большого архива доведено до сверки. Круг «Дача» после оживления существует параллельно с исходным (исходный не удалялся) — тестовые данные.
