## Что осталось (передача)

- **Отказ переноса/оживления при нехватке места на сервере** — на стенде не моделируется: минимальный «Предел сервера» — 1 ГБ (поле целых ГБ) или 1 % диска (~15 ГБ), это много больше любых тестовых кругов. Свидетельство серверной стороны есть от 15.11 на wynd2 (карточка `fits:false`, отказ 507, [протокол](move-scenarios-2026-11-15.md)); телефонная сторона отказа не показана.
- **«Отсечка после скачивания» (0.36.0)** — в коде это `LockCutoff`: дата отсечки подвижна владельцем, пока никто не скачал личный архив, и фиксируется первым скачиванием (`archive.go:343`). Для проверки нужен полный поток: круг со старыми записями → «Заархивировать и удалить старое» → сдвиг отсечки владельцем → скачивание личного архива → попытка сдвига после него. Отложено в отдельный сеанс: длинный сценарий, часть строк уже подтверждена в цикле C82 22.11.
- Ветка «установленного веб-приложения» для «Проверить обновления» — ждать, когда владелец заново установит PWA с действующего сервера.
