# Android · высота шапки редактора новой записи

19 ноября 2026, [план 50](../plans/50-android-wrapper.plan.md). Замечание
владельца относится к цветной шапке редактора с «Отменой», именем круга
и «Опубликовать». Принятое расположение действий задано кадрами
`docs/visual/screens.html#e4-2` (`825921cc`) и
`docs/plans/55-desktop-frames.svelte.txt#pc6` (`54ecac07`).
В действующем Настольном перенос из Проводника открывает этот же маршрут
редактора через `web/src/lib/desktop/drop.svelte.ts`. Исходный Android-кадр
после передачи медиа снят на OPPO в [сквозном прогоне](android-share-live-2026-11-19.md).

## Вариант

Для предпросмотра использован код `3f3536ad`. В копии штатного
`web/src/routes/circles/[id]/compose/+page.svelte` в `FormLayout`
передано `compact={!isEdit && !isQueue}`. В ветке `compose` общего
`web/src/lib/layouts/FormLayout.svelte` нижний отступ заголовка
равен `style:height={compact ? '4px' : '12px'}`. Это меняет высоту
цветного блока с 60 до 52 CSS px. Код предпросмотра применяется
только в отдельной копии.

## Проверка

Vite dev и Edge Headless отрисовали реальный маршрут
`/circles/88888888-8888-4888-8888-888888888888/compose` в двух
изолированных профилях с синтетической сессией и ответами API.
Репозиторный JPEG и тестовый WebM добавлены через штатный input.
Снимки получены через CDP `Page.captureScreenshot`. В обоих прогонах
viewport 360 × 728 CSS px, DPR 2, светлая тема, одинаковые тестовые
данные. Это мобильный viewport Edge. Снимки не включают системные
полосы Android.

- [Шапка 60 px](../../dev/screens/shots/android-compose-header-2026-11-19/before.png)
- [Шапка 52 px](../../dev/screens/shots/android-compose-header-2026-11-19/compact.png)

Визуально проверены шапка, обе кнопки, заголовок, поле ввода, плитки,
строка даты и панель вложений. Верх шапки и нижняя панель совпали
попиксельно. Содержимое совпало после сдвига на 16 физических пикселей.
Замеры `before.json` и `compact.json` подтверждают одинаковые размеры
и положение заголовка, кнопок и нижней панели. `check:ui` прошёл,
Svelte check показал 0 ошибок и предупреждений. Вёрстка варианта ждёт
утверждения.
