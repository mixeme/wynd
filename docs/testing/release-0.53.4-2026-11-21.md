# Выпуск 0.53.4 — поиск по мере ответов серверов; экран держит снимок при задержке (2026-11-21)

Содержание: C95 «Поиск — позже» — группы общего поиска появляются с ответом
своего сервера, миниатюры едут по одной (`47a56eaf`); кадр поиска сохраняется
при смене области (`13cb89e4`); C102 — прерванная запись завершается и
измеряет длительность файла (`2abe51a9`); C103 — волна голосового на всю
ширину строки в приложении и в читаемом архиве (`4385a2aa`, `6496e255`);
C105 — снимок настроек круга и альбома дня не прячется загрузкой и не
заменяется ошибкой офлайн (`19764847`, `d0a8f884`); C106 — «Дни» с экрана
дня открывают список дней, касание своей вкладки ведёт в её список
(`747d90d6`, `7cdbe03c`); C107 — ролик без кадра показывает себя в очереди и
редакторе (`763e682a`); C108 — холодная ссылка на запись остаётся на адресе
офлайн (`4d3c38e0`); C109 — холодный показ улочки не ждёт статус оплаты
(`301b7144`, форматирование `23e723d1`); C110 — «Назад» с формы имени не
ведёт на погашенную ссылку (`5ddc5030`); C111 — счётчик «Карты» считает
записи, а не фото с местом (`72ccf79d`); C112 — системная «Назад» закрывает
лист реакций, а не открывает его заново (`f76667a5`). Web-часть стрелки
«Назад» с экрана входа в оболочках — `b8792abd`, `bacbed95`, `22eea6d7`
(оконная часть выпущена в Настольном 0.4.2, Android — в следующем APK).
Миграций и новых настроек нет, схема базы остаётся 17. «Оператору» — в
[CHANGELOG](../CHANGELOG.md).
