# Передача: живая проверка самообновления Мастерской 0.3.1 → 0.4.1

Записано 7 ноября 2026 для следующей сессии. Проверка **ещё не выполнена**; её нельзя выполнить раньше срока из-за задержки выпуска.

## Когда проверять

**Не раньше 9 ноября 2026, 23:16 МСК** (2026-11-09 20:16:11 UTC).

В `internal/installer/selfupdate.go` стоит `UpdateDelay = 72h`; `workshop-v0.4.1` опубликован 2026-11-06 20:16:11 UTC. До этого 0.3.1 не покажет обновление — это не ошибка.

## Что уже готово

- `workshop-v0.4.1` опубликован: <https://github.com/mixeme/wynd/releases/tag/workshop-v0.4.1>.
- В выпуске `wynd-workshop.exe`, `.sha256`, `.sig`; подпись проверена открытым ключом, **signature OK**.
- SHA-256 exe 0.4.1: `6989D29F758023C92A8BC410F4941DDD3BE6A258B6467BDC24128877AC0E0D48`.
- Локальный набор: `D:\Local\Git\wynd\dev\selfupdate-check`.
  - `0.3.1\wynd-workshop.exe` — подписанный 0.3.1 с GitHub;
  - SHA-256 0.3.1: `90F9AE49D64A65E22B25CA915ED21CEE30DA8180303AE1BB369E69005EA958DC`;
  - `start-0.3.1.ps1` — запуск с временными `APPDATA`, `LOCALAPPDATA`, `USERPROFILE`; настоящий профиль не трогает;
  - `run\` — рабочая копия, которую обновляет Мастерская.
- Скрипт сам проверяет 72 часа и отказывается запускать проверку раньше срока.

**Сервер, SSH и профиль сервера не нужны.** 0.3.1 спрашивает GitHub при запуске и показывает полосу `SelfBar` на первом экране. Не нужно вводить `wynd.mixfed.ru`, root или ключ.

## Порядок проверки

```powershell
cd D:\Local\Git\wynd
powershell -ExecutionPolicy Bypass -File dev\selfupdate-check\start-0.3.1.ps1
```

1. Дождаться окна `Wynd Мастерская [0.3.1]`.
2. На первом экране должна появиться полоса о **0.4.1**.
3. Нажать **«Обновить»**, затем **«Обновить и перезапустить»**.
4. Окно 0.3.1 закроется, откроется новое с заголовком `Wynd Мастерская [0.4.1]`.
5. Проверить файлы:

```powershell
Get-FileHash dev\selfupdate-check\run\wynd-workshop.exe -Algorithm SHA256
Get-ChildItem dev\selfupdate-check\run\wynd-workshop.exe*
```

Ожидается SHA-256 `6989…0E0D48`, рядом может быть `.old` до следующего запуска; `.new` быть не должно.

## Что считать успехом

- Полоса обновления появилась без подключения к серверу.
- Подпись принята, ошибки «подпись не сошлась» нет.
- Заголовок и SHA-256 соответствуют 0.4.1.
- После повторного запуска `.old` исчез.

## Если не получилось

- **До 9 ноября 23:16** — это ожидаемо, не проверять. Не обходить задержку.
- **Полосы нет после срока** — проверить интернет до `api.github.com`, что запущен именно `dev\selfupdate-check\run\wynd-workshop.exe`, и прислать скриншот.
- **«Подпись не сошлась»** — не повторять установку, сохранить скриншот и `wynd-workshop.exe.sig` из выпуска.
- **Окно не перезапустилось** — сохранить список `run\wynd-workshop.exe*` и скриншот.

## Если локального набора нет

```powershell
New-Item -ItemType Directory dev\selfupdate-check\0.3.1 -Force
gh release download workshop-v0.3.1 -R mixeme/wynd `
  -D dev\selfupdate-check\0.3.1 -p 'wynd-workshop.exe*' --clobber
```

Скрипт и README лежат в `dev\selfupdate-check`; каталог `dev` не входит в git. Для проверки можно также скачать 0.3.1 вручную и запустить из отдельной папки, не подключаясь к серверу.

## Состояние после проверки

- 0.4.1 уже опубликован; проверка не меняет сервер и не публикует новый выпуск.
- В `main` после тега 0.4.1 есть исправления, которых нет в опубликованном exe:
  - `c152cac6` — кнопки без трёх точек, `loadingLabel` по умолчанию сохраняет название;
  - `26b6cc76` — подписи «Сохраняем…», «Собираем архив…» и т. п.;
  - `724fdc15` — окно подписи не прокручивается в начало.
