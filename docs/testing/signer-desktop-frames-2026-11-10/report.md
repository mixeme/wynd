- Окно: `cmd/wynd-signer/frontend/src/App.svelte` (рамка — `Window.svelte`, шапка — `$ui/workshop/TitleBar.svelte`), коммит `main` `70414ecd`.
- Утверждённого визуального кадра у «Подписи» нет: кадры 12а–12д в `docs/visual/installer.html` помечены черновиками и расходятся с реализованными этапами на одном экране (план 45). Поэтому основа — текущая реализация, отличия перечислены построчно.
- Кадры «до» сняты с того же `70414ecd` тем же конвейером с прежним набором выпусков (только Мастерская).

## Изменение (точный список отличий)

1. **12б — список.** Заголовок «Выпуски Мастерской» → «Выпуски». Строки получают название программы: «Мастерская {версия}» / «Wynd для компьютера {версия}». У черновика окна без подписи — действие «подписать», как у Мастерской. Остальные строки, значки, статусы и нижняя строка «Подписать файл на этом компьютере» не изменены.
2. **12в — проверка выпуска окна.** Заголовок «Мастерская {версия}» → «{программа} {версия}». Четыре этапа проверки (сведения о выпуске, сумма, удостоверение) без «Проверяем открытый ключ» и «Читаем описание выпуска». Вместо блока `whatsnew` — «Окно обновляется вручную: выпуск останется черновиком, «что нового» и публикацию делает владелец.». Уведомление «В этой сборке нет открытого ключа…» остаётся только у Мастерской. Кнопка «Подписать» (опубликовать окно программа не предлагает).
3. **12г — итог.** «Файл wynd-desktop.exe.sig выложен в черновик. Он не опубликован: «что нового» дописывает и публикует выпуск владелец.» Для Мастерской текст прежний (`whatsnew.md`).
4. **12а — ключ.** «Ключ подписи Мастерской» → «Ключ подписи Wynd». Подзаголовок: «Этим ключом подписываются выпуски Мастерской и Wynd для компьютера. Мастерская принимает обновление, только если новая версия подписана им. Ключ создаётся один раз.» Красное предупреждение внизу не тронуто (говорит только про Мастерскую) — вопрос владельцу ниже.
5. **12д — подписанный файл.** «Сам exe не изменился: Мастерская примет его только вместе с этим файлом» → «Сам exe не изменился: обновление Мастерской принимается только вместе с этим файлом» (подписывается любой exe, не только Мастерская).
6. Тексты этапов проверки, названия кнопок и уведомлений у Мастерской не менялись.

Не менялись: шапка окна, ширина 640 и высота 560, поля, шрифты, цвета, отступы, расположение действий.

## Рендер

- Конвейер: `vite` 6.4.5, страница `/mock/mock.html` — та же настоящая `App.svelte`, но `window.go.main.App` подставлен (без GitHub и ключа). Ответы повторяют выпуски `mixeme/wynd` на 2026-11-10: `workshop-v0.4.1`, `workshop-v0.3.1` опубликованы с подписью; `desktop-v0.1.1` — черновик без подписи. Для кадра «до» экрана подписи Мастерская 0.4.1 показана черновиком (`?demo=draft`) — иначе у опубликованного выпуска нет действия «подписать».
- Изменённая версия: `npx vite --host 127.0.0.1 --port 5178 --strictPort` из `cmd/wynd-signer/frontend`; исходная: тот же коммит `70414ecd` в отдельном дереве, порт 5179, `?products=workshop`.
- Снимок: Microsoft Edge `--headless=new --disable-gpu --hide-scrollbars --window-size=640,560 --virtual-time-budget=6000`, масштаб 100 %, светлая тема (единственная в окне), кадр 640×560 — размеры окна «Подписи» (`main.go`: Width 640, Height 560).
- Панель ZCode-браузера снимки перестала отдавать (таймаут подготовки поверхности), поэтому снимал headless Edge тем же адресом. Это рендер HTML/Svelte, не нативное окно Wails.
- Состояния, доведённые нажатиями: `?open=desktop-v0.1.1` нажимает «подписать» в строке выпуска; `?pass=…` вводит пароль и нажимает «Подписать»; `?file=1` проходит «Подписать файл на этом компьютере».
