## Изменение (точный список отличий)

### «Wynd Подпись»

1. **12б — список.** Заголовок «Выпуски Мастерской» → «Выпуски». Строки получают имя программы из описания в Go: «Мастерская 0.4.1», «Wynd Настольный 0.1.1». У черновика Настольного без подписи — «подписать», как у Мастерской. Остальные строки, значки, статусы и нижняя строка «Подписать файл на этом компьютере» не изменены.
2. **12в — проверка выпуска Настольного.** Заголовок «Мастерская {версия}» → «{программа} {версия}». Шесть этапов — те же, что у Мастерской: сведения о выпуске, сумма, удостоверение, **открытый ключ** (сборка Настольного вшивает общий ключ экосистемы), «Читаем описание выпуска». «Что нового — из выпуска» читается из `cmd/wynd-desktop/whatsnew.md` в теге (у Мастерской — `cmd/wynd-installer/whatsnew.md`); есть раздел — кнопка «Подписать и опубликовать», нет — «Подписать» и «выпуск подпишем, но не опубликуем».
3. **12г — итог.** Как у Мастерской: «Выпуск подписан и опубликован», «Файл wynd-desktop.exe.sig выложен в выпуск на GitHub.» Экран длиннее окна — кадр снят у нижнего края, где итог и кнопки.
4. **12а — ключ.** «Ключ подписи Мастерской» → «Ключ подписи Wynd»; подзаголовок «Выпуски программ Wynd. Программа принимает обновление, только если новая версия подписана им.»; предупреждение внизу — «уже розданные программы больше не обновить: новую версию они не примут» (было только про Мастерскую).
5. **12д — подписанный файл.** «Мастерская примет его только вместе с этим файлом» → «программа принимает обновление только вместе с этим файлом».
6. Шапка, ширина 640 и высота 560, поля, шрифты, цвета, отступы, расположение действий не менялись.

### Окно «Wynd Настольный»

7. **Полоса обновления над страницей.** Новый элемент окна: «Вышла версия 0.2.0», строки «Что нового», действия «Обновить и перезапустить», «Позже», «Что нового» (страница выпусков); при отказе подписи — «Подпись не сошлась: обновление не установлено.». Тон, шрифты и цвета — из общих токенов окна; кнопки — существующие текстовые действия, как «Другой сервер». Размер окна 760×780 не изменился.

## Осмотр

Просмотрел все двенадцать снимков. Шапка, шрифты, поля, кнопки, отступы и ширина окна «Подписи» совпадают с исходными кадрами; новых элементов компоновки нет, кроме имени программы в строках и заголовке. На 640×560 экран проверки Настольного теперь как у Мастерской — шесть этапов, «Что нового», «Подписать и опубликовать». Итог подписи длиннее окна: кадр снят у нижнего края, где итог и кнопки; строка заголовка вверху при этом прокручена — это состояние прокрутки, не обрезка вёрстки. Полоса обновления окна встаёт над страницей «Войти в Wynd», не сдвигая колонку; на 760×780 текст и действия читаются, при отказе подписи красная строка над «Что нового».

Границы: снимки доказывают вид этих рендеров в этом браузере; нативное окно Wails, системный заголовок, другие размеры и живое обновление с GitHub не проверялись. DOM-проверки и тесты геометрию не подтверждают.
