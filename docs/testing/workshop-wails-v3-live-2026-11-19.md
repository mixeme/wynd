# Мастерская на Wails v3: сборка и живая проверка — 18–19 ноября 2026

Третий и последний шаг перевода окон (план 64 §4): Мастерская переведена на `github.com/wailsapp/wails/v3@v3.1.0` в ветке `wails-v3`.

## Основа

- Оформление не менялось: оболочка, вкладки, список серверов, архивные экраны и тексты — те же, что в выпущенной 0.4.5. Утверждённая основа — [реестр кадров Мастерской](../visual/workshop.html) и [снимки реализации](../visual/reviews/workshop-implementation-2026-11-05/) (базовый кадр `baseline-s0.jpg` — 1024 × 760; окно приложения — 760 × 560, как в выпуске).
- Исходник: `cmd/wynd-workshop/{main.go,archives.go}`, `frontend/src/{api.ts,Window.svelte}`.

## Что изменено в коде

- `main.go`: `wails.Run` → `application.New` + `Services`; `OnStartup`/`OnShutdown` → `ServiceStartup`/`ServiceShutdown`; `Assets` → `application.AssetOptions{Handler: AssetFileServerFS(assets)}`; окно 760×560 (мин 680×480, `Frameless`, фон F4F0E9); `runtime.Quit`/`BrowserOpenURL`/`ClipboardSetText` → `app.Quit()`/`Browser.OpenURL`/`Clipboard.SetText`.
- `archives.go`: диалоги → `app.Dialog.OpenFileWithOptions(...).PromptForSingleSelection()` / `PromptForMultipleSelection()`; папка — `CanChooseDirectories`; «Показать в папке» — `Browser.OpenURL`.
- `frontend/src/api.ts`: мост `backend()` — при отсутствии mock зовёт `Call.ByName("main.App.<метод>")` через объект-посредник (список полусотни методов вручную не нужен); путь `window.go` сохранён для галереи и `profiles.test.mjs`.
- `frontend/src/Window.svelte`: `runtime()` — `Window`/`Application` из `@wailsio/runtime 3.1.0` (зависимость добавлена); mock-путь `window.runtime` для галереи сохранён.
- `profiles.test.mjs`: в JSDOM добавлена заглушка `fetch` — runtime v3 при загрузке проверяет необязательный `/wails/custom.js`.
- `build/windows/info.json` и `wails.exe.manifest`: конкретные значения вместо шаблонов v2 (0.4.5, «Wynd Мастерская», `com.wynd.workshop`).
- `scripts/build-workshop.bat`: путь v3 (npm, `wails3 generate syso`, `go build` с вшитым `SigningKey`); `.github/workflows/workshop.yaml` ставит `wails3@v3.1.0`.
