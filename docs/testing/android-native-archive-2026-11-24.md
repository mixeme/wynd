# Android: нативная очередь 5.4 — постоянный `.wynd` (24.11.2026)

Этап 5 плана [50](../plans/50-android-wrapper.plan.md): выбранный для
«Оживить круг» файл `.wynd` больше не теряется при перезапуске. Решение
владельца 2026-10-17: помнить файл с постоянным правом доступа, после ответа о
месте и после обрыва продолжать без повторного выбора.

## Что сделано

- **Постоянное право.** Для выбора `.wynd` системный `ACTION_OPEN_DOCUMENT`
  получает `FLAG_GRANT_PERSISTABLE_URI_PERMISSION`; `MediaChromeClient` после
  выбора вызывает `takePersistableUriPermission`. Другие файлы и фото не
  трогаются.
- **Хранилище.** `ArchiveStore` в private `SharedPreferences` хранит origin,
  URI, имя, размер и случайный токен. Файл не копируется. `status` проверяет,
  что URI ещё открывается; после перезапуска процесса право чтения остаётся.
- **Отдача странице.** Мост `__wyndArchive` (только главный фрейм выбранного
  origin) отдаёт `status`, `open` и `forget`. `open` возвращает путь
  `/__wynd_archive/<token>`; `shouldInterceptRequest` отдаёт по нему файл из
  URI (`application/octet-stream`, `no-store`) без копирования и без доступа к
  произвольным путям. Чужой/старый токен — 410.
- **Страница.** На входе в «Оживить круг» (`/settings/servers/accept`) страница
  спрашивает native; если файл есть, сама получает Blob/File и открывает его:
  зашифрованный — шаг пароля, обычный — чтение и проверка места. Явный «Назад»
  из пароля/просмотра и успешное оживление вызывают `forget`; после отказа
  файл остаётся для повтора. Пароль не сохраняется — его вводят заново.
- **Старый APK.** Без моста страница работает как раньше: файл и пароль живут
  только на экране.

## Живой прогон на OPPO

OPPO CPH1931, Android 10, debug APK из текущего дерева. В «Принять круг» →
«Оживить из архива» открыт системный выбор; выбран `A12.wynd` (115 КБ) из
«Скачанных». В private prefs появились `origin`, `uri`
(`content://…/Download/A12.wynd`), `name`, `size` и `token`; страница показала
шаг пароля с файлом.

Приложение полностью остановлено (`am force-stop`) и запущено снова; страница
`/settings/servers/accept` открыта заново — **без системного выбора** она сама
получила тот же `A12.wynd` через `/__wynd_archive/<token>` и показала шаг
пароля. `forget` через мост очистил prefs (`<map />`). Это проверяет
постоянное право, отдачу файла и авто-восстановление после смерти процесса.

**Границы:** пароль не сохраняется; восстанавливается файл, а не состояние
серверной заявки на место — после восстановления страница заново спрашивает
место. Живой прогон шёл через системный выбор и страницу, но навигация на
`accept` — CDP; на телефоне системные нажатия в DocumentsUI сработали только
с клавиатуры (TAB/ENTER), тапы не выбирали файл — грабля стенда. Старый APK
без моста и браузер не затронуты.
