# Стрелка «Назад» с экрана входа — живая проверка черновика 0.4.4 (23.11.2026)

Проверка исправления, из-за которого в установленном Настольном 0.4.1 стрелка
на экране входа видна, но не работает (`wynd:return-to-address` понимает только
оболочка с 0.4.2). Реестр — [§7](../pending-device-checks.md#7-рядом--не-телефон).

## Что проверялось

- Черновик **Настольного 0.4.4** — `dev/release-0.4.4/wynd-desktop.exe`,
  17 691 136 байт, SHA-256
  `7d43821d2019a340302add112b53cf3a1cc0254b1f8ee0fe33577fce3770c573`
  (совпадает с CI-черновиком `desktop-v0.4.4`).
- Сервер — локальный стенд 0.53.5 `127.0.0.1:7682`, учётка не входила:
  проверялся только возврат с экрана входа.
- Профиль окна изолирован, без сохранённых серверов — окно открылось на
  «Войти в Wynd».

## Сценарий

1. В поле «Адрес сервера или приглашение» введён `http://127.0.0.1:7682`,
   нажато «Дальше». Окно проверило сервер и открыло его экран входа
   («Дом Ани», «Войти», поле «Почта»).
2. В дереве доступности найден BackBar — кнопка `Назад` (accessible name
   «Назад»), нажата через `InvokePattern`.
3. Окно вернулось на собственный экран «Войти в Wynd»; в поле адреса осталось
   `127.0.0.1:7682` (без схемы — так оболочка хранит адрес).
4. Повторено дважды: `Назад` → адрес на месте.

## Свидетельства

- `login-with-back.png` — экран входа сервера, стрелка «Назад» в левом верхнем
  углу (620×780, настоящий PrintWindow WebView2).
- `address-after-back.png` — экран оболочки после нажатия: «Войти в Wynd»,
  поле с `127.0.0.1:7682`.
- Вывод UIA: `back=Назад`, `address-field=127.0.0.1:7682`.
- SHA-256 кадров: `login-with-back.png` — `ba08a575…`, `address-after-back.png` —
  `fcc1c2b5…`.

## Что не проверялось

- Установленный у владельца 0.4.1: стрелка там по-прежнему мертва до установки
  0.4.3/0.4.4 — это обновление, а не код.
- Самообновление до 0.4.3/0.4.4 — не раньше 26.11 (72 ч после публикации).
- Физический щелчок мышью: кнопка нажата через `InvokePattern` дерева
  доступности, обработчик тот же.

## Уборка

Окно и стенд остановлены; временная запись схемы `wynd:` удалена (приложение
создаёт её при следующем запуске); `IconUri` уведомлений возвращён на реальный
профиль `%APPDATA%\Wynd\desktop\toast-icon.png`; вход не выполнялся, записей
`Wynd.Desktop` в Credential Manager не появилось.
