`Spec.TestCert` — это **staging Let's Encrypt** с пропуском проверки TLS на шаге «Проверка» (комментарий в install.go): настоящий ACME-путь с проверкой владения доменом, но без боевых лимитов выпуска.

## 2. Отказ сертификата при закрытых портах (план 45)

Порты 80/443 закрыты для контейнерного трафика правилом в `DOCKER-USER` (трафик к контейнерам идёт через FORWARD/DOCKER-USER, правила `INPUT` на Docker-порты не действуют — первая попытка через `INPUT` прошла мимо, сертификат выдался). Установка в `/srv/wynd-nocert2` с TestCert:

- **«Сертификат» — failed**, экран: **«Сертификат не выдали»** — «Let's Encrypt не смог зайти на wynd2.mixfed.ru по порту 80, или сайт не открывается снаружи. Чаще всего порты 80 и 443 закрыты в панели хостинга (брандмауэр). Откройте входящие порты 80 и 443 и нажмите „Повторить“.» В журнале шага — логи Caddy с попытками ACME.
- Ветка восстановления: правила сняты, «Повторить» (повторный прогон установки) — сертификат выдан, проверка прошла, сайт 200.

## 3. Несинхронные часы и исправление (план 45)

`timedatectl set-ntp false`, время сдвинуто на +25 минут:

- Осмотр: **«Часы сервера расходятся с вашими на 24 мин — настроим синхронизацию времени»** (note с планом действия).
- Установка с исправлением часов: первый шаг **«Синхронизация часов»** — `apt-get install systemd-timesyncd; timedatectl set-ntp true`; время вернулось, установка прошла целиком, сайт 200.

## 5. Wynd за найденным nginx: conf.d, чужой certbot, чужой сертификат, замер (план 45, [61]/[65])

nginx с раскладкой **conf.d** (sites-enabled отключён в nginx.conf), certbot 4.0.0, настоящий сертификат Let's Encrypt для wynd2.mixfed.ru выпущен certbot'ом:

- Установка Wynd за nginx (`Spec.Proxy=nginx`): шаги docker/place/image/files/start/**«Сайт в nginx»**/cert/check — все done.
- Файл сайта — `/etc/nginx/conf.d/wynd-wynd2.mixfed.ru.conf`: слушает 80 и 443 ssl, **переиспользует чужой сертификат** (`/etc/letsencrypt/live/...`), проксирует на `127.0.0.1:7676`; контейнер Wynd публикует порт только на loopback.
- Проверка шагом «Проверка» прошла с настоящей проверкой TLS (без TestCert): сайт 200, сертификат валиден.
- **Замер: 13 секунд** от начала до «Проверка» при уже скачанном образе (докачка образа из ghcr на этой машине добавляет ≈1 минуту — замер в п. 1). Отдельно сборка на слабом сервере замерена 7–8.11 (установка ≈12–13 мин, обновление ≈16 мин).

## Что осталось по живым проверкам

- **Переезд установки (9а–9г)** и его ветки «только данные за чужим прокси» и «свой Caddy с DNS/сертификатом» — нужны две машины (два профиля окна; ядро гоняет переезд через Wizard-слой с резервированием концов).
- **Сервер с AAAA** — текущий шаблон nginx слушает IPv4; нужна машина с AAAA-записью (правка DNS за владельцем).
- Certbot Stale после удаления с сохранением данных — пояснение и состояние Stale, когда прокси не перечитал настройку (нужен прокси-стенд nginx+certbot, сохраняющийся между прогонами).
