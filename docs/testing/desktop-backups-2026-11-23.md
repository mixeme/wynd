# Настольный: копии архивов по расписанию — 23 ноября 2026

Функция 7 плана [66](../plans/66-desktop-functions.plan.md): окно само собирает архивы кругов в выбранную папку и держит их число или срок. Сборку ведёт Go-часть оболочки, пока приложение запущено, — окно можно закрыть в значок.

## Приёмка экранов (владелец, 23.11)

- **Экран «Копии по расписанию»** — принят после правок: переключатель включения сверху («Сохранять копии по расписанию»), ниже применимы папка (поле + «Открыть» / «Выбрать…» справа от поля), частота (чипы «Каждый день / Каждую неделю / Каждый месяц / Свой интервал» с полем дней), хранение (число + чипы «последних / дней», подсказка со следствием), строка «Последняя копия», главная кнопка «Сохранить». Кадр — [screen.png](desktop-backups-2026-11-23/screen.png).
- **Строка входа «Копии по расписанию»** в «Настройки → Приложение» — принята после правок: **своя секция «Копии»** (не в «Запуске»), строки отделены заголовками секций, **пояснения секций перенесены под их заголовки** («При входе в Windows откроется Wynd.», «Для новых кругов и тех, где настройки уведомлений не менялись.») с отступом до первой строки; строка видна только в окне (мост есть). Кадр — [settings-row.png](desktop-backups-2026-11-23/settings-row.png).

## Механизм

- **Настройки** — `backups.json` в `%AppData%\Wynd\desktop`: включено, папка, расписание (день/неделя/календарный месяц/свой интервал в днях), хранение (число последних или срок в днях), последняя копия. Значения проверяются (`NormalizeBackupConfig`): неизвестное расписание, пустая папка при включённых копиях, крайние значения — отказ с текстом на экране, а не молчаливая подмена.
- **Сборка** (`internal/desktop/backups.go`): раз в полчаса (первая проверка через 30 с) окно сверяет срок и, если пора, для выбранного сервера берёт круги (`GET /circles`) и архив участника (`GET /archive/download`, тот же, что «Скачать архив», — с докачкой Range) токеном из Credential Manager, пишет `«<круг> ГГГГ-ММ-ДД.zip»` во временный файл и переименовывает. Повторная копия в тот же день не перезаписывает старую (« (2)»). Сбой одного круга не отменяет остальные.
- **Хранение**: по количеству — остаются N новейших на каждый круг; по сроку — удаляются старше N дней. Удаляются только свои файлы (имя совпало с шаблоном); чужие файлы в папке не трогаются.
- **Сервер** — выбранный в окне; токены — из системного хранилища (функция 3). Без сохранённой сессии сборка пропускается с записью в журнал.

## Тесты

`go test ./internal/desktop`: нормализация формы (все отказы), сроки расписания (день/неделя/календарный месяц/свой интервал/выключено), имена файлов (санитизация, пустое имя, суффикс при занятом), ротация по количеству и по сроку (чужие файлы не трогаются), полный прогон `RunBackupOnce` на httptest-сервере (токен в заголовке, два круга, байты совпадают, повтор в тот же день даёт « (2)»). Ворота web и desktop-контуров — зелёные.

## Границы и живая проверка

- Живой сборки на настоящем сервере в этой сессии не было (создала бы копии всех кругов владельца): механизм покрыт полным прогоном на httptest. **Проверка владельцем — реестр §7:** включить копии, выбрать папку, дождаться первой копии; проверить, что она собирается и при закрытом в окно значке.
- Полный архив круга (с шифрованием) — не копируется: у него одноразовая ссылка, копируется архив участника — как ручное «Скачать архив».
