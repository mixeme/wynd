# Проверки видео и фото на OPPO, 21 ноября 2026

OPPO CPH1931, Android 10 (API 29). Веб и локальный сервер Wynd 0.53.4
собраны из `807ba203` и доступны по USB через `adb reverse`. Для прогонов
созданы отдельные тестовые круги. Снимки сняты с телефона через
`adb exec-out screencap -p` (720 × 1600, портрет, светлая тема).

## C107. Кадры WebM и MP4 в офлайн-очереди

**Пройдено в Firefox 132.0.** В круге «Видео OPPO» добавили WebM (VP8,
8 секунд) через «Фото и видео» → «Файлы» и MP4 (H.264, 15 секунд)
из [альбома Movies в приложении OPPO «Фотоснимки»](fx-gallery-movies.png).
Оба кадра были видны [в редакторе](fx-both-ready.png) до публикации.

| Прогон | Карточка без сети | После возврата сети |
| --- | --- | --- |
| WebM и MP4 | [Кадр WebM, длительность 0:08, два вложения](c107-queued.png) | [Одна запись с обоими роликами](c107-result.json) |
| MP4 отдельной записью | [Кадр MP4, длительность 0:15](c107-mp4-queued.png) | [Одна запись с MP4](c107-mp4-result.json) |

В каждом прогоне выключили Wi-Fi и мобильные данные и перекрыли доступ к API
через USB на время постановки в очередь. Записи с контрольными подписями
отсутствовали на сервере до восстановления сети. После возврата сети
каждая запись опубликовалась автоматически. Журнал локального прокси показал
по одному успешному POST публикации на прогон.

Локальный сервер работал без ffmpeg. В первом прогоне сервер сохранил оба
видеофайла без постеров. После публикации на плитке WebM
[появилась заглушка](c107-published-settled.png). Кадры в редакторе и
офлайн-очереди подтверждены отдельно для обоих форматов.
