# Проверки Wynd 0.53.3 на OPPO, 20 ноября 2026

OPPO CPH1931, Android 10, Firefox 132, USB. Снимки окна получены через
`adb exec-out screencap -p` (720 × 1600 px, светлая тема, DPR 2). Для прогона
на wynd2 использован тестовый круг «A26-проверка». Firefox предлагал
обновление с 0.53.2. После действия «Перейти на новую версию» в настройках
показана [0.53.3](version.png). [Протокол выпуска](../release-0.53.3-2026-11-20.md).

## C92. Дата в полях периода

**Пройдено на выпущенном клиенте 0.53.3.** В поиске круга раскрыли «Период».
В [пустых полях](c92-empty.png) видны «с» и «по», значки календаря и стрелки.
Касание значка открывает [системный календарь Firefox](c92-picker.png).
После выбора 20 ноября 2026 года в обоих полях [дата видна целиком](c92-dated.png),
в том числе в поле «по» в фокусе. Обе подписи уступили место датам.
Геометрию полей и иконок сверили с [принятыми кадрами](../c92-date-range-2026-11-20/README.md).
Касание текстовой области пустого поля и смена области поиска остаются
отдельным прогоном с `13cb89e4` по [§9 реестра](../pending-device-checks.md#9-проверки-после-android-сессии-20-ноября).

## C96/C101. «Доступ» в панели

**Пройдено на OPPO с релизным кодом 0.53.3.** Панель открыта в Firefox на
изолированном сервере, собранном из `v0.53.3` (`03e0e498`). Клиент вшит
в бинарник, `/api/v1/instance` сообщил `0.53.3`. Доступ к стенду на петле
компьютера дан через `adb reverse`, использованы временная база и приглашение.

- После входа непосредственно в `/admin/access` открыт раздел «Доступ».
- Вверху страницы блоки расположены один под другим. Адрес приглашения
  виден целиком, переносится строками и читается рядом со «Скопировать».
  [Кадр до прокрутки](admin-top.png).
- Свайпом открыты раздел «Живые», его действия и QR. Полоса разделов и
  активная вкладка «Доступ» остались сверху, на той же высоте.
  [Кадр после прокрутки](admin-bottom.png).

## C100. Переходы в круге без сети

**Частичный результат на выпущенном клиенте 0.53.3.** В Firefox открыли
заполненные экраны «A26-проверки» на выданном клиенте wynd2, вернулись в ленту,
отключили Wi-Fi и мобильные данные и повторили переходы. ADB подтвердил
`Active default network: none`. После прогона обе настройки возвращены,
сеть снова стала доступна. Снимки завершались через 1,5–2,0 с после запуска
команды тапа, включая передачу PNG по USB. Они подтверждают, что содержимое
доступно без успешного ответа сервера. Для оценки первого кадра при ожидающем
запросе нужен отдельный прогон с задержанным API.

| Переход | Что видно офлайн |
| --- | --- |
| Лента → [«Сетка»](c100-grid-offline.png) | Две сохранённые плитки и итог «2 записи с фото и видео из 2 записи». |
| «Сетка» → [альбом записи](c100-post-album-offline.png) | Семь фотографий, имя и дата публикации, действие «К записи». |
| «Сетка» → [«Дни»](c100-days-offline.png) → [16 ноября](c100-day-offline.png) | Карточка дня с числом записей, затем обложка дня и первая запись. |
| День → [альбом дня](c100-day-album-offline.png) | Дата, девять плиток и отметка выбранной обложки. |
| День → [«Карта»](c100-map-offline.png) | Видно «0 записей с местом из 2 записей» под запросом Firefox о геопозиции. В тестовом круге нет записей с точками. |
| Загруженный поиск «С фото» → [запись](c100-search-post-offline.png) | После отключения сети открылись обсуждение, текст «Семь снимков за день», автор и миниатюра. |
| Лента → [настройки круга](c105-settings-offline-repeat.png) | Вместо прогретой формы — «Не удалось выполнить запрос». См. C105 ниже. |

Открыты проверки с точками на карте, откликами, «Поделиться» через Android,
переходом из ссылки и уведомления, обновлением живых счётчиков и первым
кадром при задержанном API.

### C105. Настройки круга скрывают прогретую форму офлайн

**Воспроизведено дважды.** В [онлайн-настройках](c105-settings-online.png)
видны имя, цвет, окно правок и параметры приглашений. Вернулись в ленту,
отключили обе сети и снова открыли настройки тем же способом через имя
и аватар. [Снимок после отключения](c105-settings-offline-repeat.png) показывает
только шапку и ошибку. Ожидание по C100 — показать сохранённые поля и
участников, обновить приглашения и квоту при получении ответа.
