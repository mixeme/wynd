# Проверки Wynd 0.53.3 на OPPO, 20 ноября 2026

OPPO CPH1931, Android 10, Firefox 132, USB. Снимки окна получены через
`adb exec-out screencap -p` (720 × 1600 px, светлая тема, DPR 2). Для прогона
на wynd2 использован тестовый круг «A26-проверка». Firefox предлагал
обновление с 0.53.2. После действия «Перейти на новую версию» в настройках
показана [0.53.3](version.png). [Протокол выпуска](../release-0.53.3-2026-11-20.md).

## C92. Дата в полях периода

**Пройдено на выпущенном клиенте 0.53.3.** В поиске круга раскрыли «Период».
В [пустых полях](c92-empty.png) видны «с» и «по», значки календаря и стрелки.
Касание значка открывает [системный календарь Firefox](c92-picker.png).
После выбора 20 ноября 2026 года в обоих полях [дата видна целиком](c92-dated.png),
в том числе в поле «по» в фокусе. Обе подписи уступили место датам.
Геометрию полей и иконок сверили с [принятыми кадрами](../c92-date-range-2026-11-20/README.md).
Касание текстовой области пустого поля и смена области поиска остаются
отдельным прогоном с `13cb89e4` по [§9 реестра](../pending-device-checks.md#9-проверки-после-android-сессии-20-ноября).
