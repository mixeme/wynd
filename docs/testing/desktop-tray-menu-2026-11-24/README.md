# Меню трея в стиле рамки — 23–24.11.2026

**Принято владельцем 24.11.2026 («Да»).** Замена нативного меню значка в трее:
пункты были шире текста из-за колонки отметок и резерва под стрелки, которые
Windows оставляет даже в меню из двух строк.

Оба — PrintWindow настоящего меню, не эскизы. `before.png` — SHA-256
`c941e369…`, `menu.png` — `7953b70c…`.

## Что сделано

- Меню — отдельное маленькое окно Wails (`/?tray-menu=1`), без системного
  заголовка и без записи в панели задач. Стиль — токены рамки: бумага
  `--paper`, чернила `--ink`, шрифт Golos 13.5 px, тонкая рамка `#cfc5b8`;
  строки 24 px, разделитель 1 px, ширина 92 px по тексту «Открыть».
- Пункты «Открыть» и «Выход»: первый показывает главное окно, второй
  завершает программу. Закрытие — по Esc, выбору пункта или потере фокуса.
- Окно прогревается при старте скрытым (1×1 за краем экрана) и затем
  прячется: первое создание WebView2 занимает секунды, а правый щелчок
  должен показывать меню сразу. На показе размер возвращается к 92 × 56.

## Проверки

- Кадр `menu.png` снят PrintWindow с работающего exe; в дереве доступности
  окно видно как `Menu` с пунктами `Открыть` и `Выход`.
- Через доступность нажаты оба пункта: «Открыть» показал главное окно
  (`Wynd [0.4.4]`), «Выход» завершил процесс.
- Ворота: `scripts\test-desktop.bat` — `[desktop] OK`, `svelte-check` —
  0 ошибок и предупреждений.

## Границы

- Физический правый щелчок по значку в этой среде не воспроизводится
  (синтетический ввод не двигает курсор); показ меню проверен вызовом того же
  пути, что и правый щелчок. Сам щелчок и «Выход» живой рукой — за владельцем,
  реестр §7.
- В черновике **0.4.4** (сборка 23.11) ещё нативное меню: правка уходит в
  следующий выпуск Настольного.

## Уборка

Тестовые окна остановлены; временная запись схемы `wynd:` удалена; `IconUri`
уведомлений возвращён на реальный профиль; данные сервера не использовались.
