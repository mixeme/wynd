# OPPO · перенос и архивы · 22.11.2026

OPPO CPH1931, Android 10, Firefox 132.0, 720 × 1600. Два локальных стенда с Wynd 0.53.4 из коммита `9aa34258`. Проверки проходили под отдельными тестовыми учётками. Кадры сняты с телефона через ADB.

## A9 — приглашение и отказ

Владелец отделил круг и позвал одного участника через API стенда. На OPPO участник открыл приглашение из списка кругов. На карточке указаны исходный круг и имя пригласившего. Участник нажал «Отказаться» и подтвердил отказ. Приглашение исчезло из списка. На сервере исходный круг сохранил статус `active`, отделённый получил статус `gone` для этой учётки, список ожидающих приглашений больше не содержит его ID.

## Перенос большого круга

Три записи с файлами, 35 211 515 байт исходных данных. Приёмник дошёл до 33 554 432 байт (32 МиБ), после чего стенд удерживал остаток загрузки. Принудительно закрыли Firefox и снова открыли экран приёма. Wynd показал текущий ход на прежней отметке. Снова закрыли Firefox, отпустили остаток и дождались статуса завершения по API, пока браузер был закрыт. Приёмник подтвердил сверку и вернул три записи в ленте нового круга.

При повторном входе на обычный экран приёма уже завершённого переноса открылось поле для ссылки. Экран итогов показал «Круг на месте» при прямом открытии адреса результата. Передача завершилась, автоматический показ итога при таком повторном входе остаётся открытым.
