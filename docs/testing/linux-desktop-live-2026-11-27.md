## Найдено и исправлено в прогоне

- **C150. Холодный запуск по ссылке приглашения ронял окно.** Оболочка
  переставляет адрес iframe, WebKit отменяет начатый ответ, `ReverseProxy`
  зовёт `ErrorHandler`; тот при писателе без `http.Hijacker` паниковал
  `http.ErrAbortHandler`, а asset-сервер Wails v3 панику в горутине не
  перехватывает — процесс умирал. Тем же путём шёл недоступный сервер.
  Исправлено `605c90be`: ушедший клиент — тихий выход, недоступный сервер
  без Hijack — недоданное тело (`Content-Length: 1`, ноль байт), WebKit
  даёт сетевой сбой. Тесты `TestProxyAbortsWithoutHijacker`,
  `TestProxyCanceledRequestDoesNotAbort`. На этой же машине: до фикса —
  `panic: net/http: abort Handler` и закрытие окна, после — экран
  приглашения и живой процесс.
- **C149 (проверка исправления).** Автозапуск и запись сервера через
  `window.parent.go` на этой сборке работают: строка «ЗАПУСК» видна,
  переключатель создаёт и удаляет файл автозапуска.

## Ограничения машины

- **Голос и видео:** `/dev/video*` нет, `arecord -l` не показывает устройств
  захвата — запись не проверялась.
- **HiDPI:** экран 1280×800 при 96 dpi, масштабирования нет.
- **Wayland:** `/usr/share/wayland-sessions` пуст, сеанс X11; поведение
  портала горячей клавиши и frameless-ресайза на Wayland не проверялось
  (решение владельца: Ubuntu не обязательна).
- **Трей без хоста:** на этой машине StatusNotifierWatcher есть (XFCE
  `systray`), поэтому ветка «без трея крестик закрывает окно» живьём не
  проверялась. Политика закреплена тестом `TestNoTrayCannotHide`.
- **AppImage:** проверены запуск через FUSE и подключение к серверу; полный
  вход, лента и вложения — в `.deb` (тот же бинарник).
- Перетаскивание окна за заголовок и ресайз краем мышью не снимались;
  размер менялся `wmctrl -e` (переливка проверена).
