# Android · ввод приглашения на OPPO

19 ноября 2026. OPPO CPH1931, Android 10. Установленный `0.1.0-debug`
с ПК3 из `bf248c97`. SHA-256 установленного APK сверена с локальной сборкой:
`c0e9c2cfbc16c0f7d713bc0859844a1894bad98b616228d1bbfb4efc347eac19`.

Через временный тестовый ответ HTTP 503 открыт ПК3 прежнего тестового
источника. «Другой сервер» показал пустую форму адреса. Поле нажато через
ADB по его фактической позиции в WebView. Тестовое приглашение введено
через системный ввод, проверены полный путь и параметр запроса.

- Системная клавиатура уменьшила видимую область WebView с 728 до 473 CSS px.
  Поле осталось целиком над клавиатурой, «Дальше» было доступно.
- Системная «Назад» закрыла клавиатуру. Видимая область вернулась к 728 CSS px,
  приглашение и все три действия остались в форме.
- После 7 секунд на домашнем экране Wynd вернулся к тому же приглашению в том
  же процессе. Каталог не изменился. Тестовое значение удалено, временное
  USB-перенаправление снято, приложение остановлено как до прогона.

Снимки `empty.png`, `keyboard.png` и `keyboard-dismissed.png` в
`dev/screens/shots/android-startup-input-2026-11-19/` сделаны через
`adb screencap` и осмотрены. Экран 720 × 1600, ширина WebView 360 CSS px,
DPR 2, масштаб 100%, светлая тема. Измерения сохранены в `input-checks.json`.

В той же папке подготовлен `qr-fixture.png` с синтетическим приглашением
для проверки задней камеры. Владелец отложил эту проверку. На OPPO
системный сервис автозаполнения не настроен. Автозаполнение на серверном
входе и прогон на realme 8 остаются открытыми.

## Возврат после трёх минут в фоне

На том же OPPO через локальный ответ HTTP 503 открыт ПК3. После «Другой
сервер» в поле введено синтетическое приглашение. Клавиатура закрыта
системной кнопкой «Назад». По «Домой» активность Wynd ушла в фон,
диспетчер Android подтвердил переход на домашний экран.

После 180 секунд в фоне открылся тот же процесс с тем же документом WebView.
Значение поля целиком совпало с введённым, включая параметр запроса.
На снимке поле показывает конец адреса из-за горизонтальной прокрутки.
Снимок и измерения сохранены в `dev/screens/shots/android-startup-idle-2026-11-19/`.
Приглашение очищено без отправки, USB-перенаправление снято, Wynd остановлен.
Каталог источников совпал с исходным.
