# Проверки поиска Wynd на OPPO, 21 ноября 2026

OPPO CPH1931, Android 10, светлая тема, портрет 720 × 1600 px. Firefox 132 и Android WebView 157.0.8103.50 в отдельном APK 0.1.0-debug. Клиент, сервер и APK собраны из `fe574e3a`. До релиза 0.53.4 (`ff648837`) код поиска и Android-оболочки совпадает. У APK изменён только идентификатор пакета для отдельного профиля, адрес стенда задан параметром debug-сборки. Стенд работает по USB, на каждом его сервере одна тестовая учётка и два синтетических круга. Снимки сделаны штатным `adb exec-out screencap -p`.

## C104. Смена области поиска

В запросе `opal` оставили даты 21.11.2026 и фильтр «С фото». Переключали область в обе стороны, сначала с закрытой клавиатурой, затем с открытой. В локальном прокси задерживали ответы поиска на 3 с. В WebView и в контрольном прогоне Firefox также задерживали список и сведения о круге на 3,3 с.

Во всех восьми переходах из интерфейса Wynd на ранних снимках (к 1,2–1,5 с от команды касания, до ответа поиска) видны новая шапка, запрос, даты и «С фото». Закрытая клавиатура осталась закрытой, открытая убралась. После ответов в круге видно [две записи с фото](wv-open-to-circle-late.png), в общем поиске [три в двух кругах](wv-global-results.png). [Результаты в Firefox](fx-global-complete.png). Обычный вход в поиск круга поднимал клавиатуру в [Firefox](fx-search-entry.png) и [WebView](wv-circle-search-entry.png). Обычный вход в [общий поиск WebView](wv-global-entry.png) также поднимал клавиатуру.

В WebView просмотрели 14 кадров CDP с реального устройства. На соседних кадрах видна смена области [из круга](wv-closed-cast-001.jpg) [во все круги](wv-closed-cast-002.jpg) и [из общего](wv-closed-cast-004.jpg) [в круг](wv-closed-cast-005.jpg). Пустого кадра в этой последовательности нет. Для Firefox доступны отдельные ADB-снимки, по которым нельзя измерить краткую вспышку между ними.

**Прямое открытие общего поиска в Firefox.** Через Android `ACTION_VIEW` отдельно открыли `/search?q=opal&from=2026-11-21&to=2026-11-21&photo=1&circle=<id>`, [дождались результатов](fx-global-before-detail-delay.png) и нажали «Этот круг» при той же задержке. На [раннем снимке к 1,21 с](fx-detail-held-early.png) остался только логотип Wynd. Сведения о круге вернулись на 4,27 с, на [следующем сохранённом снимке](fx-detail-after.png) видны фильтры и две записи. При таком же переходе в рамках пары экранов, начатой из поиска круга, [на раннем снимке к 1,50 с](fx-paired-detail-early.png) уже видны шапка и фильтры. После ещё одного запуска по прямому адресу ранний снимок застал исходный поиск, поздний — поиск круга, поэтому время показа заставки не измерено. Этот вариант C104 остаётся открытым.

## C95. Строки поиска и миниатюры

Открыли общий поиск с улочки и ввели `opal`. На каждом из двух отдельных тестовых серверов были два круга с пятью совпадениями, три из них с фото. Время от команды ввода включает передачу через ADB. Прокси подтвердил ответы поиска и миниатюр с кодом `200`.

- **WebView.** Поиск ответил примерно на 1,06 с. [К 3,6 с](wv-c95-before-thumbs.png) видны все пять строк и три заглушки. Ответы миниатюр вышли около 11,62 с, [к 15,0 с](wv-c95-after-thumbs.png) видны все три фото.
- **Firefox.** [Обычный вход с улочки](fx-global-entry.png) поднял клавиатуру. Поиск ответил на 1,09 с. [К 3,6 с](fx-c95-before-thumbs.png) на месте все пять строк, миниатюры ещё ждут. Ответы вышли на 8,17, 13,94 и 19,61 с. [К 10,2 с](fx-c95-one-thumb.png) появилась первая миниатюра, две другие оставались заглушками. [К 26,8 с](fx-c95-after-thumbs.png) видны все три.

Эта часть C95 пройдена. Независимое появление результатов в одной сессии WebView подтверждено отдельным [прогоном двух серверов](../phone-pending-2026-11-21-oppo/README.md#c95-поиск-по-двум-серверам-в-webview).
