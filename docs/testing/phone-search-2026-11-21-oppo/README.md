# Проверки поиска Wynd на OPPO, 21 ноября 2026

OPPO CPH1931, Android 10, светлая тема, портрет 720 × 1600 px. Firefox 132 и Android WebView 157.0.8103.50 в отдельном APK 0.1.0-debug. Клиент, сервер и APK собраны из `fe574e3a`. До релиза 0.53.4 (`ff648837`) код поиска и Android-оболочки совпадает. У APK изменён только идентификатор пакета для отдельного профиля, адрес стенда задан параметром debug-сборки. Стенд работает по USB, в нём две синтетические группы результатов и одна тестовая учётка. Снимки сделаны штатным `adb exec-out screencap -p`.
