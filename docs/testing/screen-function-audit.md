# Сверка макетов с живой реализацией

**Тип:** сверка
**Статус:** закрыт как отчёт
**Эталон:** [screens.html](../visual/screens.html) · маршруты [client-reference.md](../reference/client-reference.md)
**Дата прогона:** 11 сентября 2026
**Повтор:** та же дата — очередь планов закрыта, решения в справочниках

Цель — кликабельность, логика, сквозные маршруты, не визуальная пиксельная сверка.

Хвосты после проверки закрыты.

## Как читается статус

| Статус | Значение |
|--------|----------|
| `ok` | Контролы живые, логика и цель есть |
| `partial` | Дверь есть, сценарий обрывается или не совпадает с макетом |
| `dead` | Выглядит как действие, обработчика нет |
| `out` | «Что не нарисовано», localhost-ограничение или системный UI |

`/dev/smoke` с пустым `onclick` в сверку не входит.

## Прогон

Локально: `go run ./cmd/wynd` (`:7676`) + Vite `:5174`. Инстанс `test`, `registration_mode=open`.

Сквозное, что дошло до конца в браузере:

1. `/` → «Регистрация без приглашения» → код → пустая улочка 2.2.
2. «Новый круг» → «Семья» создан, на улочке виден.
3. Лента 3.6, вкладки Дни / Сетка / Карта, compose 4.1, настройки 6.1–6.2, идентичность, участники, уведомления, удаление 6.7.
4. Владелец «Покинуть»: диалог 6.15 на хабе («Сначала передайте владение»).
5. Выход с сервера → инвайт `/invite/{token}` 1.1 → код → вступление 1.3 → лента второго человека в том же круге.

Не закрыто в том прогоне: публикация с полосы (автоклик «Отправить» отклонён), живая панель админа (пароль инстанса неизвестен), полный цикл оплаты (реквизитов нет — `/pay` возвращает на улочку, это совпадает с макетом).

## Вне сверки (из screens.html «Что не нарисовано»)

Зум карты, миграция круга, вид HTML-архива, вёрстка писем, системный QR/шаринг, плеер видео, клавиатура, бэкап вне продукта, GDPR-самоудаление, выбор обложки дня как отдельный макет.

## Межпользовательский сценарий

Цепочка живая: владелец создаёт круг → ссылка `/invite/{token}` → второй заводит почту кодом → 1.3 «Войти в круг» → лента того же `circleId`. После join шапка берёт имя с формы (`identity_name` в контексте круга).

Публикацию с полосы в прогоне 11 сентября не подтвердили кликом; путь API `POST /posts` → snapshot → второй видит (если пост после его `started_at`) закрыт приёмочным `TestAcceptanceCircleInviteSyncLeaveDelete`.
