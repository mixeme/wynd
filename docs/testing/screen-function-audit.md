# Сверка макетов с живой реализацией

**Тип:** сверка
**Статус:** открыт
**Эталон:** [screens.html](../visual/screens.html) · маршруты [client-reference.md](../reference/client-reference.md)
**Дата прогона:** 15 сентября 2026
**Карта номеров:** текущая галерея (105 кадров, `e1-1`…`e10-15`)

Две проверки на кадр: **дверь** (кликабельность, логика, маршрут) и **состав** (строки, кнопки, чипы, hint, порядок, тексты). Лишнее в приложении — тоже дыра. Пиксели (отступы, кегль, точный CSS) не сверялись.

`/dev/smoke` с пустым `onclick` и блок «Что не нарисовано» в сверку не входят.

## Как читается статус

| Статус | Значение |
|--------|----------|
| `ok` | Дверь живая; состав и тексты совпадают с кадром |
| `partial` | Дверь есть, но состав, порядок или текст разошлись с кадром |
| `dead` | Выглядит как действие / кадр есть, обработчика или маршрута нет |
| `out` | «Что не нарисовано», localhost-ограничение или системный UI |

## Вне сверки (из screens.html «Что не нарисовано»)

Зум карты, миграция круга, вид HTML-архива, вёрстка писем, системный QR/шаринг, плеер видео, клавиатура, бэкап вне продукта, GDPR-самоудаление, выбор обложки дня как отдельный макет.
