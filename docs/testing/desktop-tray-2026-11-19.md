# Настольный: значок в трее, закрытие и запуск в трей — 19 ноября 2026

Первая функция C66 после перевода окон на Wails v3. **Вёрстка меню ждёт утверждения владельца**: код лежит в ветке `wails-v3`, в `main` не влит.

## Что сделано

- `cmd/wynd-desktop/main.go`: значок `app.SystemTray` с иконкой окна (`build/windows/icon.ico`) и подсказкой «Wynd Настольный»; меню — «Открыть Wynd Настольный» и «Выход». Левый клик по значку открывает окно.
- Закрытие окна любым путём (крестик своей рамки, Alt+F4, пункт задачи) прячет окно (`win.Hide()`), а не завершает программу: `events.Common.WindowClosing` отменяется, программа остаётся в трее. «Крестик» оболочки зовёт `App.RequestClose()` — тот же результат со значком; если значка нет, приложение закрывается, как раньше.
- `--from-startup` (флаг автозапуска ПК5) теперь читается: окно создаётся скрытым (`Hidden`), программа ждёт в трее.

## Кадр меню

`docs/testing/desktop-tray-2026-11-19/tray-menu.png` — PrintWindow настоящего меню (`#32768`) работающего приложения, 243 × 57, тёмное оформление Windows по умолчанию, 100%. Это не эскиз: снят с собранного exe; меню открывалось временной переменной `WYND_TRAY_MENU_PREVIEW`, сам код меню — выпускной (переменной в сборке нет).

| Пункт | Назначение |
| --- | --- |
| Открыть Wynd Настольный | показать и поднять окно |
| Выход | закрыть программу полностью |

## Проверено живьём (изолированный `%APPDATA%`)

| Проверка | Результат |
| --- | --- |
| Значок в трее | ✓ «Wynd Настольный» виден в системной области уведомлений |
| «Крестик» окна | ✓ окно скрылось (`IsWindowVisible=false`), процесс жив |
| Показ окна из скрытого состояния | ✓ окно вернулось (та же функция, что зовёт пункт меню) |
| Запуск с `--from-startup` | ✓ окно не показывалось, процесс жив, значок в трее на месте |
| Сборка и ворота | ✓ `scripts\build-desktop.bat`, `scripts\test-desktop.bat` |

Границы: нажать пункт меню в тестовой сессии нельзя (меню — родное окно Windows, дерево доступности его не читает), поэтому «Открыть…» проверено той же функцией показа из скрытого состояния, а не щелчком по меню. Уведомлений и работы при закрытом окне здесь нет — это другие пункты C66.

## Статус

Кадр и поведение — на утверждение. После «принимаем» — влить в `main`; до этого пункт C66 остаётся открытым.
