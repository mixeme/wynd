# A26: читаемый архив с настоящего сервера в браузере — 17 ноября 2026

Закрывающая проверка A26: архив собран **настоящим сервером Wynd 0.53.0** (`wynd2.mixfed.ru`) и открыт в браузере на компьютере, как это делает человек. Проверялись плитки, «Ещё N», просмотр поверх, переход «лента → запись» и подпись — на архивных данных настоящей сборки, а не на прототипе.

## Как получен архив

1. Сервер `wynd2.mixfed.ru` (0.53.0, стенд `/opt/wynd`). Учётная запись `a26-check@wynd.local` заведена одноразовым приглашением из панели; код входа получался через журнал контейнера (штатный режим «код в журнал», после проверки возвращён `public_url=https://wynd2.mixfed.ru`, `loopback:false, code_delivery:mail`).
2. Через API создан круг **«A26-проверка»** и две записи: «Семь снимков за день» (7 фото) и «Фото и ролик с настоящего сервера» (фото + ролик с обложкой `video_poster_blob_id`). Файлы — синтетические (`dev/screens/dacha.jpg`, `dev/archive-frame/sample.mp4`), личных данных в круге нет.
3. `POST /circles/{id}/archive/link` → ZIP 4,2 МБ; распакован и открыт в headless Edge через `file://`, окно **1040 × 900**, DPR 1, масштаб 100%, светлая тема.

## Что подтверждено

| Проверка | Результат |
| --- | --- |
| Лента архива (A26-выравнивание + плитки) | шапка «A26-проверка», карточки как в приложении; у записи с 7 фото видны первые 6 плиток и кнопка «Ещё 1 фото»; у записи с роликом плитка ролика — кадр обложки со значком play |
| «Ещё N» | по кнопке раскрывается седьмая плитка, текст меняется на «Свернуть» (aria-expanded), обратно сворачивается |
| «Лента → запись» | шапки обеих карточек — ссылки `posts/<ID>.html` (в DOM 2 ссылки) |
| Просмотр фото | плитка открывает `.lb` на всё окно: «3 из 7», подпись `Проверка · 16 ноября 2026, 20:24 UTC · 1600 × 1066` (размер из настоящего файла), точки, стрелки; закрытие крестиком возвращает фокус на «Открыть фото 3» |
| Просмотр видео | «2 из 2», только стрелка назад, нативное управление `0:15`, обложка, без автозапуска; подпись `960 × 540` |
| Без JS (структура) | плитки — `<a href="media/…">` на сам файл, спрятанное раскрывает `<noscript>` (проверено по разметке в `internal/archive` тестах и в HTML этого архива) |

Снимки — настоящие кадры браузера, без перерисовки: `a26-live-feed.png`, `a26-live-expanded.png`, `a26-live-viewer-photo.png`, `a26-live-viewer-video.png`; SHA-256 — `sha256.txt`.

## Границы

Проверялся настольный Edge через `file://`; другие браузеры и телефон не проверялись (телефонный просмотр архива закрыт решением по C73). Тестовый круг «A26-проверка» остаётся на стенде wynd2 — его можно удалить в панели; личных данных в нём нет.
