# Баннер про приложение Android и страница установки

26 ноября 2026. Задача владельца — [план 73](../plans/73-android-app-banner.plan.md).
Решения: показывать в любом вебе на Android, вести на свою страницу установки,
подсказку про браузер оставить.

## Кадры (вид 26.11)

Настоящий рендер клиента 0.54.1 на стенде (`vite` 5178), рамка **360 × 728 CSS px,
DPR 2**, светлая тема, строка браузера **Firefox на Android**, круг «Тест OPPO»
с сервера wynd2 (настоящая учётная запись, данные круга из сервера). «Что нового?»
отмечено прочитанным, чтобы в кадре были только две подсказки Android.

- [Улочка: баннер и подсказка про браузер](android-app-banner-2026-11-26/street.png)
- [Страница установки, вид 26.11](android-app-banner-2026-11-26/install.png) — заменена правкой 27.11

Страница проверена здесь же: заголовок «Приложение для Android», три строки
«Что даёт», шаги установки, кнопка «Скачать приложение». Из этой страницы
запрос к `api.github.com` вернул последний опубликованный выпуск — 0.1.5 и
ссылку на `wynd-android.apk`; в клиенте сработает тот же путь.

## Правка страницы установки (27.11)

Владелец: кадр не помнит; верхнее пояснение повторяло список ниже;
«Записи в фоне» → «Отправка записей в фоне»; «Окно можно закрыть» →
«Приложение можно закрыть»; «Видео сжимается на телефоне» → «Видео сжимается
в фоне» (в браузере ролик тоже сжимается на телефоне, но страницей и при
открытом экране); «Не нужно держать экран открытым»; «Уведомления» →
«Push-уведомления»; внизу — только быстрый вход ссылкой из «Подключить
устройство» (человек держит настроенное устройство в руках, копировать ссылку
проще, чем сканировать свой экран); зазоры над и под кнопкой равны (было 16 и 8
CSS px, стало 16 и 16; по кадру 18,7 и 20,0 — разница только от начертания букв).

Добавлены забытые пункты: «Место со снимков — точка на карте круга» —
приложение запрашивает `ACCESS_MEDIA_LOCATION` и получает исходные координаты
снимка из системной галереи, браузер их не получает; «Поделиться в Wynd —
фото и видео из других приложений» — системные SEND-намерения, приёма
«Поделиться» в вебе нет.

Кадры:
- [Страница установки, вид 27.11, тёмная](android-app-banner-2026-11-26/install-dark.png) — **принят владельцем 27.11 («Да»)**; настоящий рендер стенда `vite` 5178, 360 × 800 CSS px, DPR 3, тёмная тема, как на телефоне.
- [Тот же экран в светлой теме](android-app-banner-2026-11-26/install-light.png) — 360 × 728 CSS px, DPR 2; для сверки «до/после», отдельно не принимался.

Правка страницы — в следующем серверном выпуске: в 0.55.0 её нет. Подсказка про
быстрый вход по ссылке соответствует Android 0.1.6 (черновик, ждёт подписи):
в 0.1.5 приёма ссылки на стартовом экране ещё нет.

## Что осталось живым

На телефоне Android: баннер в браузере и в установленной PWA; в приложении
Wynd баннера нет; крестик закрывает насовсем; кнопка скачивает APK; без сети
открывается страница выпусков. Проверка записана в
[реестр устройств](pending-device-checks.md).
