# Баннер про приложение Android и страница установки

26 ноября 2026. Задача владельца — [план 73](../plans/73-android-app-banner.plan.md).
Решения: показывать в любом вебе на Android, вести на свою страницу установки,
подсказку про браузер оставить.

## Кадры

Настоящий рендер клиента 0.54.1 на стенде (`vite` 5178), рамка **360 × 728 CSS px,
DPR 2**, светлая тема, строка браузера **Firefox на Android**, круг «Тест OPPO»
с сервера wynd2 (настоящая учётная запись, данные круга из сервера). «Что нового?»
отмечено прочитанным, чтобы в кадре были только две подсказки Android.

- [Улочка: баннер и подсказка про браузер](android-app-banner-2026-11-26/street.png)
- [Страница установки](android-app-banner-2026-11-26/install.png)

Страница проверена здесь же: заголовок «Приложение для Android», три строки
«Что даёт», шаги установки, кнопка «Скачать приложение». Из этой страницы
запрос к `api.github.com` вернул последний опубликованный выпуск — 0.1.5 и
ссылку на `wynd-android.apk`; в клиенте сработает тот же путь.

## Что осталось живым

На телефоне Android: баннер в браузере и в установленной PWA; в приложении
Wynd баннера нет; крестик закрывает насовсем; кнопка скачивает APK; без сети
открывается страница выпусков. Проверка записана в
[реестр устройств](pending-device-checks.md).
