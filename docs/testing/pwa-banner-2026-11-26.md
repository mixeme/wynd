# Баннер «Wynd на главный экран»

26 ноября 2026. Задача владельца — [план 74](../plans/74-pwa-install-banner.plan.md). **Кадры приняты владельцем 26.11 («Да»).**
Решения: показывать в Chrome/Vivaldi/Safari/Firefox; порядок — подсказка о браузере,
веб-приложение, приложение, «Что нового?»; в баннере PWA — про уведомления.

## Кадры

Настоящий рендер клиента 0.54.1 на стенде (`vite` 5178), рамка **360 × 728 CSS px,
DPR 2**, светлая тема, строка браузера **Firefox на Android**, круг «Тест OPPO»
с сервера wynd2. «Что нового?» отмечено прочитанным.

- [Улочка: три баннера](pwa-banner-2026-11-26/street.png) — «Рекомендуем Chrome или Vivaldi»,
  «Wynd на главный экран», «Приложение Wynd для Android».
- [Шаги установки](pwa-banner-2026-11-26/help.png) — нажатие баннера в стенде: системного
  окна нет (стенд без служебного воркера), показаны шаги для Firefox.

## Что проверено

- Баннер стоит после подсказки о браузере и перед баннером про приложение;
  «Что нового?» — ниже всех трёх (слово владельца 26.11).
- Нажатие без системного окна открывает шаги по браузеру; в Chrome/Vivaldi
  `beforeinstallprompt` даст своё окно установки, шагов не будет.
- Закрытие баннера пишется на устройство (`wynd:pwa-hint-closed`); установленная
  PWA и приложение Wynd баннера не видят (проверено тестами `pwaHint` и `install`).

## Что осталось живым

На телефоне: Chrome на Android — системное окно установки и исчезновение баннера
после установки; Firefox и Safari — шаги меню; открытие с домашнего экрана —
баннера нет; крестик закрывает насовсем. Записано в
[реестр устройств](pending-device-checks.md).
