## Принятый вид

Тот же `Lightbox fixed` закрывает всё окно тёмным фоном. Фото целиком (`object-fit: contain`), без кадрирования. Сверху слева — закрытие и счётчик, справа — скачивание. По краям — предыдущий/следующий элемент записи; на границе подборки лишней стрелки нет. Под медиа — точки и подпись с автором, абсолютной датой/временем UTC и размером файла в пикселях. Дата UTC сохранена из тестового архива, относительного «сегодня» нет.

У видео та же оболочка; внутри — настоящий `<video controls playsinline preload="metadata">`, без автозапуска. На кадре показано начальное состояние с тестовой обложкой `dacha.jpg`; сам тестовый ролик взят из уже существующей фикстуры `../a26-card-proposal-2026-11-15/sample.mp4`. Обложка условная, как в принятой карточке; извлечение постера из видео здесь не реализовано. При переходе к другому вложению и при закрытии видео останавливается. Крестик/Escape возвращают к исходной карточке и её превью.

HTML просмотрщика получен SSR настоящих `Lightbox` и `BylineParts`, CSS извлечён из существующего `ui.css`; оформление компонента не менялось. `review.html` содержит небольшой адаптер действий для изолированного макета: открытие, закрытие, листание, фокус и скачивание. Это не реализация рабочего архива и не проверка Svelte action `modal`/интеграции с историей браузера. Для SSR импорты `$app/navigation` заглушены функциями, которые бросают ошибку при вызове; они при рендере не вызываются. Вёрстка компонентов не подменяется.

## Рендер и осмотр

Headless Microsoft Edge, локальный `file://`, существующий `dev/screens/cdp.mjs`; **1040 × 900**, DPR 1, масштаб 100%, светлая тема страницы. Тёмный фон самого просмотрщика — штатный фон `Lightbox`, одинаковый для фото и видео. Оба состояния — настоящие снимки браузера, без ручной перерисовки.

- `a26-viewer-approved-card.png` и `a26-viewer-card.png` совпадают по SHA-256 с принятым полным кадром `a26-card-proposal-desktop.png`: `82cf7f762caa8315d9472b313bf856f80c1beff069df3ae4a385683d0183b3a4`. Добавление просмотрщика не изменило карточки.
- `a26-viewer-photo.png`: фото **3 из 12**, обе стрелки, третья точка активна, подпись `Аня · 10 ноября 2026, 21:05 UTC · 1600 × 1066`.
- `a26-viewer-video.png`: видео **2 из 2** на паузе, последняя точка активна, только стрелка назад, нативные управление и длительность 0:15; подпись с фактическими размерами ролика 960 × 540.
- `a26-viewer-return.png`: возврат к карточке после Escape; фокус на исходном превью видео (обводка фокуса ожидаема).

Кадры осмотрены: изображение целиком, верхняя панель и подпись читаются, стрелки и точки на месте, у видео управление видно, горизонтального переполнения нет. Проверены открытие из третьего превью, переход 3 → 4 → 3, закрытие крестиком, открытие ролика, его воспроизведение и остановка при переходе к фото, закрытие Escape с возвратом фокуса и сохранением `scrollY=0`. Размер оверлея — [0, 0, 1040, 900]. Полный сценарий записан в `capture.json`. Производственная история браузера, работа на телефоне и другие браузеры здесь не проверялись.

Источники и кадры добавлены коммитом `466ee4f2`; хеши файлов — `sha256.json`. Приёмка обоих кадров записана 2026-11-16. Без изменения оформления повторное согласование этих кадров не требуется.

## Повторение

Из корня:

```powershell
node docs/visual/build-a26-viewer-proposal.mjs
```

Из `dev/screens`:

```powershell
$env:CDP_PORT='9348'
$env:CDP_DIR='a26-viewer-review-edge'
node cdp.mjs ../../docs/testing/a26-viewer-proposal-2026-11-15/capture.json
```

Абсолютный префикс `D:/Local/Git/wynd` в `capture.json` заменить для другой рабочей копии. Снимки появляются в `dev/screens/shots`; сохранённые копии лежат рядом с этим README. Отдельный браузер закрыт, его временный профиль после проверки удалён.
