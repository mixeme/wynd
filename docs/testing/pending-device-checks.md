# Проверки на устройствах, которые ещё не завершены

Единый список всех незавершённых проверок на телефонах, планшетах и в браузерах. Другие контуры (Мастерская, окно для компьютера, «Подпись», сервер) — в разделе 7 со ссылками; их подробности остаются в планах, чтобы не расходиться.

Правила:

- пункт закрывается только свидетельством с устройства: версия, устройство, сценарий, фактический исход; кодовые, API- и компонентные тесты телефонную галочку не закрывают;
- результат записывается в протокол проверки (`phone-checks-YYYY-MM-DD.md`) или прямо в строку пункта;
- подтверждённое вычёркивается, сломанное становится пунктом «C» в [плане 46](../plans/46-open-questions-and-debt.plan.md);
- для плашек и ссылок после реализации действуют правила плана 56, а не прежние ожидания о галочке сервера.

Состояние на 2026-11-19: на обоих серверах **0.53.2** (первый кадр из снимков и запуск без ожидания сети — [протокол](release-0.53.2-2026-11-19.md)); до этого 0.53.1 (быстрее чтение круга) и 0.53.0 (плитки и просмотр медиа в читаемом архиве, «лента → запись», окно скачивания на iPhone закрывается само — [протокол](release-0.53.0.md)). До этого: 0.52.3 (выравнивание архива, год в полях периода, «Назад» без петли при оверлее). Раньше: 0.52.2 («Назад» одним правилом, звук в архиве, код отказа по данным круга). До 15 ноября телефон проверяет всё до 0.51.0 включительно (0.51.1 менял только окно для компьютера). Исправления C83–C87 (поиск по периоду, поля «с»/«по», карточка сервера на входе и «Без приглашения», «Назад» из глобального поиска) выпущены в 0.52.1 и ждут проверки. Протоколы: [3 ноября](phone-checks-2026-11-03.md), [4 ноября](phone-checks-2026-11-04.md), [8 ноября](phone-checks-2026-11-08.md), [11 ноября](phone-checks-2026-11-11.md).

## 8. Телефон по USB — агент проверяет сам

Пункты разделов 1–2 и 6, которые агент выполняет без владельца: телефон подключён по USB с включённой отладкой (ADB), в Chromium-браузере телефона включена отладка веб-содержимого (`chrome://inspect` с компьютера; Firefox и браузеры без CDP не годятся). Нажатия — через CDP, системная «Назад» и перезапуск приложения — через adb (`KEYCODE_BACK`, `am force-stop`); тёмная тема — `adb shell cmd uimode night`; авиарежим — `adb shell svc wifi/mobile data`. Снимать свежим профилем браузера: старый service worker отдаёт устаревший клиент. Сервер и данные для сценариев — wynd2 (панель и API доступны агенту, коды входа — через журнал; `public_url` после пробы возвращать).
