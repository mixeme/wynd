# Проверки на устройствах, которые ещё не завершены

Единый список всех незавершённых проверок на телефонах, планшетах и в браузерах. Другие контуры (Мастерская, окно для компьютера, «Подпись», сервер) — в разделе 7 со ссылками; их подробности остаются в планах, чтобы не расходиться.

Правила:

- пункт закрывается только свидетельством с устройства: версия, устройство, сценарий, фактический исход; кодовые, API- и компонентные тесты телефонную галочку не закрывают;
- результат записывается в протокол проверки (`phone-checks-YYYY-MM-DD.md`) или прямо в строку пункта;
- подтверждённое вычёркивается, сломанное становится пунктом «C» в [плане 46](../plans/46-open-questions-and-debt.plan.md);
- для плашек и ссылок после реализации действуют правила плана 56, а не прежние ожидания о галочке сервера.

Состояние на 2026-11-25: на обоих серверах **0.54.0** ([протокол](release-0.54.0-2026-11-25.md)); до этого 0.53.9 ([протокол](release-0.53.9-2026-11-25.md)), 0.53.8 ([протокол](release-0.53.8-2026-11-24.md)); до этого 0.53.7 ([протокол](release-0.53.7-2026-11-24.md)); до этого 0.53.6 ([протокол](release-0.53.6-2026-11-23.md)); телефонный прогон C123 и C120 — [протокол](phone-c123-2026-11-23/README.md); до этого 0.53.4 (поиск по мере ответов серверов; правки C102–C112; схема 17 — [протокол](release-0.53.4-2026-11-21.md)); до этого 0.53.3 (первый кадр во вкладках, альбомах и панели; дата в периоде целиком; панель на телефоне — [протокол](release-0.53.3-2026-11-20.md)), 0.53.2 (первый кадр из снимков и запуск без ожидания сети — [протокол](release-0.53.2-2026-11-19.md)), 0.53.1 (быстрее чтение круга) и 0.53.0 (плитки и просмотр медиа в читаемом архиве, «лента → запись», окно скачивания на iPhone закрывается само — [протокол](release-0.53.0.md)). ## 12. Linux «Wynd Настольный» — Ubuntu 24.04/Debian 12

Сборка и пакеты проверены в CI ([протокол](linux-desktop-2026-11-24.md)); черновик **0.5.0** с Linux-пакетами ждёт подписи ([протокол](release-desktop-0.5.0-2026-11-25.md)). Ниже — то, что требует настоящего рабочего стола.

- [ ] **Установка и вход.** `apt install ./wynd-desktop_<версия>_amd64.deb` или AppImage; окно, вход, улочка, лента, запись, медиа; SSE и очередь после сворачивания.
- [ ] **Скачивание и запись.** Скачать архив/вложение через `<a download>`; записать голос и видео — проверить WebKitGTK и GStreamer.
- [ ] **Трей.** Значок в GNOME (AppIndicator)/KDE/XFCE; «Открыть», «Выход»; крестик прячет окно только при живом трее. Снимок меню — на приёмку.
- [ ] **Уведомления.** Новая запись и «вышла версия» при скрытом окне; на виду молчит.
- [ ] **Автозапуск.** Строка «Запускать при входе в систему»; после входа в сеанс окно/трей; выключение убирает файл.
- [ ] **Схема `wynd:`.** Ссылка приглашения из браузера открывает окно; второй запуск не создаёт второе окно.
- [ ] **Токены.** После перезапуска вход сохраняется через Secret Service; без keyring — ошибка и копия в IndexedDB, не потеря.
- [ ] **Окно.** X11 и Wayland: перетаскивание, ресайз frameless, горячая клавиша `Ctrl+Alt+W`, тёмная/светлая тема, HiDPI.
