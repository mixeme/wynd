# Проверки на устройствах, которые ещё не завершены

Единый список всех незавершённых проверок на телефонах, планшетах и в браузерах. Другие контуры (Мастерская, окно для компьютера, «Подпись», сервер) — в разделе 7 со ссылками; их подробности остаются в планах, чтобы не расходиться.

Правила:

- пункт закрывается только свидетельством с устройства: версия, устройство, сценарий, фактический исход; кодовые, API- и компонентные тесты телефонную галочку не закрывают;
- результат записывается в протокол проверки (`phone-checks-YYYY-MM-DD.md`) или прямо в строку пункта;
- подтверждённое вычёркивается, сломанное становится пунктом «C» в [плане 46](../plans/46-open-questions-and-debt.plan.md);
- для плашек и ссылок после реализации действуют правила плана 56, а не прежние ожидания о галочке сервера.

Состояние на 2026-11-11: на обоих серверах **0.51.1**; 0.51.1 меняет только окно для компьютера, на телефоне проверяется всё до 0.51.0 включительно. Протоколы: [3 ноября](phone-checks-2026-11-03.md), [4 ноября](phone-checks-2026-11-04.md), [8 ноября](phone-checks-2026-11-08.md), [11 ноября](phone-checks-2026-11-11.md).

## 1. Сейчас на телефоне (выпущено, ждёт проверки)

### 1.1 «Назад» на экран-источник — 0.51.0, план 61

Ни один сценарий ещё не принят на телефоне. Проверять стрелкой и системной «Назад» — правило одно.

- [ ] Лента → баннер «Перенос круга» → «Перенос круга» → «Назад» возвращает в ленту на то же место; из «Настроек» круга — как раньше.
- [ ] Лента → баннер «Полный архив» → «Назад» возвращает в ленту; из «Квоты» — как раньше.
- [ ] Поиск → день или запись → «Назад» возвращает в поиск с тем же запросом; поиск по всем кругам — так же.
- [ ] «Сетка» → фото/альбом: «К записи» в шапке ведёт в запись; дата и время публикации в просмотре фото — ссылка на запись; «Назад» из альбома возвращает в «Сетку», из записи — туда, откуда открыли.
- [ ] Шапка круга → имя и аватар → «Настройки» круга → «Назад» возвращает на ту вкладку, откуда открыли (лента, «Дни», «Сетка», «Карта», «Отклики», «Поиск»).
- [ ] «Уйти из круга» или «Уйти с сервера» → «Передать владение» → «Назад» возвращает на экран выхода.
- [ ] «Уйти с сервера» с одним участником → «Настройки» круга → «Назад» возвращает на экран «Уйти с сервера насовсем».
- [ ] День, открытый из поиска, — см. 1.2; из ленты и будильника дня «Назад» ведёт в ленту.
