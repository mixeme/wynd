# «Кто мы» в шапке круга: имя появлялось не в первом кадре

26 ноября 2026. Замечание владельца: «При входе в круг кто мы на показывается
не сразу. Это тоже не покрыто кэшем?»

## Причина

Имя в круге (`identity_name`) **кэшируется** — в `circle_meta` настроек
приложения (`web/src/lib/circles/meta.ts`), рядом с цветом круга. Но первый
кадр шапки его не брал:

- при нажатии на строку улочки `openCircle` кладёт в сеялку
  (`web/src/lib/circles/seed.ts`) имя, цвет, курсор и права — **без имени
  в круге**;
- макет круга строит шапку из сеялки, `identityName` пустой — блока «кто мы»
  в шапке нет (`CircleBar`: `{#if identity}`);
- имя приходило позже: `paintCachedMeta` читал снимок улочки из IndexedDB
  и только тогда `circle_meta`; если снимка нет — после ответов
  `GET /circles` и `GET /circles/{id}`.

Замер на стенде (360 × 728 CSS px, DPR 2, тёплый кэш): шапка появлялась на
454 мс после нажатия, имя — на 478 мс, то есть **на 24 мс позже** (1–2 кадра).
На телефоне разрыв больше: чтения IndexedDB медленнее, а без снимка улочки
имя ждёт сеть.

## Что сделано

- Строка улочки читает `circle_meta` одним обращением (`getCircleMeta`) и
  несёт `identityName` рядом с `colorToken` (`web/src/lib/circles/circles.ts`).
- Сеялка и `openCircle` передают имя в круг; макет круга ставит
  `identityName` и `identityInitial` из сеялки — блок «кто мы» в первом кадре
  (`web/src/routes/circles/[id]/+layout.svelte`).
- Из поиска имя тоже переезжает: `rememberSearchCircle` получает
  `ctx.identityName` (`web/src/lib/journal/search-scope.ts`).
- Фото-аватар по-прежнему приходит после сведений о круге (это ссылка на
  блоб); до него видна буква имени. Серверное имя уточняет шапку следом —
  как и цвет круга.

Тесты: `circles-cache.test.ts` (строка улочки отдаёт имя из кэша),
`search-scope.test.ts` (имя едет в сеялке поиска). svelte-check 0/0,
676 тестов, lint и check:ui зелёные.

## Осталось

- Живая проверка на телефоне/планшете: вход в круг с улочки — имя и буква
  в шапке сразу, без появления через мгновение. Вход по прямой ссылке
  (уведомление) берёт имя из снимка улочки, если он есть; иначе — после
  ответа сети, это отдельный путь.
