# C127: подсказка «Сменить сервер интерфейса» при общих входах

Решение владельца 25.11 по C127 — вариант **(б)**: входы и круги видны при
любом источнике интерфейса. Их хранит оболочка Android (общий файл, как у окна
для компьютера), а не IndexedDB выбранного источника. Поэтому прежняя подсказка
«Входы и круги останутся на своих серверах» перестаёт быть правдой: входы
больше не принадлежат серверу интерфейса.

Изменена одна строка — подпись строки «Сменить сервер интерфейса». Показывается
только там, где есть общее хранилище (новый APK, мост `__wyndSecrets`); в
браузере и старых APK остаётся прежний текст. Вёрстка, размеры и порядок строк
не менялись.

## Как сняты

Настоящий рендер собранного клиента из этого дерева (не рисунок): сервер
`cmd/wynd` с `web/dist`, стенд `127.0.0.1:7679` на данных `dev/c92/data`
(«Стенд OPPO A»), headless Edge через `dev/screens/cdp.mjs`, окно 360 × 728
CSS px, светлая тема, одинаковые данные.

Мосты оболочки подставлены скриптом до загрузки страницы: `__wyndPush` и
`__wyndInterfaces` — в обоих кадрах; `__wyndSecrets` — только в «после», как
в новом APK. Подсказка выбирается по наличию моста
(`androidSecretsAvailable()`), поэтому кадр «после» — это ровно то, что увидит
телефон после установки APK с C127.
