# Выпуск настольных приложений 20 ноября 2026, вечер — Мастерская 0.4.7, Настольный 0.4.2

Черновики обоих окон собраны CI и **ждут подписи и публикации владельца** в
«Подписи». «Подпись» не менялась — своего выпуска у неё нет.

## Что в выпусках

- **Мастерская 0.4.7** (`workshop-v0.4.7` → `b87c93bb`): полный вывод сборки
  пишется на сервер (`/var/tmp/wynd-build.log`, перезаписывается каждой
  сборкой), а окно догружает начало кнопкой **«Загрузить начало»** порциями
  по 256 КБ через мост `BuildLogChunk`; кнопка видна только у обрезанного
  журнала, служебная строка «начало вывода не сохранено» после догрузки
  скрыта (`ecc55949`). Вёрстка принята владельцем 20.11 («Да») после правки
  отступа 16 px (`9038632a`) — [кадры](c71-log-earlier-2026-11-20/README.md).
  «Что нового» — раздел `0.4.7` в `cmd/wynd-workshop/whatsnew.md`.
- **Настольный 0.4.2** (`desktop-v0.4.2` → `b87c93bb`): на первом запуске
  стрелка «Назад» с экрана входа (почта) ведёт к вводу адреса сервера —
  оболочка показывает свой первый экран «Войти в Wynd» с прежним адресом в
  поле (`b8792abd`, `wynd:return-to-address`; план 50, находка владельца
  20.11). «Что нового» — раздел `0.4.2` в `cmd/wynd-desktop/whatsnew.md`.

ключа** — имя файла в exe не встречается, потому что `build-desktop.bat`
вшивает ключ значением через `-ldflags -X`. Рабочая проверка — искать в exe
префикс содержимого `signing-key.pub` (здесь `KVkfXHEkcFEFKpDk/…`).
