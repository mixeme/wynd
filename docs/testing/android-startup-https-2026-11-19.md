# Android · холодный запуск сохранённого интерфейса по HTTPS

19 ноября 2026. OPPO CPH1931, Android 10, WebView 157.0.8103.50.
Тестовый сервер `wynd2.mixfed.ru` отдавал Wynd 0.53.0.

Для прогона собран отдельный debug-пакет `mixeme.wynd.debug.httpscache`
из `1cb2ecba`, с начальным адресом `https://wynd2.mixfed.ru`. Все 10
файлов встроенного старта совпали с установленным APK с ПК3 из `bf248c97`.
SHA-256 тестового APK
`41c4863ce24e76f6e24860ce0b8119924a5fa2319bd4cbe8544b6525c96e4068`.

WebView тестового пакета открывал сервер через USB и локальный CONNECT-релей
для `wynd2.mixfed.ru:443`. Проверку сертификата выполнял WebView.
Для имитации отказа релей закрыл открытые соединения и отклонял новые.
Доступ к серверу ограничивался только для тестового пакета. Системные
настройки, рабочий профиль и настройки сервера не менялись.

## Наблюдения

- На чистой установке Wynd сам зарегистрировал `/sw.js` со scope `/`.
  Workbox сохранил 362 записи, включая `/index.html`. После навигации
  на `/` форма входа открылась под контролем воркера, `workerStart > 0`.
- После отключения релея запрос к `/api/v1/instance` с уникальным query
  и `cache: 'no-store'` завершился сетевой ошибкой в WebView. После
  `am force-stop` запустился новый процесс. Релей отклонил пять
  соединений при запуске. Форма «Войти» открылась на исходном HTTPS-адресе
  с сообщением о недоступности сервера. `/sw.js` обслужил навигацию,
  `workerStart > 0`, в Cache Storage по-прежнему 362 записи.
- После возврата доступа к HTTPS и ещё одного полного перезапуска
  регистрация, precache и контроль воркера сохранились. Состояние
  серверной плашки в этой попытке зафиксировано на проверке связи.

Для сравнения осмотрены реальные снимки `online.png` и `cold-cached.png`
из `dev/screens/shots/android-startup-https-2026-11-19/`. Оба сняты через
`adb screencap` при 360 × 728 CSS px, DPR 2, масштабе 100% и светлой теме.
В холодном запуске видна сохранённая серверная форма с её обычной плашкой
и подсказкой об отказе. Данные CDP, PID, счётчики релея и результат
очистки в `observed.json` рядом со снимками.

Подтверждён холодный запуск сохранённой формы входа. Вход с учётной
записью, сохранённые круги и очередь этим прогоном не проверялись.
Изолированный пакет удалён, USB-перенаправление снято. Путь APK рабочего
пакета и байты его каталога источников совпали до и после прогона.
