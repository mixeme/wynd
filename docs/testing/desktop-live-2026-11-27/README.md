## §26. Вшитый интерфейс по умолчанию — пройдено

Выпускная 0.5.7, чистый `APPDATA`, сервер `http://127.0.0.1:7691`:

- первый запуск и вход открывают **вшитый** клиент (`embedded ui: интерфейс из
  exe` в журнале), мост отдаёт настоящий адрес сервера; «Настройки →
  Приложение → Интерфейс» показывает «Встроенный / Интерфейс приложения /
  Сейчас открывает интерфейс»;
- «Сменить источник интерфейса» → «Дом Ани»: страницы пошли с сервера, в списке
  отмечен сервер, «Встроенный» не отмечен, `servers.json` получил
  `"source":"server"`;
- возврат на «Встроенный»: страницы снова из exe, `servers.json` —
  `"source":"embedded"`, сервер снова подписан «Данные с этого сервера», входы
  и круги не изменились;
- запуск с `--server-ui`: журнал `server ui: интерфейс с сервера`, «Интерфейс»
  показывает «Дом Ани / Сейчас открывает интерфейс», `servers.json` не
  изменился (`source` пуст); следующий обычный запуск снова вшитый;
  `--embedded-ui` принимается без ошибки.

## Границы

- Сеанс RDP без переднего окна: физические клавиши, Enter, правый щелчок по
  значку трея, перетаскивание и прокрутка колесом не выполнялись; поля и
  кнопки — UI Automation, мышь — posted-сообщения. Это не заменяет живую
  проверку ввода человеком.
- Значок загрузки снят с задержкой 2 с на GET данных круга; без задержки
  локальный стенд отвечает быстрее, чем успевает кадр. Задержка — только в
  тестовом прокси, не в продукте.
- Самообновление проверено на опубликованных 0.5.6 → 0.5.7 с GitHub;
  отказ подписи и медленный канал не воспроизводились.
- Заполненные экраны архивов Мастерской и ветки §23 «новичок»/многословный
  запрос не проверены.
- Вёрстка вшитого интерфейса (три кадра в плане 66, функция 9) по-прежнему
  ждёт приёмки владельцем: эти проверки подтверждают поведение и кадры окна,
  но не заменяют приёмку.
