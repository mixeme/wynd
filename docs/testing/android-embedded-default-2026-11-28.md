# Android: вшитый интерфейс по умолчанию (28.11.2026)

План [50](../plans/50-android-wrapper.plan.md), раздел «Вшитый интерфейс».
Решение владельца 28.11: «Переключай Android приложение на вшитый интерфейс».
Подготовка без переключения и устройство режима —
[android-embedded-ui-2026-11-24](android-embedded-ui-2026-11-24.md); схема —
принятое решение Настольного 27.11
([desktop-embedded-default-2026-11-27](desktop-embedded-default-2026-11-27.md)).

## Модель

- Источник интерфейса — поле `source` в `interface-servers.json`:
  `embedded` (по умолчанию, в том числе для старых файлов без поля) или
  `server`. Выбранный сервер остаётся источником **данных** в обоих режимах:
  API, события и медиа идут на его адрес, origin WebView прежний. Смена
  источника не переносит данные: общие входы (C127), IndexedDB и очередь
  остаются на месте.
- Вшитый — основной. Серверный — явный откат: «Настройки → Приложение →
  Интерфейс» → «Сменить источник интерфейса» → сервер из списка. Отдельного
  флага запуска у APK нет (в отличие от `--server-ui` окна) — откат
  выполняется в самом приложении и остаётся до обратного выбора.
- В списке источников «Встроенный» стоит первым; выбранный сервер подписан
  «Данные с этого сервера» и не имеет крестика удаления. Выбор сервера
  открывает его серверный интерфейс, выбор «Встроенный» возвращает вшитый
  клиент с тем же сервером данных.
- Клиент вшит в каждую сборку: `wyndEmbeddedUi` в `build.gradle` теперь
  `true` по умолчанию; `-PwyndEmbeddedUi=false` — сторож прежнего лёгкого APK
  (в нём источник `embedded` тихо отдаёт страницы с сервера).
- При смене источника (в обе стороны) и при обновлении APK один раз снимаются
  регистрации Service Worker и CacheStorage выбранного origin, страница
  перезагружается; IndexedDB, сессии и очередь не трогаются. Без этого
  прежний воркер того же origin отдавал бы страницы и чанки прежнего
  источника.

## Что сделано

- `android/.../InterfaceCatalog.java` — поле `source`, `source()` и
  `selectEmbedded()`; чужое значение и серверный источник без выбранного
  сервера читаются как вшитый (как `sourceLocked` в Настольном); выбор сервера
  (`select`) записывает серверный источник атомарно с выбором.
- `android/.../InterfaceBridge.java` — операция `embedded` протокола
  (`protocol: 1`): busy-проверка, запись источника на UI-потоке, отметка сброса
  воркера, перезапуск оболочки; выбор сервера помечает сброс так же.
- `android/.../MainActivity.java` — вшитые ресурсы включаются по
  `BuildConfig.EMBEDDED_UI` **и** `source == embedded`; сброс воркера
  (обновление APK + смена источника) вынесен из вшитого режима в общий
  `onPageFinished`.
- `android/app/build.gradle`, `scripts/build-android.ps1`,
  `.github/workflows/android.yaml` — клиент по умолчанию в каждой сборке;
  ключ `-NoEmbeddedUi` и CI-сторож `-PwyndEmbeddedUi=false` держат рабочим
  путь без клиента.
- Веб-клиент — `$lib/android/interfaces.ts` знает `source` (поле без значения
  читается как `server` — нативная до переключения всегда серверная) и
  операцию `embedded`; «Настройки → Приложение» показывает «Встроенный /
  Интерфейс приложения»; экран списка источников показывает «Встроенный»
  первым, сервер данных — «Данные с этого сервера», подсказка как у
  Настольного («Интерфейс открывается из приложения или с выбранного
  сервера…»).

## Кадры (настоящий рендер)

Настоящие страницы `/settings/app` и `/settings/app/interface` из
проверяемого исходника (vite + headless Edge/CDP), светлая тема, 100%, DPR 1,
размеры 390×780 и 360×640 — как в принятых кадрах 17.11. Нативные мосты
заменены демонстрационными на том же протоколе; каталог: «Дом Ани» (выбранный)
и «Файлы». Файлы и манифест:
`dev/screens/shots/android-embedded-default-2026-11-28/`, сценарий
`scripts/render-android-embedded-default.mjs`, галерея —
`dev/frames-gallery/plan50-android-embedded.html`.

- кадр 1 — «Настройки → Приложение» во вшитом режиме: «Встроенный /
  Интерфейс приложения», «Сменить источник интерфейса»;
- кадр 2 — список источников: «Встроенный» выбран, сервер подписан
  «Данные с этого сервера», второй сервер removable;
- кадр 3 — тот же список после выбора сервера: отмечен сервер,
  «Встроенный» остался строкой выбора.

**Принятие смысла и вёрстки раздельно.** Слово владельца 28.11 принимает
переключение как решение (смысл). Приёмка вёрстки кадров не выполнена: кадры
показаны владельцу и ждут его слова; до приёмки вариант считается
предложенным.

## Не проверено вживую

Реестр [§33](pending-device-checks.md): установка обновления поверх
серверного режима (старые файлы без `source` → вшитый), смена источника в
обе стороны на телефоне со сбросом воркера, офлайн-запуск вшитого клиента,
поведение при старом воркере от сервера на HTTPS, realme 8 и Android 13+,
выпускная сборка. F-Droid-редакция собирает клиент своим `gradleprops`
(`wyndEmbeddedUi=true`) — без изменений.
