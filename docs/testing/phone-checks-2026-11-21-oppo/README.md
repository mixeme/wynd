# Повтор проверок Wynd на OPPO, 21 ноября 2026

OPPO CPH1931, Android 10, Firefox 132. Светлая тема, портрет, 720 × 1600 px. Клиент и сервер собраны из `9498d769` на изолированном стенде с одним тестовым кругом, одной записью, реакцией и синтетическими комментариями. Запись открывали через Android `ACTION_VIEW` после остановки Firefox. Снимки сделаны на телефоне через `adb exec-out screencap -p`.

## C108. Холодное открытие обсуждения и возврат сети

Открыли обсуждение из [карточки круга с непрочитанным откликом](warm-street.png). После отключения Wi‑Fi и мобильных данных стенд также перестал отдавать любые ответы через USB. Firefox показал [«Соединение было сброшено»](first-cold-early.png) до запуска Wynd. На loopback сервис-воркер из сборки вручную зарегистрировали заранее. Диагностика после остановки Firefox показала, что HTML остался в Cache Storage, а активной регистрации и контроллера уже нет. Сквозной запуск без доступа к оболочке остался открытым.

Затем оставили HTML, JS и CSS доступными через USB, а все запросы к API блокировали. Android в обоих прогонах подтвердил отсутствие активной сети. Во время каждого отключения второй участник добавлял новый комментарий через сервер. После возврата сети страницу не перезагружали.

|---|---|---|

В обоих прогонах после возврата сети стенд записал фоновые ответы ленты `200`. В первом прогоне строка адреса на снимке обрезана, полный адрес отдельно сверили во втором.
