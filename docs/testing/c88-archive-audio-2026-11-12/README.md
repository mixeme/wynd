# C88 — звук в читаемом архиве круга: кадры, приёмка

Рендеры — настоящий HTML генератора (`internal/archive`) в браузере, окно 375 × 812 (снимок удвоен), тема светлая. Архив собран `go run ./dev/archive-frame …` из тестовых файлов (сгенерированный WAV и картинка-обложка); сам генератор кадров в git не входит (`dev/`).

## Приёмка

**Вёрстка принята владельцем 12 ноября («Да»)** — кадры ниже и `archive-c88-still.png` с `archive-app-compare.png`; повторное согласование не требуется. Там же решено: у звука без обложки — такая же полосатая заглушка, как в приложении («Да, добавь такую же заглушку»).

Заглушка сделана в main 12 ноября: у `.att-cover` архива фон, полоски и рамка от `.pic` приложения; заодно у обложки с файлом появилась рамка 1 px — в приложении она есть всегда, раньше архив её не рисовал. Стили держит тест паритета `TestArchiveStylesMatchApp` (внутренний тест `internal/archive`): он сверяет стили архива с `tokens.css` и `ui.css` приложения и падает при расхождении; охват не только аудио, но и карточки, шрифтов, аватаров, медиа и комментариев — задокументированные отличия перечислены в его таблице и в плане 46 (A26).
