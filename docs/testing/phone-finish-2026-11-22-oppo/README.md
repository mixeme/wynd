# Повтор проверок Wynd на OPPO

22 ноября 2026. OPPO CPH1931, Android 10, Android WebView. Сервер и отдельный APK собраны из `10ba8658`. Использованы независимые базы, локальный тестовый SMTP и синтетические учётки.

## Вход и лента

В отдельном APK ввели адрес синтетической учётки и код из журнала нужного сервера. Прямой локальный сервер без прокси отдал список и ленту с HTTP 200. На OPPO открылись тестовый круг и запись. В трассе после принятия кода есть второй `POST /auth/verify` с ответом 404. Навигация завершилась. Повторный запрос замечен в одном прогоне.

[Список](local-login-list.png) · [Лента](local-login-feed.png) · [Трасса API](direct-login.json)

## C22 — системные «Файлы» Android

Один и тот же контрольный JPEG дважды выбран через DocumentsUI с разрешением `ACCESS_MEDIA_LOCATION`. При включённой настройке скачанный JPEG совпал с исходником по SHA‑256. Широта и долгота совпали с EXIF. При выключенной настройке все шесть значений координат стали `0/0`, широта и долгота отсутствовали в ответе ленты. Дата обеих записей осталась 17 мая 2024 года.

[Включено](c22-native-on.png) · [Выключено](c22-native-off.png) · [EXIF и ответы сервера](c22-native.json)

## Открытка дня

Подготовили два названных дня. У первого была одна фотография и автоматическая обложка. Изображения в открытке ленты и в «Днях» совпали по SHA‑256. У второго дня была только текстовая запись. Открытка в ленте показала дату, название и подпись без места под снимок.

## Ссылка на архив из письма

В обеих ветках видна кнопка «Скачать». У другой учётки по тому же адресу показано «Нет доступа». В старом реестре для этой ветки указан текст «Вас нет в этом круге».

## Уведомления о квоте

Первый запрос тестового владельца отклонили, второй одобрили. Локальный SMTP принял «Просят место для круга» для администратора и два письма владельцу — «В месте отказали» и «Кругу дали место». После одобрения сервер показал 2 000 000 байтов. Интерфейс запросов и очередь на заполненной квоте проверены на OPPO в предыдущем прогоне.

## Уход с сервера

У владельца виден список собственных кругов, действие ухода погашено. Тестовому участнику показаны «Исчезнет», «Останется в кругах» и «Необратимо». После включения стирания имени ввод точного имени сервера разблокировал подтверждение. Единственный сервер исчез из сессии, открылся вход. Старый ключ получил HTTP 403. В ленте владельца запись осталась с подписью «Без имени».
