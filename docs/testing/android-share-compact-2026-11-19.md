# Android · компактная шапка выбора круга

19 ноября 2026. [План 50, этап 3](../plans/50-android-wrapper.plan.md).
Замечание владельца о высоте шапки относится в этом предпросмотре к экрану
«Новая запись» перед выбором круга. Смысл сценария принят в плане, вёрстка
отдельного экрана выбора круга ждёт утверждения.

Текущий экран `web/src/routes/share/+page.svelte` из `29723025` использует
строки кругов из `docs/visual/screens.html#e2-1` (`825921cc`).
Вариант использует штатный компактный `BackBar` из кадра поиска
`docs/visual/screens.html#e2-19` и его Svelte-реализации
`web/src/routes/dev/smoke/e2-19/+page.svelte` (`6bc2b317`).
Настольный вариант импорта открывает редактор уже выбранного круга,
как зафиксировано в [протоколе этапа](android-share-live-2026-11-19.md).

Предпросмотр собран из `b5a90136` с одной поправкой в копии
`web/src/routes/share/+page.svelte`:

```diff
-<FormLayout app title="Новая запись" onback={() => void cancel()}>
+<FormLayout app compact title="Новая запись" onback={() => void cancel()}>
```

сценарии с фото и видео. Размер 720 × 1600, viewport 360 × 728 CSS px,
DPR 2, светлая тема.
