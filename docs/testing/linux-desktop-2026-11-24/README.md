## window.png

Настоящий кадр окна Linux-сборки (`wynd-desktop` 0.4.5) в Xvfb,
Ubuntu 24.04, GTK3/WebKit2GTK 4.1. Видны своя полоса заголовка, экран
«Войти в Wynd», поле адреса и «Дальше». Снят в CI `import -window root`
(1024×900). Это существующий экран; новых элементов нет.

## settings-autostart.png

Настоящая отрисовка Svelte-экрана «Настройки → Приложение» в headless
Edge с Linux-UA и мостом `__wyndDesktop`; ответ `Autostart` — включён.
Это **не окно Linux**: браузерный рендер проверяет текст и строку
автозапуска, а не chrome приложения.

- На всех платформах: «При входе в систему откроется Wynd», «Запускать
  при входе в систему». Разделения Windows/Linux больше нет — решение
  владельца 24.11.
- **Принято владельцем 24.11 («Принимаем»).** Утверждён текст и строка
  автозапуска на этом кадре; это не приёмка всей Linux-версии и не
  приёмка трея — он ещё не снят.

## signer-linux-extras.png

Настоящая отрисовка окна «Wynd Подпись» из стенда `cmd/wynd-signer/frontend/mock`
с данными выпуска 0.5.0. Окно показывает, что кроме exe проверяются Linux
`.deb` и AppImage: сумма из `SHA256SUMS` и удостоверение сборки; для каждого
файла выкладывается свой `.sig`. Это внутренний инструмент, не экран Linux-приложения.
Кадр ждёт приёмки.

## Не снято

- **Меню трея.** Нативное StatusNotifierItem; в Xvfb нет хоста трея.
  Попытка поднять standalone-хост не дала видимого меню. Для кадра нужен
  рабочий стол с AppIndicator (GNOME/KDE/XFCE). Макет вместо него не
  рисовался.
- **Кнопка «Открыть в приложении»** в Linux-браузере пока не включена.
- Живой вход, лента, SSE, скачивание и запись — на Linux-машине с
  рабочим столом, реестр §12.
