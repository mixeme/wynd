# Единый вид выбора файла архива в Мастерской — 27.11.2026

Владелец 27.11 по трём снимкам окна Мастерской 0.4.10: «Три экрана про выбор
файла архива, но выглядят по-разному. Нужно выработать единый стиль». Выбран
вариант «ссылка везде»: подпись, под ней подчёркнутая ссылка; выбранный файл —
строка с «другой». 11б не меняется, 11в и 11г получают ссылку, 11г — подпись
«Архив».

расхождение.

## Изменение

`cmd/wynd-workshop/frontend/src/Archives.svelte`, только блок выбора исходного
файла:

- **11б «Объединить архивы»** — не меняется: подпись «Архивы», строки с «✕»,
  ссылка «+ добавить архив».
- **11в «Разделить архив»** — пустое состояние: `Button variant="ghost"`
  «Выбрать архив» заменена на `TextButton class="link under"` «выбрать архив»
  в том же `div.ins-more`, что и ссылка 11б. Заполненное состояние не менялось.
- **11г «Лента из полного архива»** — добавлена подпись `Label` «Архив» над
  строкой файла; пустое состояние: кнопка «Выбрать файл .wynd» заменена на
  ссылку «выбрать файл .wynd» в `div.ins-more`. Поле пароля, «Сохранить как»
  и строка файла не менялись.

Новых компонентов `$ui` нет: только `Label`, `FileRow`, `TextButton`, `Button`,
`FieldLine`. В `cmd/wynd-workshop/frontend/src/gallery/scenes.ts` добавлены
пустые сцены `11b-merge-empty`, `11v-split-empty`, `11g-full-empty`; в
заполненных сценах текст нажатия приведён к новым ссылкам в нижнем регистре.
