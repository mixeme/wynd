# Android: каркас и первый запуск — 2026-11-16

## Область шага

По поручению владельца начаты подготовка и Java-каркас плана 50.
Среда подготовлена отдельным коммитом `09ef52bc`; параметры и архивы —
[протокол среды](android-environment-2026-11-16.md).

В `android/` добавлены Gradle wrapper с SHA-256 дистрибутива, приложение
на системном WebView, отдельный debug-пакет `mixeme.wynd.debug`, проверяемая
политика origin и повторяемые команды сборки и проверки телефона.
Минимум текущего каркаса — API 21, compile/target — API 36. Внешних библиотек
во время исполнения нет; JUnit используется только для тестов.

Сверены [правила application ID](https://developer.android.com/build/configure-app-module):
`mixeme.wynd` и отладочный суффикс допустимы. Для установки через ADB
проверка разработчика не требуется по
[официальному FAQ Android](https://developer.android.com/developer-verification/guides/faq?hl=en).
Ключ выпуска владельца не создавался; для debug используется отдельный ключ
в `D:\android-env\keys`, release-вариант пока выключен. Это не подготовка
публичного выпуска APK и не проверка условий будущего магазина.

Учтены решения настольного приложения: независимые роли источника и учётки,
настоящий origin, прямой сетевой путь API/SSE и отсутствие ложного объявления
настольных возможностей. Подробности — [README каркаса](../../android/README.md).
Прокси и `__wyndDesktop` с Windows в Android не переносятся.

## Проверка на телефоне

- Устройство: OPPO CPH1931, Android 10 / API 29, системный WebView
  `com.google.android.webview` 130.0.6723.107. Это не realme 8 из плана 50.
- APK установлен через `adb install -r`; `am start` запустил Activity.
- Отдельный сервер слушает только `127.0.0.1:7696`; данные изолированы в
  `dev/data-android-skeleton`. Телефон получает доступ через `adb reverse`.
  Сервер и reverse оставлены работающими для просмотра установленного каркаса.
- `scripts/test-android-webview.mjs` проверил настоящий WebView через его
  отладочный CDP: существующий экран входа отрисован; маршрут приглашения
  открыт; системная «Назад» вернула на вход; переход скриптом на чужой origin
  отменён; собственный временный маркер localStorage пережил `am force-stop`
  и повторный запуск. Маркер после проверки удалён.
- Необработанных ошибок JavaScript в прогоне нет, ошибок `AndroidRuntime`
  в процессе Wynd после повторного запуска нет.
- `secureContext` и наличие Service Worker API подтверждены. Это ещё не
  проверка фактического восстановления офлайн или обновления SW.
- Временные CDP-forward закрыты. Основной JDK в обычной оболочке остался
  `C:\Program Files\BellSoft\LibericaJDK-11\bin\java.exe`.
