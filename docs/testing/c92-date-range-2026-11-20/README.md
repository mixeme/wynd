# C92 — поля периода «с — по» на телефоне, принятая вёрстка (2026-11-20)

Основа — утверждённый `DateRange` (кадр 2.19 / C84, `docs/testing/c83-c86-frames-2026-11-12`,
`c84-period2.png`). Дефект: на Firefox Android (OPPO CPH1931, 720×1560 DPR 2)
родная кнопка календаря остаётся внутри поля, и значение «19.11.2026» не
помещается — год обрезан (протокол 17.11,
проверка 3, снимки 13–15).

Принятый вариант владельцем 2026-11-20 («Да»), кадры — реальный рендер
приложения на этом телефоне (локальный стенд 7676 + vite, клиент 0.53.2 с
правкой; круг «Дом Ани», поиск → «Период»):

- `c92-vH-empty.png` — пустое поле: «с»/«по» (15 px, отступ 14 px), свой значок
  календаря (`i-day` из общего набора, на месте родного — 20 px от края),
  стрелка; подсказки «dd.mm.yyyy» нет.
- `c92-vH-dated.png` — выбрано 20.11.2026: значение целиком, тот же свой значок
  (родной значок браузера закрыт плашкой цвета поля, нажатия проходят к полю),
  зазор год↔значок ≈ 16 px, значок↔стрелка ≈ 10 px.
- `c92-vH-compare.png` — оба состояния рядом.

Проверка кадра — протокол стенда (каталог проверки убран при чистке dev/), отклонённые варианты 1–6
отмечены в [плане 46](../../plans/46-open-questions-and-debt.plan.md) (C92).
SHA-256 — в `checksums.sha256`. Повторная проверка на телефоне после выпуска —
[реестр](../pending-device-checks.md), §1.7.
