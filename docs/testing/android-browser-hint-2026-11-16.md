# Браузерная рекомендация внутри Android — 2026-11-16

Отдельный небольшой шаг этапа 1 [плана 50](../plans/50-android-wrapper.plan.md).
На настоящем WebView Wynd показывалась рекомендация Chrome/Vivaldi из веб-версии.
Это не способ сменить WebView приложения, поэтому внутри Wynd плашка не нужна.

`showBrowserHint` использует существующий `androidPort()` как признак оболочки.
Проверка не отправляет сообщения мосту и не меняет localStorage. В обычном
браузере и при отсутствии настоящего port сохраняются прежние UA/крестик-правила.
Новые CSS, компоненты, размеры и расположение элементов не добавлялись.
