## Найденный дефект: отмена диалога показывала ошибку

В v3 отмена родного диалога возвращается ошибкой внутренней библиотеки Wails (`internal/go-common-file-dialog`: «cancelled by user»), а в v2 — пустым путём. Первая сборка вывела в окне «RuntimeError: Не удалось открыть окно выбора файла: cancelled by user» после обычного «Отмена» (живой прогон, до исправления).

Исправление — `dialogCancelled` в `cmd/wynd-signer/main.go`: отмена считается отказом (`ChooseKeyPlace` → пустой путь, `ChooseKey` → состояние без изменений). Импортировать библиотеку нельзя (internal модуля Wails), поэтому сверяется текст ошибки; охраняющий тест — `TestDialogCancelled` в `cmd/wynd-signer/dialogs_test.go`. После пересборки отмена обоих диалогов оставляет окно без сообщений об ошибке — проверено.
