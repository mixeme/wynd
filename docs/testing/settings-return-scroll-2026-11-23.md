# Возврат в «Настройки круга» — замер до/после (C125, 2026-11-23)

Владелец прислал запись с телефона: после возврата из «Архива круга» экран
настроек «едет куда-то» — встаёт примерно на 400 px ниже прежнего места и через
~0,4 с уезжает на прежнее. Тот же снимок показывает, что прыжок идёт в два шага
(+32 px — подпись «Уведомлений», затем +370 px — блок «Место»/«Архив и
очистка»). Задача — вернуть экран на прежнее место без промежуточных сдвигов.

## Причина

Экран настроек рисует первый кадр из снимка (C100), но в снимок не входили две
вещи, которые измеряются позже отдельными запросами:

- квота (`GET /circles/{id}/quota`) — блок «Место» и строка «Архив и очистка»,
  только владельцу;
- подпись уведомлений (`GET /circles/{id}/notify_prefs`) — вторая строка
  «Уведомлений».

Первый кадр на 151 px короче конечного экрана (на телефоне — около 400 px:
там крупнее шрифт и есть шкала квоты). Восстановление прокрутки ставит прежнее
`scrollTop`, но содержимого над ним ещё нет — экран показывает не те строки, а
когда квота и подпись доезжают, содержимое над точкой возврата растёт, и строки
под ним уезжают вниз. Правка переносит оба ответа в один снимок экрана: первый
кадр сразу полной высоты.

## Метод замера

Стенд — `dev/scrollfix-run/` (каталог `dev/` не в git, это рабочая площадка):

- сервер `wynd.exe` из текущего дерева (клиент вшит) на `127.0.0.1:7878`,
  данные — копия стенда C92, сессия — токен anya из `dev/c92/seedA.json`;
- прокси `proxy.mjs` на `127.0.0.1:7879` → 7878 задерживает `/quota` на 450 мс,
  `/notify_prefs` — на 200 мс (окно поздней отрисовки как на телефоне);
- headless Edge 412×915 DPR 2, обход service worker (`Network.setBypassServiceWorker`),
  профиль `edge-profile`, CDP 9411;
- `probe.mjs`: вход в круг «Семья» → `/circles/<id>/settings`, прокрутка так,
  чтобы строка «Скачать свой архив» была в середине, затем тап по строке →
  «Архив круга» → стрелка «Назад». До нажатия включается запись по кадрам
  (`requestAnimationFrame`): `scrollTop`, `scrollHeight` контейнера `.form-body`,
  `getBoundingClientRect().top` строки «Скачать свой архив», наличие блока
  квоты (текст «ограничение не задано»).
- Числа «до» — сборка `wynd.exe` до правки (тот же профиль, снимок прежнего
  формата), «после» — сборка с правкой.

## Результат

Место прокрутки одно и то же (`scrollTop` 217), строка «Скачать свой архив»
до возврата — `y=648`.

**До правки** (снимок без квоты, ответы доезжают по очереди):

| после «Назад» | высота содержимого | строка «Скачать свой архив» |
| --- | --- | --- |
| первый кадр | 1 244 | 713 (вверху, прокрутка ещё 0) |
| прокрутка восстановлена | 1 244 | 647 |
| подпись уведомлений | 1 262 | 666 (+19) |
| блок «Место» | 1 395 | 799 (+133) |

Строки уехали вниз на 152 px за ~0,5 с — на телефоне тот же сдвиг около 400 px,
как в записи владельца.

**После правки** (квота и подпись — в снимке, первый кадр полной высоты):

| после «Назад» | высота содержимого | строка «Скачать свой архив» |
| --- | --- | --- |
| первый кадр | 1 395 | 865 (прокрутка 0, один кадр) |
| прокрутка восстановлена | 1 395 | 648 |

Высота не меняется, строка стоит на месте; промежуточного положения с неполным
содержимым нет. Один кадр (8–12 мс) с содержимым вверху до восстановления
прокрутки глазом не виден.

## Что осталось

Повтор на телефоне после выпуска сервера: вернуться из «Архива круга» в
«Настройки круга» при прокрученном экране — экран должен остаться на месте
(реестр проверок, §10). Снимок прежнего формата после обновления один раз не
рисуется владельцу (ждёт сеть), иначе первый кадр снова был бы короче экрана;
после первого успешного ответа снимок полный.
