## Вторая редакция — системный шрифт (ждёт ответа)

Golos убран из меню: `font: menu` — системный шрифт меню Windows (Segoe UI
9 pt при 100%), он же следует настройкам текста Windows. `line-height: 1.45`
сохранён, запасные `var(--ui)`/12 px оставлены на случай, если системный
шрифт не поддержан. Ширина 92 px, строки 24 px, поля 12 px, бумага, чернила,
рамка и разделитель не менялись.

Рендер: собран `dist\wynd-desktop-traytest.exe` из этого дерева (frontend
`npm run build`, Go с тегами `desktop,production`, без ключа подписи). Меню
показано временной переменной `WYND_TRAY_MENU_PREVIEW` (в сборке её нет),
снято PrintWindow с `PW_RENDERFULLCONTENT`; окно 92 × 56, 100%, тема бумага.
`menu-system.png` — SHA-256 `7d3dbaeb…`, не эскиз.
