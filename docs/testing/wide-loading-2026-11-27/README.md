# Широкое окно — значок загрузки по центру своей панели (27.11.2026)

## Основа

- Широкий каркас плана 76: `web/src/lib/layouts/CirclesSplitLayout.svelte`, правила `.ph.app.split` в `web/src/lib/styles/ui.css`, принятые кадры — [проверка плана 76](../wide-sections-2026-11-27/README.md), коммиты `70812502`, `f3962e38`, `72e27239`, `702d21fe`, `b3ab6e78`.
- Значок загрузки — `Loading.svelte`: не в панели, а `position: fixed; inset: 0` на всё окно. Так решено в C10, чтобы знак не прыгал от высоты разных шапок на телефоне. В широком окне правая панель — только часть окна, и знак вставал в центр окна (530 px), а не панели (700 px).
- Изменяется только положение знака в двухколоночном каркасе; размеры, панели, шапки, строки и всё оформление — прежние. В одной колонке (телефон и окно уже 1060 px) поведение не меняется.

## Изменение

`web/src/lib/styles/ui.css`, коммит `c64e4bd6`:

```css
.ph.app.split .split-side .loading:not(.compact),
.ph.app.split .split-main .loading:not(.compact) {
	position: absolute;
}
```

`Loading` остаётся `fixed` вне split; в панели он абсолютный внутри `.ph` этой панели (`.ph` уже `position: relative`), `inset: 0` — по границам панели. Правило общее для левой и правой колонки: в левой так же центрируется загрузка улицы.
