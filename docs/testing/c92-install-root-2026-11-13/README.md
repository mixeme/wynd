## Решения, закреплённые этой приёмкой

- Поле стоит **на экране установки** (осмотр сервера, где выбирают адрес сайта), а не в форме «Добавить сервер»: каталог нужен только при установке. Слова владельца: «Зачем это поле при добавлении сервера? Оно нужно только при установке».
- Поле видно только когда Wynd на сервере ещё не установлен.
- Значение по умолчанию — `/opt/wynd`; каталог называется в плане установки и запоминается в профиле; у устоявшейся установки меняется только переездом.
- Окно приложения остаётся 760 × 560; поле в нём уходит под сгиб, потому что экран и так листается из-за списка находок.
