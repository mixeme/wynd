## Синхронизация исходников и исчезнувшие ссылки

Сначала Gitea отклонил push сохранённой авторизацией. Повторный `git push origin main` по указанию владельца прошёл: `main` в Gitea и GitHub содержит `6f87c502`.

Оба тега при выпуске отправлялись напрямую в GitHub, а не через `origin`. **При сверке перед этой записью оба тега уже отсутствовали в GitHub.** Публичные страницы `v0.52.0` и `desktop-v0.2.0` отвечали 404. В авторизованном списке `v0.52.0` остался черновиком с untagged-адресом, а выпуск `desktop-v0.2.0` не находился. Локальные теги по-прежнему указывают на `6f87c502`; в Gitea теги не отправлялись.

Причина исчезновения не установлена. Этот абзац фиксирует более позднее состояние и не отменяет записанные выше результаты первоначальной проверки публикации. Перед следующим выпуском нужно восстановить теги и публичные выпуски штатным порядком через Gitea и повторно проверить их после зеркалирования. Работающие VPS это состояние GitHub не изменило.

## Диагностика раздела «Интерфейс»

Владелец сообщил, что в свежей сборке Настольного нет «Настройки → Приложение → Интерфейс». Проверка показала:

- раздел присутствует в исходнике тега и в клиентском node 102, который отдаёт сервер 0.52.0;
- `internal/desktop.Proxy` вставляет `window.__wyndDesktop` в HTML актуального `wynd.mixfed.ru`;
- сохранённый настоящий кадр WebView2 из проверки реализации показывает этот раздел.

Затем владелец подтвердил: **«Раздел есть. Проблема была в старом сервере.»** Код менять не потребовалось. Правило совместимости: оболочка 0.2.0 открывает старые серверы, но раздел управления источником интерфейса появляется только с клиентом сервера **0.52.0 или новее**. Обновление одного exe не обновляет клиент старого сервера.
