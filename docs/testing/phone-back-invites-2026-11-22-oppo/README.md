# OPPO · возвраты, день и приглашения · 22.11.2026

OPPO CPH1931, Android 10, Firefox 132.0, 720 × 1600. Локальный Wynd 0.53.4 из `9aa34258`. Использованы тестовые круги и учётки. Снимки экрана сняты через ADB.

## План 61 — возврат в настройки и квоту

Из настроек «Перенести на другой сервер» открыл экран переноса. Стрелка и системная «Назад» вернули в настройки круга. Через «Архив и очистка» и «Сохранить круг в файл» открыт полный архив. Обе кнопки вернули в «Архив и очистка» на маршрут квоты.

## Отклики из найденного дня

По запросу «Кедровый день OPPO» открыт результат типа «день». На экране активна вкладка «Дни». На «Откликах» виден счётчик 1. Вкладка показала комментарий второго участника к записи дня. Системная «Назад» открыла поиск с прежним запросом и тем же результатом.

## C82 — повтор настройки приглашений

В круге с двумя участниками сменили право «Создать приглашения» на «Могут все», затем на «Только владелец». Каждая смена добавила одну строку в журнал. Сразу после каждой смены ещё раз нажали выбранное значение. Повторный запрос завершился HTTP 200, число строк осталось прежним в обоих случаях.

## C110 — приглашение с внешней страницы

Два свежих одноразовых приглашения открыты с отдельных HTML-страниц на другом локальном адресе в той же вкладке Firefox. На форме имени до вступления использовали стрелку и системную «Назад». В обоих случаях Wynd открыл список кругов со строкой «Вас позвали — выберите имя». Страница-источник ни в одном из двух прогонов не открылась.

## План 61 — возврат из будильника дня

В двух тестовых кругах опубликовали первую запись за день прямо из ленты. После публикации появилось приглашение назвать день. В обоих случаях нажали «Назвать день». Стрелка и системная «Назад» вернули из открытого дня в хронологию того же круга.
