# Android · сохранённый интерфейс при недоступном сервере

19 ноября 2026. OPPO CPH1931, Android 10, WebView 157.0.8103.50.
Тестовый Wynd `0.1.0-debug` с ПК3 из `bf248c97`. Для проверки выделен
временный адрес на петле ADB. Рабочий каталог источников временно сохранён
побайтовой копией.

Стенд отдал production-файлы Wynd 0.53.0 из отдельной копии `web/dist`.
Синтетический API сообщил имя тестового сервера и закрытую регистрацию.
Вход и операции с учётной записью не выполнялись. IPv6 на OPPO не смог
подключиться к ADB reverse. На IPv4-петле Wynd намеренно пропускает
автоматическую регистрацию, поэтому штатный `/sw.js` зарегистрирован
вручную из CDP. Поведение автоматической регистрации на HTTPS остаётся
отдельной проверкой.

SHA-256 проверенной копии:

- `sw.js` — `5a8056a419c0d2acfd03c5c7a517e9859ac866d9962a228240bf3dc7b72521bb`;
- `index.html` — `b84988cf1bd307f29b15826904efda50668b7b88f49ad2c88f40860d4aff5b8a`.

## Фактический результат

- Пока сервер работал, воркер активировался, Cache Storage содержал
  precache Workbox, а навигация на экран входа прошла под его контролем.
  Это подтверждено в WebView по `controller.scriptURL` и `workerStart`.
- При остановленном сервере новое открытие маршрута приглашения из
  работающего WebView привело к локальному ПК3 «Сервер не отвечает».
  Факт проверен в новом локальном документе через CDP и снимок экрана.
- В отдельной попытке после `am force-stop` и запуска без сервера WebView
  выбранного источника не появился за время наблюдения. При перезапуске
  с доступным сервером условие «экран входа под управлением воркера»
  также не было выполнено за время ожидания. Потеря записей из Cache Storage
  этими наблюдениями не установлена.

Сохранённый интерфейс после отказа на этом стенде не подтвердился.
Проверка этапа 1 остаётся открытой. Снимки `online.png` и
`offline-pc3.png` в `dev/screens/shots/android-startup-cached-2026-11-19/`
сняты через `adb screencap` и осмотрены. Область WebView 360 × 728 CSS px,
DPR 2, масштаб 100%, светлая тема.

После смены WebView тестовый CDP-запрос навигации остался ждать ответ от
уничтоженной страницы. Снимок ПК3 получен из отдельного подключения к
новому WebView. Зависший тест остановлен. Данные только временного origin
удалены, каталог восстановлен побайтово, USB-перенаправления сняты.
Фактический адрес страницы и восстановление сохранены в
`offline-observed.json` и `restoration.json`.
