# Wynd Push в рабочем окне Мастерской

28 ноября сверена реализация из `c3b151cf`. Исходники окна —
`cmd/wynd-workshop/frontend/src/Window.svelte` и `App.svelte`, логика
профиля — `lib/panel.svelte.ts`. Формы используют данные выбранного
профиля и команды Wails.

В форме установки из `d83b7902` используется «домен», пример —
`example.net`. По следующему уточнению владельца в `3b686247` подсказка
выравнена по левому краю поля, зазор 8 px. Новый кадр снят в Chromium
при 1024 × 760 CSS px, DPR 1, светлой теме. Зазоры проверены и в
760 × 560 и 680 × 501. [Исправленный кадр установки](install-domain.png).

Снимки выполнены в Chromium (Edge) через DevTools Protocol. Область окна
1024 × 760 CSS px, масштаб 100%, DPR 1, светлая тема, как у принятых кадров.
Для повтора запустить `npm run dev` из `cmd/wynd-workshop/frontend`.
На `gallery.html?size=baseline&scene=2-inspect-new` заполнить каталог
`/opt/wynd` и включить галочку. На
`gallery.html?size=baseline&scene=7a-push` открыть «Настроить», затем меню
срока или подтверждение удаления. В кадрах видна тестовая версия ntfy.

Осмотрены шапка, вкладки, список серверов, контекст профиля, переносы
текста, команды сервиса и нижние действия. При пустом поддомене после
включения Push «Дальше — план» выключена. Подтверждение сохраняет
компоновку принятого кадра и сообщает о возможном кратком перезапуске Wynd.

## Зазоры и управление

Замеры в 1024 × 760, 760 × 560 и 680 × 501 совпали во всех трёх размерах.

| Замер | CSS px |
| --- | ---: |
| Каталог → строка Push, строка Push → пояснение, галочка → поле | 8 |
| Заголовок настроек → состояние | 4 |
| Состояние → команды, команды → подпись срока | 16 |
| Подпись срока → поле | 4 |
| Поле → подсказка | 8 |
| Ширина поля и открытого меню | 144 |

Горизонтального переполнения правой панели нет. Действие удаления справа
внизу доступно после прокрутки в минимальном размере. Проверены шесть
вариантов срока, отмена, запуск, остановка, запрос подтверждения и возврат
в пульт после удаления. Тесты интерфейса подтвердили привязку к выбранному
профилю, отправку поддомена и повтор сохранения и удаления после сбоя.

Сверка относится к принятым 28 ноября формам и выполнялась на подставном
сервере галереи. Сборка Windows прошла. Живой проход из нативного окна
в Docker и доставка на телефон остаются в [реестре проверок](../../../testing/pending-device-checks.md#32-wynd-push-в-мастерской-план-76).
