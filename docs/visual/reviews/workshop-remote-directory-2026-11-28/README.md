# Выбор каталога на сервере в Мастерской

Владелец запросил диалог выбора каталога на удалённой машине.
28.11 владелец утвердил [кадр выбора пустой папки](#приёмка-2811).

## Основа и изменения

Основа — кадр `2` «Осмотр — до любых изменений» из
[workshop-servers.fragment.html](../../workshop-servers.fragment.html)
в `b827aff829e43857700e1eacac833862e3ea1a06`. Действующая форма
`cmd/wynd-workshop/frontend/src/App.svelte`, сцена `2-inspect-new`,
отрисована из `3b686247`. [Кадр основы](../wynd-push-window-2026-11-28/install-domain.png).

- [Поле](directory-field.png) получает кнопку «Выбрать…» справа.
  В поле можно вводить путь вручную, включая путь к будущей папке.
- [Диалог](directory.png) показывает выбранную машину, текущий путь,
  папки и переход на уровень выше. В примере исходный `/opt/wynd` ещё
  отсутствует, поэтому открыт `/opt`. Такой системный каталог можно
  просматривать, выбрать для установки можно подходящую папку внутри.
- [Подтверждение папки](directory-selected.png) подставляет `/srv/wynd`
  в поле. Отмена оставляет прежнее значение. Проверка выбранного пути
  выполняется при составлении плана установки.

Предпросмотр использует существующие `RawSheet`, `FieldLine`, `Input`,
`MarkRows`, `MarkRow`, `TextButton`, `Hint` и `FootBar`. Для списка
у `RawSheet` предусмотрено собственное содержимое внутри его оболочки.

## Воспроизведение и границы

В отдельной рабочей копии исходника `3b686247` последовательно применить
[актуальный патч Push](../wynd-push-add-2026-11-28/add-preview.patch) и
[патч диалога](directory-preview.patch). Запустить `npm run dev` из
`cmd/wynd-workshop/frontend` и открыть
`gallery.html?size=baseline&scene=2-inspect-new&directory-preview`.
Для первого кадра диалога открыть «Выбрать…» при `/opt/wynd`.
Для второго перейти вверх, открыть `srv`, затем `wynd`.

Кадры 1024 × 760 CSS px сняты через DevTools Protocol в Chromium, DPR 1,
масштаб 100%, светлая тема. Осмотрены поле, рамка диалога, путь, список
и действия. В 1024 × 760, 760 × 560 и 680 × 501 проверены попадание
диалога в окно, зазор 8 px до подсказки и 16 px до действий, выбор папки
и закрытие по Escape без изменения поля.

Диалог отрисован с подставными папками. Код чтения каталогов выбранного
профиля в `bd8bca02` отдельно проверен с подставным SSH. Подключение
диалога к этому коду и проверка фокуса в нативном окне остаются открытыми.

## Дерево каталогов

По запросу владельца подготовлен второй вариант компоновки.
[Исходный диалог](directory.png) из `a8aefc2e` — основа сравнения.
В [новом кадре](directory-tree.png) папки вложены в дерево, стрелки
раскрывают ветки на месте. Нажатие на имя выбирает папку и показывает
её путь в нижнем поле. [Кадр с выбранной папкой](directory-tree-selected.png).
По уточнению владельца у каждой папки есть контурный значок из Wynd UI.
Зазор между стрелкой и значком уменьшен до 4 px.

Для воспроизведения взять `ddc6bf9e`, последовательно применить оба патча
из предыдущего раздела и [патч дерева](directory-tree-preview.patch).
Маршрут галереи тот же. Выложенные кадры отрисованы с подставными папками
в Chromium при 1024 × 760 CSS px, DPR 1, масштабе 100% и светлой теме.

Основа для правки значков — оба снимка дерева из `f4ec70cf`. Парное
сравнение при 1024 × 760 показало изменения только возле имён и значков
в строках списка. В трёх размерах проверен один значок на видимую папку,
раскрытие, выбор и подстановка пути. Прошли `svelte-check` и `check:ui`.

В 1024 × 760, 760 × 560 и 680 × 501 проверены размеры окна, зазор 8 px
под полем, раскрытие и сворачивание веток, выбор `/srv/wynd` и отмена
по Escape без смены исходного пути. Репозиторный метод чтения папок
остаётся основой подключения дерева после утверждения.

## Новая папка

Основа правки — дерево со значками из `ddc6bf9e`. Кнопка «Новая папка»
размещена справа от выбранного пути. Она переводит фокус в
[поле имени](directory-new-folder.png), рядом показан каталог
создания. После «Создать» [новая папка выделена в дереве](directory-tree-selected.png).
«Выбрать папку» отдельно переносит её путь в установку.

Снимки получены из актуального патча дерева при 1024 × 760 CSS px,
светлой теме, масштабе 100% и DPR 1. На первом кадре сравнили
положение диалога, текущий путь, стрелки, значки и нижние действия
с кадром из `ddc6bf9e`. В 1024 × 760, 760 × 560 и 680 × 501
проверены зазор 4 px, фокус, занятое имя, отмена, добавление строки
и подстановка пути. В галерее папки подставные. Метод создания из
`bafbba22` отдельно проверен Go-тестами с подставным SSH.

## Выбор пустой папки

В [подсказке под путём](directory-tree.png) теперь написано «Нажмите на
имя вложенной папки». Клик по имени выделяет папку, даже если у неё нет
стрелки. В [кадре с пустой папкой](directory-empty-folder.png) выделена
`/opt/apps`. Кнопка «Выбрать папку» переносит этот путь в установку.

Сравнили прежний кадр дерева и новый в Chromium при 1024 × 760 CSS px,
светлой теме, 100% и DPR 1. Различие на снимках ограничено текстом
подсказки. В 1024 × 760, 760 × 560 и 680 × 501 проверили выбор `/opt/apps`,
подстановку пути, раскрытие `/srv` без смены выбора и зазор 8 px до поля.
Проверка выполнена в Svelte-галерее с подставным деревом.

[начальный кадр](directory-tree.png) и [форму создания папки](directory-new-folder.png).
