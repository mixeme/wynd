# C142 — поле ввода с акцентной рамкой на всех экранах

**Вёрстка ждёт приёмки владельца.** Смысл правила принят в разборе 26.11: поле, которое можно менять, выглядит одинаково в клиенте и оболочках; мягкая рамка — только у статичных значений и в админке.

## Основа

- Утверждённые кадры клиента: `docs/visual/screens.html`, 1.1, 1.6, 7.41 и другие — поле `fld act` (акцентная рамка). Код: `web/src/lib/styles/ui.css:1757` (`.fld`) и `:1892` (`.fld.act`), `web/src/lib/components/forms/Input.svelte`.
- Утверждённые кадры окна: `docs/visual/desktop.html`, ПК1 «Первый запуск» (утверждён 29.10.2026) — поле `fld` без `act`; ПК2 «Вход на выбранный сервер» — уже `fld act`. ПК1 и ПК2 противоречили друг другу; по правилу C142 обе основы теперь с акцентной рамкой.

## Изменение

Только рамка поля «Адрес сервера или приглашение» на экране окна «Войти в Wynd»: `--line` `#dfd8cd` → `--c` `#2b2724` (в оболочке `--c` = `--ink`). Это следствие пропа `active` у `Input`; фон, отступы, скругление, подпись и кнопка не менялись. Заодно `active` добавлен ещё пяти полям: «Разделить круг», приём переноса, стартовый экран Android, адрес на первом запуске окна, интервал и число копий в настройках окна.

## Рендер

- Исходник: `cmd/wynd-desktop/frontend` (vite 6.4.6), порт 5179, экран без параметра, `?update=none` (полоса обновления скрыта).
- Команда: headless Edge (`msedge.exe --headless=new --disable-gpu --hide-scrollbars --virtual-time-budget=6000 --window-size=760,780 --screenshot=…`).
- Размер 760 × 780 CSS px, DPR 1, светлая тема; заголовок окна рисует сам интерфейс, поэтому он в кадре. Версия в заголовке мока — 0.2.0; в кадре владельца 0.4.2.
- Адрес в поле не заполнен (в моке нет сохранённого сервера), поэтому кнопка «Дальше» погашена. Предмет кадра — поле; значение и кнопка не менялись.
