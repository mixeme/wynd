# C143 — окно без полос-подложки: кадры

**Вёрстка принята владельцем 2026-11-26 («Принимаем»).** Кадры ПК5/ПК6/ПК6а/ПК7 в `docs/visual/desktop.html` обновлены на бумажный фон окна.

## Основа

- Окно по умолчанию 760 × 780 (`cmd/wynd-desktop/main.go:838`), колонка интерфейса — 720 (`--app-max-width`, `web/src/lib/styles/tokens.css`).
- До правки: колонка 720 в iframe, остальные 20 px по бокам красила оболочка цветом `--app-gutter` `#e0dbd2` (`.server-host`, `.page-host`, `body` в `cmd/wynd-desktop/frontend/src/app.css`). Утверждённые кадры ПК6/ПК6а/ПК7 рисовали ту же подложку, но на 1000 px она 140 px; на 760 — 20 px и читалась артефактом. Экраны оболочки (ПК1 «Первый запуск», ошибки) подложки не имели — отсюда разнобой.
- Настоящий рендер до правки — снимок окна владельца (`before-760.png`), 760 × 780.

## Изменение

Только фон оболочки: `body`, `.page-host`, `.server-host` — `--app-gutter` → `--paper`. Колонка интерфейса остаётся 720, её края больше не видны; окно — один бумажный лист. Браузер и PWA не тронуты (там клиент рисует поля сам). Содержимое, отступы, шапка и действия не менялись.

Кадры ПК5/ПК6/ПК6а/ПК7 в `docs/visual/desktop.html` обновлены: фон окна бумажный, подложки нет.

## Рендер

- До: `before-760.png` — снимок окна владельца (0.4.2), 760 × 780, светлая тема; левый край крупно — `before-edge.png`.
- После: shell vite 5179 (`cmd/wynd-desktop/frontend`) + mock `?screen=app&update=none`, клиент — vite 5173, API — стенд `dev/wynd-stand-72.exe` на 7678 (временный proxy в `web/vite.config.ts`, после съёмки возвращён); headless Edge + CDP, DPR 1, светлая тема.
- `after-760.png` — 760 × 780 (как окно владельца); `after-1000.png` — 1000 × 660 (ширина утверждённых кадров).
- В карточке сервера адрес `127.0.0.1:5173` и «Открыт для новых» — это стенд, а не wynd.mixfed.ru; версия в заголовке мока 0.2.0. На предмет кадра (фон окна) не влияет.
