Основа — утверждённый кадр `7а` «Пульт работающего Wynd» из [workshop-servers.fragment.html](../../workshop-servers.fragment.html), коммит `b827aff829e43857700e1eacac833862e3ea1a06`. Текущая оболочка и пульт отрисованы из `cmd/wynd-workshop/frontend/src/Window.svelte` и `App.svelte`, сцена `7a-server`, коммит `e4d56a8228a6f11fa8903991040a239e77043acb`.

Под строкой переезда показана строка «Сервер уведомлений работает» с версией ntfy и действием «Настроить». Она собрана из существующих `MarkRow` и `TextButton` внутри списка действий пульта. Версия в кадре условная. Привязка действия к настройкам будет рассмотрена в отдельном кадре «Хранить сообщения». [Патч для стенда](pult-review.patch).

## Рендер и проверка

- [Исходный пульт](pult-baseline.png) и [пульт со строкой](pult-push.png) сняты в Chromium через DevTools Protocol. Область кадра 1024 × 760 CSS px, светлая тема, масштаб 100%, DPR 1. Использованы данные сцены `7a-server`.
- Для повтора применить патч в отдельной копии указанного коммита и запустить `npm run dev` из `cmd/wynd-workshop/frontend`. Исходник — `gallery.html?size=baseline&scene=7a-server`, вариант — с добавленным `&push-status`.
- Осмотрены шапка, навигация, существующие кнопки и действия, типографика, разделители и строка Wynd Push. Заголовок и верхняя граница списка действий находятся на тех же координатах. Между плашкой обновления и списком 8 CSS px в обоих кадрах. Вариант полностью помещается в заданный размер.
- `git apply --check`, `node web/scripts/check-spacing.mjs` и `node docs/visual/check-workshop-servers.mjs` прошли. Образ ntfy, запрос здоровья и действия пульта проверяются после реализации подключения. Нативное окно Wails для этого кадра предстоит проверить отдельно.
