# Wynd Push. Шаг установки в Мастерской

**Статус.** Необязательная установка сервера уведомлений согласована 26 ноября в [плане 76](../../../plans/76-wynd-push.plan.md). 28 ноября владелец согласовал кадр и попросил проверить зазоры: «Да, но проверь зазоры, что они по нашей лесенке». Зазоры измерены и приведены к шагам C120.

## Основа и изменение

Основа компоновки — утверждённый кадр `2` «Осмотр — до любых изменений» из [workshop-servers.fragment.html](../../workshop-servers.fragment.html), коммит `b827aff829e43857700e1eacac833862e3ea1a06`. Для сравнения отрисована актуальная форма «Что на сервере», включая уже принятое поле «Каталог на сервере». Исходники формы и оболочки — `cmd/wynd-workshop/frontend/src/App.svelte` и `Window.svelte`, сцена `2-inspect-new`, коммит `828cccf08b1073efe7b70a54b656d27ce903ba50`.

Под каталогом появляется выключенная галочка «Сервер уведомлений Wynd Push». Включение открывает поле поддомена в той же строке и подсказку про DNS. Использованы существующие `FieldLine`, `Checkbox` и `Input`. Вариант хранится как [патч для стенда](install-review.patch).

## Рендер и проверка

- [Исходная форма](install-baseline.png), [показанный вариант](install-push.png) и [кадр с проверенными зазорами](install-push-spacing.png) сняты в Chromium через DevTools Protocol. Сцена `gallery.html?size=baseline&scene=2-inspect-new` использует настоящие `Window.svelte` и `App.svelte` с ответами тестового Go. Размер областей снимков 1024 × 760 CSS px, масштаб 100%, DPR 1, светлая тема.
- Для повтора запустить `npm run dev` из `cmd/wynd-workshop/frontend` в отдельной рабочей копии указанного коммита и открыть маршрут сцены на порту 5175. В обоих случаях заполнить каталог `/opt/wynd`. Для варианта применить патч из корня копии и включить галочку. Надпись «0.4.1» в шапке приходит из тестовых данных галереи.
- Проверено в браузере, что галочка изначально выключена и поле появляется при её включении. Осмотрены шапка, вкладки, список серверов, существующие поля, читаемость подсказки и нижний ряд действий. Первый пробный вариант с плашкой вытеснял действия за нижний край и был заменён строкой.
- `git apply --check` проверяет применимость патча, а `node docs/visual/check-workshop-servers.mjs` — закреплённые кадры. Проверки реального DNS, HTTPS, установки и нативного окна Wails входят в следующие шаги плана.

## Проверка по лесенке C120

[Лесенка Wynd](../../../testing/wynd-spacing-scale-2026-11-23.md#лесенка) задаёт 8 px между соседними блоками и перед пояснением. В показанном варианте оба отступа были переопределены на 4 px. После удаления переопределения их задаёт существующий `FieldLine` и токен `--sp-2`. Рабочий `App.svelte` не менялся.

| Замер, CSS px | Показанный кадр | После правки |
| --- | ---: | ---: |
| Поле каталога → ряд Wynd Push | 4 | 8 |
| Ряд Wynd Push → подсказка о поддомене | 4 | 8 |
| Галочка → поле поддомена по горизонтали | 8 | 8 |
| Подсказка → линия над действиями | 20,16 | 18 |
| Линия над действиями → кнопки | 16 | 16 |

Исправленные зазоры подтверждены в Chromium при 1024 × 760, 760 × 560 и 680 × 501. Общий колонтитул C146 даёт 18 px до разделителя. Разница со ступенью 16 px укладывается в допуск 2 px. В широкой форме кнопки целиком видны, ряд опустился примерно на 6 px и появилась вертикальная прокрутка на 5 px. Узкие размеры проверены с прокруткой к блоку, без горизонтальной прокрутки панели. При ширине 680 px пример поддомена обрезается внутри поля. Нативное окно Wails предстоит проверить отдельно.
