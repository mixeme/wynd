# A25 — полоса обновления Мастерской: кадры, ждут приёмки

Рендеры — [единый макет Мастерской](../../../visual/installer.html), кадры `10г`, `10д`, `10е` (окно 880 px, светлая тема), сняты в браузере 2026-11-13. Основа — утверждённая компоновка «Список и пульт» (2б, с заменой серверного блока «Вышла версия 0.43.0» на строку «Стоит самая свежая версия», чтобы на кадре не было двух обновлений). Полоса повторяет подход Настольного (`cmd/wynd-desktop/frontend/src/app.css`, `.desk-update-bar`): под шапкой окна, поверх интерфейса, страницу не сдвигает.

Высота полосы: 58 px в покое и при установке, 60 px с строкой отказа подписи — как у Настольного (~60 px). На первых рендерах полоса была 75 px: класс `.actions` в галерее несёт поле 17 px из стилей пульта — в полосе обнулено; в приложении его нет.

## Что решают кадры (A25, решение владельца 2026-11-13 — переносим подход Настольного в Мастерскую)

- Полоса — единственное место обновления: отдельный экран 10б и тихая строка 10а2 уходят; «Позже» прячет полосу до следующего запуска.
- При отказе подписи установка гаснет, «Попробовать ещё раз» больше нет — повтор в следующий запуск; «Позже» и «Что нового» остаются, полосу можно закрыть.
- «Что нового» — страница выпусков в браузере (в Настольном так же); список изменений из 10б не переносится.
- Пока идёт установка, «Позже» погашено; серверные операции ждут окончания.

Кадры 10а–10в остаются в макете как история решения 2026-10-24; реализация A25 их заменяет.
