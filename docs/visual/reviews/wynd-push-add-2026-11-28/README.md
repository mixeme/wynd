# Добавление Wynd Push из пульта

**Смысл** согласован в плане 76: Push можно подключить после установки
Wynd. Владелец уточнил, что можно использовать отдельный публичный домен.
В поле и подсказке теперь написано «домен». Прежняя подпись «Поддомен»
отклонена. **Вёрстка всех трёх кадров** утверждена. Сценарий подключён
к окну Мастерской и проверен в галерее с подставными данными.

## Основа и изменения

В основе кадр `7а` «Пульт работающего Wynd» из
[workshop-servers.fragment.html](../../workshop-servers.fragment.html)
в `b827aff829e43857700e1eacac833862e3ea1a06` и принятая
[строка состояния Push](../wynd-push-pult-2026-11-28/pult-push.png) из
`2d36a4d7`. Рендер использует `Window.svelte` и `App.svelte` из
`cmd/wynd-workshop/frontend/src`, сцену `7a-server` на `c3b151cf`.

| Кадр | Что видно |
| --- | --- |
| [Основа](baseline.png) | Работающий Wynd до добавления строки |
| [Пульт](pult-add.png) | «Добавить» в строке сервера уведомлений под переездом |

В сцене для существующей установки без Push меняется только область

`Label`, `Input`, `Hint`, `MarkRow`, `Button` и `FootBar`.

## Рендер и проверка

Снимки сделаны через DevTools Protocol в Chromium (Edge), область кадра
1024 × 760 CSS px, светлая тема, DPR 1 и масштаб 100%. Для повтора применить
[патч](add-preview.patch) в отдельной рабочей копии `c3b151cf`, запустить
`npm run dev` в `cmd/wynd-workshop/frontend` и открыть галерею.
Основа — `gallery.html?size=baseline&scene=7a-server`, вариант — та же
сцена с `&push-add-preview`. Для плана ввести `example.net`.

Форма и план пересняты на `3b686247` с обновлённым патчем предпросмотра.
По замечанию владельца в форме говорится о своём адресе сервера
уведомлений. В плане названо возможное последствие для сайта.
Подсказка выравнена по полю домена, зазор 8 px. В кадре Wynd работает
на `family.example.ru`, а Push добавляется на `example.net`.

Форма переснята парно с установкой на `1f92555d` после замечания о
разном зазоре. В обоих вариантах подсказка начинается в одном
положении относительно поля и использует `Hint`.

Осмотрены шапка, навигация, три шага, переносы и нижние действия. Сравнение
снимков пульта дало изменения внутри области новой строки, x 251–997,
y 568–598. В 1024 × 760, 760 × 560 и 680 × 501 зазоры формы составили
4 px от заголовка к подзаголовку, 16 px до подписи, 4 px до поля и 8 px до
подсказки. В плане 16 px перед первым разделом, 4 px перед его строкой и
16 px между разделами. Горизонтальной прокрутки нет. В минимальном
размере нижняя кнопка доступна, «Назад» сохраняет ввод.

Галерея проверяет вид и переходы. Код `PlanPushAdd` из `01ea7ca9` отдельно
прошёл проверки Go с подставным SSH для отдельного домена и поддомена.
Применение описано в разделе [«Проверка реализации»](#проверка-реализации).

## Проверка реализации

В `e75c295e` пульт, форма и план связаны с `PlanPushAdd` и `ApplyPushAdd`
выбранного профиля. Подтверждение запускает повторную проверку DNS и
проекта Compose, затем добавляет Push и проверяет HTTPS и адрес в API Wynd.
При отказе Мастерская пытается вернуть прежние настройки. Если восстановление
прервалось, в пульте доступно продолжение для того же домена.

Для проверки `npm run dev` из `cmd/wynd-workshop/frontend`, маршрут
`gallery.html?size=baseline&scene=7a-server` без патча. Пульт, форма и
план отрисованы в Chromium при 1024 × 760 CSS px, светлой теме, DPR 1 и
100%. Все три снимка совпали с утверждёнными попиксельно. В 1024 × 760,
760 × 560 и 680 × 501 проверены высота строк 40,5 px, зазор подсказки
8 px и применение через подставной API. Патч оставлен для исторического
рендера.

Фронтенд проверяет отказ DNS, сохранение домена при возврате, привязку
вызовов к выбранному профилю и повтор из плана. Go-тесты с подставным
SSH проверяют успех, восстановление `.env` и `Caddyfile`, повтор после
неоконченной операции и отказ при конфликте проекта. Сборка и тесты
Wails прошли. Нативное окно на Docker-стенде ещё не проверено.
[Реестр проверок](../../../testing/pending-device-checks.md#32-wynd-push-в-мастерской-план-76).
