Докачка (вопрос владельца «Докачка будет при обрыве?»): скачанные целиком файлы при повторе не качаются заново — сверка по описи (размер и сумма); файл, оборванный посередине, докачивается с того места, где оборвался (SFTP читает файл с любого места) — важно для больших видео; снимок базы на сервере остаётся до конца бэкапа, повтор берёт его же. Новый бэкап собирается рядом и заменяет прошлый только целиком: оборванный не оставляет папку наполовину старой, наполовину новой.
