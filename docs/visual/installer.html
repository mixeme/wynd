Добавьте в HTTPS-сайт wynd.example.org

ProxyPreserveHost On
RequestHeader unset X-Forwarded-For
RequestHeader set X-Real-IP "%{REMOTE_ADDR}s"
RequestHeader set X-Forwarded-Proto "https"
ProxyPass / http://192.168.1.20:7676/ timeout=300 flushpackets=on
ProxyPassReverse / http://192.168.1.20:7676/
LimitRequestBody 104857600
SetEnvIfNoCase Accept "text/event-stream" no-gzip
SetEnvIf Request_URI "^/api/v1/probe/" no-gzip

Нужны модули proxy, proxy_http, headers и setenvif. Сохраните настройки HTTPS и сертификат этого сайта. Проверьте настройку Apache перед применением.
