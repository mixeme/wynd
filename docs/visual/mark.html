Гайд по знаку: что это такое, из чего он построен и как его рисовать.

Выведено из образа продукта · август 2026

Знак

Петляющая улочка — то, что означает само слово.

Wynd — узкая извилистая улочка между домами. Знак не метафора продукта и не иллюстрация к нему: это само имя, написанное одной линией. Поэтому у него нет предмета, который можно было бы «улучшить» — есть только линия, её ход и её вес.

В продукте та же линия читается как хроника: она уходит вглубь, и по ней идёшь. Круг — не лента, а дорога, у которой есть начало.

Что в нём закреплено

Четыре решения, каждое из которых можно нарушить и получить другой знак.

  • Два изгиба — ровно один период. Меньше — не петля, больше — орнамент.
  • Концы на оси. Оба конца возвращаются на вертикаль, иначе фигура заваливается.
  • Постоянная амплитуда. Улочка петляет одинаково, а не сходит на нет.
  • Резкое перо. Глубина даётся весом линии, а не наклоном: ни поворота, ни схождения к точке схода в знаке нет.
При поиске профиля разбирался вариант с концами, уведёнными с оси ради перспективы. Выбрана симметрия концов и более резкое перо. На 16 px от перспективы всё равно ничего бы не осталось, а вес линии выживает.

Построение

Знак не рисуется от руки. Он считается — из двух правил.

Ось — один период синусоиды

Высота знака H = 60, ось идёт от y = −30 (верх) до y = +30 (низ) и описывается одной формулой:

x = −A · sin(2π · y / H),   A = 19.2 = 0.32 H

Отсюда всё остальное: концы сами приходят на ось, амплитуда сама остаётся постоянной, изгибы сами оказываются на y = −15 и y = +15. Ни один узел не двигается вручную.

Перо — линейный рост сверху вниз

Ширина линии растёт по y линейно, от 0.62 вверху до 2.38 внизу — почти вчетверо. Перо ставится перпендикулярно оси, а не вертикально: контур — это две стороны, отложенные по нормали.

Это единственное место, где знак говорит о глубине. Тонкий конец уходит вверх и вдаль, тяжёлый лежит под ногами. Поэтому знак и не отражается: зеркало меняет вес местами и выворачивает смысл.

Торцы — полукруг

Оба конца закрыты полукругом радиусом в половину пера в этой точке: 0.31 вверху и 1.19 внизу. Срезанных торцов у знака нет.

Если знак нужно перерисовать

Девять строк вместо файла — на случай анимации, генерации или переноса в другой формат. Выборка в 161 точку взята из исходника; для крупных размеров её можно сгущать.

const H = 60, A = 19.2, W0 = 0.6163, W1 = 2.3810, N = 161;

const axis = y => -A * Math.sin(2 * Math.PI * y / H);   // ось: один период
const pen  = y => W0 + (W1 - W0) * (y / H + 0.5);        // перо: линейно по y

const side = s => Array.from({length: N}, (_, i) => {    // s = +1 / -1
  const y = -H / 2 + H * i / (N - 1);
  const k = -A * 2 * Math.PI / H * Math.cos(2 * Math.PI * y / H);  // dx/dy
  const n = Math.hypot(k, 1);                            // нормаль (1, -k)/n
  return [axis(y) + s * pen(y) / 2 / n, y - s * pen(y) / 2 * k / n];
});

// контур: side(-1) сверху вниз, полукруг r = pen(30)/2,
//         side(+1) снизу вверх, полукруг r = pen(-30)/2, замкнуть.
Сверено: контур, посчитанный по этим формулам, совпадает с контуром знака из образа продукта с расхождением 0.001 при высоте 60 — то есть это и есть исходное построение, а не приближение к нему.

Поле

Знаку нужно пустое место со всех сторон — не меньше шестой части его высоты.

Габарит знака с пером — 39.90 × 61.47. Минимальное поле — H/6 = 10. В иконке поля больше, и это нормально; меньше — нельзя нигде.

Цвет

Чернила на бумаге. Всё остальное — только внутри продукта.

Бумага #F4F0E9, чернила #2B2724 — те же переменные, что в интерфейсе. Знак не перекрашивается под площадку и не выворачивается на тёмном: бумага не фон под маркой, а её часть.

Цветным знак бывает в одном случае — внутри интерфейса, когда линия рисуется цветом круга. Для этого есть mark.svg без подложки, берущий currentColor.

Размеры

На 32 px и мельче перо перестаёт работать, и нужен второй файл.

Тонкий конец линии — 1 % высоты знака. На 32 px это доля пикселя: конец бледнеет, на 16 px исчезает совсем. Верхний ряд — эталон, нижний — вариант с поднятым минимумом.

Граница — 32 px: 32 и мельче — мелкий вариант, крупнее — эталон. Утолщённым пером знак теряет наклон, поэтому выше границы он не годится.

В иконке

Одна композиция на все площадки.

Холст 1024, знак 491 × 756 по габариту с пером, оптический центр совмещён с центром холста. 756 — портретный прямоугольник иконочной сетки Apple; в круг safe zone 819 знак укладывается, поэтому маска Android ничего не срежет.

Подложка сплошная и во всё поле: iOS не допускает прозрачности, углы площадка скругляет сама. Своё скругление в файл не зашивается.

В интерфейсе

Знак появляется редко и по делу.

Под каждым событием, в разделителях дней или фоном карточек линия стала бы текстурой и начала спорить с фотографиями. Оболочка молчит — значит и знак молчит. Мест, где линия делает работу, а не украшает, четыре:

  • Твой отрезок. Линия обрывается точкой: выше — хроника круга, ниже — твоя часть. Рисуется цветом круга.
  • Начало журнала. Линия растворяется кверху: здесь начинается круг. Видно один раз, за долгий скролл.
  • Обновление. Линия дорисовывается по мере вытягивания — на месте штатного индикатора.
  • Пустой круг. Крупная бледная линия и приглашение.

В этих местах линия — не иконка, а элемент: её можно обрывать, растворять и дорисовывать. Правила этого гайда — про знак как знак; внутри четырёх сценариев работает продуктовая логика.

Логотип

Знак плюс слово — почерком, а не каллиграфией.

Шрифт — Nothing You Could Do: тонкий штрих рифмуется с пером знака. В продакшене слово переводится в кривые, чтобы не тянуть шрифт в приложение ради четырёх букв.

Лок держится на трёх числах, считанных от чернильной высоты знака H: чернильные высоты знака и слова равны, чернильные центры совмещены, зазор между чернилами 0.35 H. Кегль слова из этого следует — 0.86 H. Построение, файл в кривых, границы размеров и тэглайн — в гайде по логотипу.
