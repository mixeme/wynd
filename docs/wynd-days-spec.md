# Wynd: механика «Дни»

День — взгляд на журнал, не отдельное хранилище. Название и обложка дня — **сказанное**, того же класса, что запись: окно правок, реальное удаление. Что можно стереть, а что нельзя — в [сказанном и структуре журнала](wynd-event-log-immutability.md). Этот документ — про группировку, права на день и схлопывание.

## Три времени записи

- **`created_at`** — момент попадания записи в лог. Неизменен, основа ленты, курсоров и непрочитанного.
- **`entry_date`** — дата, к которой пользователь относит запись. Правится в пределах окна правок этой записи; клиент предлагает её из EXIF (`captured_at`).
- **`captured_at`** — время съёмки из метаданных. Справочное.

Если в посте несколько фото с разными датами съёмки — у поста всё равно один `entry_date` (ориентир для группировки). Фото внутри поста могут показывать свою дату отдельно.

## Основная лента

Не меняется. Порядок и непрочитанное — по `created_at`. Запись задним числом — обычный пост в потоке, с пометкой даты, к которой она отнесена.

## День как сущность

- `День = (circle_id, entry_date)` — общий на весь круг, без автора.
- Существует, пока есть хотя бы одна неудалённая запись с этим `entry_date`.
- День сам по себе не контент: это проекция. В журнале живут записи за этот день и, если их задали, название и обложка — сказанное.
- Удаление последней записи дня схлопывает день: проекция исчезает, название и обложка уходят из журнала вместе с ним. Строки «название удалено» нет — сказанного больше нет.
- Если позже кто-то снова напишет с этим `entry_date` — день возрождается пустым, без старого названия и обложки.

## Вкладка «Дни»

Отдельная вкладка (сетка), derived view поверх того же журнала.

- Группировка `GROUP BY entry_date`.
- Карточки внутри дня — по `entry_date` (с точностью до времени, если есть).

## Название дня (`day_titled`)

- Сказанное. Окно правок — как у записи, снимок в момент, когда название задали.
- Задать, сменить или убрать может тот, у кого есть хотя бы одна запись за этот `entry_date`.
- Актуальное имя — последний `day_titled` для этого дня. Убранное название в журнале не лежит.
- Убрать название, пока день жив, день и записи не трогает: откат к предыдущему имени или к безымянному дню (подписан датой, не словами «без названия»).
- Схлопывание дня уносит все `day_titled` этого дня из журнала.
- Одновременное переименование — last-write-wins по `created_at`.

## Обложка дня (`day_cover_set`)

Тот же паттерн, что название: сказанное, окно правок, last-write-wins, любой участник с записью за этот день.

- Ссылка на медиа внутри чьей-то записи за этот день.
- Автор события должен быть среди авторов записей дня.
- Актуальная обложка — последний `day_cover_set`. Убранная обложка в журнале не лежит.
- Схлопывание дня уносит обложку из журнала вместе с днём.
- Если удалили запись с фото-обложкой, а день ещё жив — откат к предыдущему `day_cover_set`; если его нет — к автовыбору.

### Автовыбор обложки (fallback)

- Пока никто не выбрал обложку вручную, вкладка показывает предложенное фото дня (например, первое по `entry_date` / `captured_at`).
- Автовыбор считается при рендере, в лог не пишется.
- Ручной `day_cover_set` всегда приоритетнее.

## Подсказка после первой записи дня

Сразу после первой записи с новым `entry_date` — мягкая подсказка задать название и обложку. Необязательно, публикацию не блокирует, появляется после факта.

Для второй и следующих записей дня подсказки нет. Если пропустили — день без имени, с автообложкой; любой, у кого есть запись за день, может задать их позже через вкладку «Дни».

Это обучение, не постоянный элемент интерфейса: первые N раз (или пока человек сам ни разу не назвал день). Порог — деталь реализации. Сама функция никуда не девается.
