# 63 — Подпись выпусков «Wynd для компьютера»

**Тип:** инструмент разработчика (окно «Wynd Подпись»).
**Статус:** 2026-11-10 код и кадры подготовлены в отдельной ветке `signer-desktop` (от `main` `70414ecd`); кадры ждут ответа владельца. Не влито, не выпущено. Выпуски окна на GitHub остаются черновиками: подпись их не публикует.

## Зачем

«Wynd Подпись» подписывала только выпуски Мастерской (`workshop-v…`, `wynd-workshop.exe`). Окно для компьютера собирается тем же способом из тега `desktop-v…` (`wynd-desktop.exe`), но программа этих выпусков не видела — подпись окна была отмечена отдельной задачей в `.github/workflows/desktop-client.yaml`. Владелец 2026-11-10: «Не умеет подписывать Wynd для компьютера».

## Что предлагается (ветка signer-desktop)

- **Один ключ на обе программы.** Выпуски окна подписываются тем же ключом владельца и тем же форматом `.sig`, что у Мастерской; окно пока само не проверяет подпись при обновлении, но файл подписи готов для этого (отдельная задача самообновления окна).
- **Список выпусков общий:** строки «Мастерская {версия}» и «Wynd для компьютера {версия}» в одном списке (кадр 12б), заголовок «Выпуски» вместо «Выпуски Мастерской».
- **Проверки окна короче:** сумма и удостоверение сборки те же; этапов «Проверяем открытый ключ» и «Читаем описание выпуска» у окна нет — встроенного ключа самообновления и `whatsnew.md` у окна ещё нет.
- **Черновик окна не публикуется подписью.** У Мастерской подпись публикует черновик, когда есть `whatsnew.md`; у окна «что нового» дописывает и выпуск публикует владелец. Программа только выкладывает `wynd-desktop.exe.sig`.
- **Тексты** экранов 12а/12б/12в/12г/12д под обе программы; вёрстка, шапка, поля, кнопки, интервалы и цвета не меняются.
