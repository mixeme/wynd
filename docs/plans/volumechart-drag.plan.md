## Почему нельзя собрать из имеющихся

Смотрели [`$ui/forms/VolumeChart.svelte`](../../web/src/lib/components/forms/VolumeChart.svelte): столбцы, заливка до `cutoffX`, подпись даты. Указатель не слушается: нет `oncutoff`, нет pointer/drag. Экран 6.8 двигает отсечку полем даты — сценарий «линия на графике, сразу видно сколько освободит» с этим компонентом не собрать. Расширять поле даты вместо графика нельзя: макет именно жест на линии.

Не новый виджет с нуля: те же SVG-столбцы, добавить жест на существующий `VolumeChart`.
