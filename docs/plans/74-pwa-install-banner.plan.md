# 74 — Баннер «Wynd на главный экран» в браузере

**Тип:** новая задача (вопрос владельца 26.11.2026: «А баннер для браузера про PWA можно сделать? Или мы не сможем отличить?»).
**Статус:** вёрстка принята владельцем 26.11 («Да»); выпущено в 0.55.0 (26.11); живая проверка — на устройствах.
**Обновлено:** 2026-11-26.

## Решения владельца (26.11)

1. **Показывать** в Chrome, Vivaldi, Safari и Firefox — во всех браузерах; не только в Chrome/Vivaldi.
2. **Порядок** — «Рекомендуем Chrome или Vivaldi», ниже «Wynd на главный экран», ниже «Приложение Wynd для Android», ниже «Что нового?». Слово владельца 26.11 после кадров (прежние порядки отменены).

## Что можем отличить

- **Приложение Wynd (APK)** — по мосту `__wyndAndroid` (`androidPort()`), 100 %.
- **Установленная PWA** — по `display-mode: standalone` (`matchMedia`) и `navigator.standalone` (Safari): при запуске с домашнего экрана баннера нет.
- **Вкладка браузера** — остальное; надёжно отличить «PWA установлена, но открыта вкладка» нельзя (в Chrome есть `getInstalledRelatedApps`, но это только Chrome и нужна настройка manifest — не берём).
- **Окно Настольного** — по мосту `__wyndDesktop`: баннера нет.

## Что сделано

- `web/src/lib/pwa/install.ts` — перехват `beforeinstallprompt` (Chromium) и `promptPwaInstall()`: системное окно установки, одноразовое событие; `runningStandalone()` — «уже с домашнего экрана». Вызов перехвата — в корневом `+layout`.
- `web/src/lib/session/pwaHint.ts` — показ/закрытие баннера (`wynd:pwa-hint-closed`, как у соседних подсказок) и шаги установки по браузеру: Safari на телефоне — «Поделиться» → «На экран „Домой“»; Firefox — «Установить»/«Добавить на главный экран»; Safari на компьютере — «Добавить в Dock»; Chrome на Android — «Установить приложение»; компьютер — значок в адресной строке. В Firefox на компьютере установки нет — баннера нет.
- Баннер на улочке: после подсказки о браузере и перед баннером про приложение — `title` «Wynd на главный экран», `text` «Уведомления и запуск без адресной строки.» (слово владельца 26.11 — про уведомления), шеврон и крестик. Нажатие: есть системное окно — открываем его; нет — окно с шагами меню (`Dialog` + `Scrim`, кнопка «Понятно»). Поставили — баннер исчезает.
- Тесты: `pwaHint.test.ts` (10) — браузеры, установленная PWA, окно Wynd, Firefox на компьютере, крестик, шаги по браузерам; `install.test.ts` (4) — без события «unavailable», системное окно и выбор, отписка, `standalone`. svelte-check 0/0, 714 тестов (итоговый прогон), lint и check:ui зелёные.

## Кадры

Настоящий рендер клиента 0.54.1: 360 × 728 CSS px, DPR 2, светлая тема, Firefox на Android, круг «Тест OPPO» с wynd2. Галерея — `http://127.0.0.1:8897/pwa-banner.html`.
Снимки — [улочка](../testing/pwa-banner-2026-11-26/street.png) (три баннера: браузер, веб-приложение, приложение) и [шаги установки](../testing/pwa-banner-2026-11-26/help.png). **Оба кадра приняты владельцем 26.11 («Да»)**.

## Открыто

- Живая проверка: Chrome на Android — своё окно установки и исчезновение баннера после установки; Firefox и Safari — шаги меню; установленная PWA и приложение Wynd — баннера нет; крестик закрывает насовсем. В реестре устройств.
- Ограничение: PWA, установленная, но открытая вкладкой, определяется как браузер — баннер покажется снова (до крестика).
