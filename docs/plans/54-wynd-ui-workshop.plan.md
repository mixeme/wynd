# Раздел Мастерской в Wynd UI — пробел Wynd UI

**Тип:** пробел Wynd UI
**Статус:** закрыт
**Экран / макет:** окно Мастерской (`cmd/wynd-installer/frontend`) · docs/visual/installer.html, все кадры

Решение владельца, 2026-10-26: «Да» на вопрос «Делаю раздел `workshop/` в Wynd UI?» (план 46, C61). Прецедент — `admin/`: компоненты, нужные только админке, живут в общей библиотеке по её правилам и с каталогом.

## Почему нельзя собрать из имеющихся

Окно Мастерской берёт из Wynd UI только `Button`, `Input`, `Label`, `Chip`, `TextButton`; всё остальное — своя разметка `ins-*` прямо в экранах (`App.svelte` — 1781 строка, `Archives.svelte`): строка «значок — текст — действие» повторена 28 раз, плашка — 38. Компоненты клиента по смыслу совпадают с частью этого (`Row`, `CheckRow`, `DangerNote`, `Sheet`), но выглядят иначе: сделаны под списки в телефоне (у `Row` поля 13×16 и значок по центру строки, у строки окна — 7×0 и значок по первой строке текста; `DangerNote` — чёрная рамка с подписью сверху). Расширять их вариантами «как в окне» — два вида в одном компоненте ради одного потребителя. Галочки и выбора одного у клиента нет совсем (только `Switch`).

Вид окна не меняется: компоненты повторяют нынешнюю разметку и стили. Проверка — стенд окна `cmd/wynd-installer/frontend/gallery.html` (60 сцен с подставным Go): снимок «где какой текст, шрифт, рамка и фон» каждой сцены до и после должен совпасть.

## Добавить в библиотеку

| Компонент | Путь | Зачем |
|-----------|------|-------|
| Notice | `$ui/workshop/Notice.svelte` | Плашка `ins-box`: обычная, отказ (`bad`), заметка над заголовком (`note`), моноширинная; заголовок, пояснение, действие справа |
| MarkRows | `$ui/workshop/MarkRows.svelte` | Список строк со значками |
| MarkRow | `$ui/workshop/MarkRow.svelte` | Строка «значок — текст — действие» (план, осмотр, пульт, шаги) |
| FileRow | `$ui/workshop/FileRow.svelte` | Строка файла во вкладке «Архивы»: имя, пояснение или ошибка, действие |
| StepList | `$ui/workshop/StepList.svelte` | Ход работы: установка, обновление, бэкап, переезд |
| StepNav | `$ui/workshop/StepNav.svelte` | Колонка шагов слева |
| FootBar | `$ui/workshop/FootBar.svelte` | Ряд кнопок внизу экрана, неброское действие справа (`ins-push`) |
| Checkbox | `$ui/workshop/Checkbox.svelte` | Нарисованная галочка с подписью |
| Radio | `$ui/workshop/Radio.svelte` | Нарисованный выбор одного с подписью |
| CopyLine | `$ui/workshop/CopyLine.svelte` | Строка, которую человек вставит сам, и «Скопировать» |
| FieldLine | `$ui/workshop/FieldLine.svelte` | Поле и кнопка в ряд (папка, файл) |
| CommandLog | `$ui/workshop/CommandLog.svelte` | Что выполнялось на сервере |
| RawSheet | `$ui/workshop/RawSheet.svelte` | Окно поверх «Что проверили» (кадр 2е) |
| WorkshopTabs | `$ui/workshop/WorkshopTabs.svelte` | Вкладки «Серверы» и «Архивы» |
| SelfBar | `$ui/workshop/SelfBar.svelte` | Полоса «Вышла Мастерская …» (кадр 10а) |
| TitleBar | `$ui/workshop/TitleBar.svelte` | Своя полоса заголовка окна |

Общие правила раздела (оттенки текста, значок строки, блок команд, кнопка «✕») — `web/src/lib/styles/workshop.css`; его подключает только Мастерская. Остальные стили — внутри своих компонентов.
