## Назначение и правила

Новичок ставит Wynd на свой VPS по SSH, получает ссылку первого запуска и затем обслуживает установку. Администратору остаются install.sh и Docker — приложение их не заменяет.

- Чужие сервисы не трогать; перед изменениями показывать план «поставим / изменим с копией / не тронем».
- Шаги: проверить, выполнить, убедиться. Повтор после обрыва безопасен; ошибка названа понятными словами с дальнейшим действием.
- ОС сервера — Debian и Ubuntu. Приложение — Windows и Linux; Linux собирается отдельно, требует cgo и WebKitGTK.
- Мастерская устанавливает Wynd только через Docker. Поддержку другого каталога вместо `/opt/wynd` пробуем отдельно; установка бинарника со службой systemd в её задачи не входит. Решение владельца 2026-11-05.
- Вход по ключу предпочтителен; пароль по умолчанию только в памяти. «Запомнить пароль» сохраняет его в системной связке после успешного входа.
- Секреты не в планах и не в Git. Учётки и адреса проверки — в закрытом myenv рядом с проектом; чужие установки и процессы не использовать без разрешения.
- До выпуска изменённых SSH-команд, переноса или обновления нужен проход безопасности по SECURITY.md.
- Перед откатом предупреждать: хранилище IndexedDB клиента не откатывается вместе с сервером.
- Логика `App.svelte` вынесена в контроллер `lib/panel.svelte.ts` и модули `lib/display`/`lib/rollback` (16.11, [план 60 §8](60-review-followup.plan.md), досрочно по решению владельца). Новые операции профиля добавляются в контроллер, разметка остаётся в `App.svelte`; отдельной задачи «отрефакторить всё» нет.
- «Wynd Подпись» — инструмент разработчика, который собирают локально; готовый exe в публичные выпуски не добавлять. Обычным пользователям Мастерской он не нужен, разработчику удобнее локальная сборка. Решение владельца 2026-11-05; команда сборки — в [DEVELOPMENT](../DEVELOPMENT.md#wynd-мастерская).

[Единый макет](../visual/workshop.html), стенд — cmd/wynd-workshop/frontend/gallery.html. Компоненты workshop находятся в общей Wynd UI; правила — [справочник](../reference/ui-components.md). Сборка, подпись и выпуск — [DEVELOPMENT](../DEVELOPMENT.md#wynd-мастерская).
