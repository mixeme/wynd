# 65 — Подпись Android-выпуска в окне «Wynd Подпись»

**Тип:** инструмент разработчика («Wynd Подпись»), расширение плана 63.
**Статус:** основа и объём собраны 2026-11-19; кадры готовятся, реализация — после утверждения.
**Обновлено:** 2026-11-19.

## Зачем

APK выпусков Android собирает CI ([android.yaml](../../.github/workflows/android.yaml)): тег `android-v*` создаёт черновик с `wynd-android-unsigned.apk`, SHA-256 и attestation. Подпись и публикация сейчас — локальный сценарий `scripts/sign-android-release.ps1`; владелец 2026-11-19: «давай сначала добавим в Подпись поддержку подписи Android приложения». Окно «Wynd Подпись» должно подписывать Android-выпуск так же, как Мастерскую и Настольный: список выпусков → проверка → пароль → подпись и публикация.

## Принятые решения

- **Android — третья строка в таблице продуктов** `internal/signing` (план 63: «новая программа экосистемы — строка в products; окно своих списков программ не держит»). Имя в окне — «Wynd для Android» (как в заголовке черновика CI), тег `android-vX.Y.Z`, файл выпуска `wynd-android.apk`, признак подписи — наличие `wynd-android.apk` в выпуске (у exe — `.sig`, у Android — подписанный APK сам по себе).
- **Проверка перед паролем** повторяет скрипт: сумма, attestation с проверкой workflow `android.yaml` и тега, пакет/версия из `aapt dump badging` (пакет `mixeme.wynd`, `versionName`/`versionCode` из тега, без `application-debuggable`), выравнивание `zipalign -c 4`, раздел версии из `android/whatsnew.md` тега (существующий `WhatsNew`), `releaseReady` из `android/version.properties` тега. Каждый отказ — `Problem`, подпись недоступна, как у exe.
- **Подпись — apksigner** из среды Android (`D:\android-env`: JDK `jdk-17*`, build-tools `35.0.0`), keystore — постоянный ключ владельца (`D:\Local\Git\myenv\wynd\wynd-android.p12`, alias `wynd-android`); среда и keystore — настройки окна, значения по умолчанию как в скрипте. Пароль передаётся apksigner через переменную окружения процесса, не в аргументах и не через окно apksigner: в GUI консольного запроса нет. Неверный пароль — «Пароль не подошёл», как у exe (12в). Подпись с сертификатом `CN=Android Debug` запрещена.
- **Публикация** — как у exe: загружаем подписанный APK и `.sha256`; черновик публикуется с заголовком «Wynd для Android X» и «Что нового» из тега. Блокировка первого выпуска сохраняется: без `releaseReady=true` в теге публикация невозможна — выпуск подписывается и остаётся черновиком, окно объясняет это словами из Go.
- **Поле — только там, где применяется** (решение владельца 13.11): путь к keystore не добавляется в экран выпусков для всех программ. Экран Android-выпуска при настроенном keystore выглядит как 12в; без keystore показывает выбор файла ключа (по образцу «Где хранить ключ» 12а) перед паролем.
- Этапы проверки приходят из Go (StepList), окно новых списков этапов не держит; тексты итога подписи для Android приходят из Go тем же путём.

## Отличия от exe-потока (для кадр-основы)

Экран выпуска (12в) остаётся тем же: этапы проверки, поле пароля, «Что нового — из выпуска», «Подписать». Отличается содержимое, всё оно приходит из Go:

- набор этапов: нет «Проверяем открытый ключ»; вместо него «Проверяем пакет и версию», «Проверяем выравнивание» и «Проверяем готовность к публикации» (последняя с пояснением «первый выпуск: публикация заблокирована» при `releaseReady=false`);
- черновик без `releaseReady=true`: кнопка «Подписать» (не «Подписать и опубликовать») и пояснение, что выпуск останется черновиком;
- итог (12г): «Файл wynd-android.apk выложен в выпуск/черновик», без слов о `.sig`;
- строка выпусков (12б) без изменений: Android-черновик приходит данными.
