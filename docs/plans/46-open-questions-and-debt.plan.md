- [ ] **C95. Отзывчивость при чтении кругов (2026-11-19).** Владелец предложил начать с повседневных переходов. Ниже — кандидаты в порядке проверки по коду `baa9f174`. **Замер на OPPO заменили десктоп-замером с приближением слабого телефона (OPPO занят разработкой Android): база и сравнение — в [протоколе](../testing/responsiveness-baseline-c95-2026-11-19.md). Три первых кандидата сделаны и замерены 2026-11-19 (`f8c6f022`, `311361dc`, `52c72703`), инструментация снята. Контрольный проход на OPPO пройден 2026-11-19: порядок эффектов подтверждён, быстрый путь записи держится (~117 мс), но пересоздание экрана ленты телефон оценивает втрое дороже стенда (S2 314 мс) — числа стенда читать как минимальную оценку.** Итог по сети (net, медианы): список → лента 961 → 475 мс, нажатие → текст записи 344 → 145 мс, «Назад» → карточка на месте 409 → 200 мс, «Назад» → список 756 → 530 мс; остаток «Назад» — пересоздание экрана ленты роутером (~200–230 мс net), отдельного кандидата не заводили. **19.11 (C97): первый кадр на переходах улочка ↔ круг теперь из снимков — см. C97.**
