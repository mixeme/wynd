## A. Открытые вопросы продукта

Решения нет — сначала нужно понять, как продуктом пользуются.

- [ ] **A1. Перенос круга на другой сервер.** Отложен сознательно; глобальные идентификаторы под него уже заложены. Персональный архив участника при отсечке — не это, он описан в квоте.
- [ ] **A2. Общие ярлыки групп кругов.** Сейчас группы и пины на улочке живут только на устройстве (IndexedDB). Общие между устройствами — когда станет ясно, сколько кругов бывает у человека.
- [ ] **A3. Удаление профиля и стирание имён.** Кто инициирует — сам участник или администратор по внешнему обращению; на весь инстанс или по кругам. Экрана удаления профиля участником нет.
- [ ] **A4. Зум карты** при точках, разбросанных от дачи до другой страны.

Источник — [wynd.html](../wynd.html), «Что осталось»; «Вне scope» в [server-reference.md](../reference/server-reference.md).

## B. Возможно позже — по реальному запросу

- [ ] **B1. UnifiedPush** — если Web Push не хватит (Android без сервисов Google).
- [ ] **B2. Нативная оболочка для фоновой загрузки видео** (Capacitor и WorkManager). PWA не умеет надёжно дожимать загрузку в фоне, но в WebView нет Push API — пуши пришлось бы переделывать на FCM или UnifiedPush, а версия приложения отвязалась бы от сервера. Не в 0.x.

Источник — [stack.html](../stack.html), «Пуши» и «Отвергнутые альтернативы» (TWA).

## C. Технический долг после 1.0

- [ ] **C1. Таблица `blob_refs`.** Дублирует ссылающиеся таблицы и отстаёт; истина — предикат `internal/blob`. Снять отдельным решением.
- [ ] **C2. `Chronicle.UnreadPostCount` и `Chronicle.LastVisibleEvent`.** Прежние медленные пути; в коде сервера не вызываются, живут как оракулы в `snapshot_circles_test.go`. Убрать, когда новый путь закроют другие тесты.
