## Неизменные правила

- Передача прошлого для сохранения выключена по умолчанию. Согласие охватывает унаследованное прошлое и не расширяет чтение. Отказ ограничивает архив владельца его отрезками; перенос всего круга сохраняет это ограничение. Оживление сохраняет полученный журнал для следующей копии. Отделение копирует только видимое отделяющемуся.
- Группы и закрепления не переезжают. Встреча 1.10 уже реализована и не является новой задачей.
- Истёкшая ссылка перевыпускается без оживления круга; прежняя ссылка недействительна.
- Перенос отдаётся без полной исходящей копии на диске, с возобновлением по неизменному снимку. Принимающий сервер может хранить временный файл.
- Одинаковые байты физически общие, права и метаданные копий независимы. Хеш не доказывает наличие файла у клиента. Удаление и очистка не затрагивают другие копии.
- Смена принимающего сервера сохраняет ссылку/файл и отзывает прежний запрос места как неактуальный на сервере; ошибка отзыва не скрывается. Новый сервер проверяется заново.

## Проверка

Тесты проверяют поведение: состав архива и видимость разных участников, невозможность получить прежний готовый файл после отказа, отсутствие исходящего полного файла при переносе, докачку после обрыва/перезапуска, сохранность общей копии при удалении другой и невозможность узнать о чужом файле по хешу. Миграции проходят на существующих данных; восстановление архивов прежних схем сохраняется. Проверки интерфейса включают ошибки и сохранение введённого при смене сервера.
