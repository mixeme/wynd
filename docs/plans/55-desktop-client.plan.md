# 55 — Wynd для компьютера

**Тип:** новая возможность, C66 плана 46.
**Статус:** ПК1–ПК5 и плашки сервера утверждены. Механизмы нескольких серверов, команды автозапуска и получения файлов проверены на образце. Продуктовая оболочка не начата.
**Обновлено:** 2026-10-29.

## Принятые решения

- Сначала Windows, затем Linux; macOS — при появлении спроса.
- Wails v2.16.0, как у Мастерской. Трей, системные уведомления, работа и дозагрузка при закрытом окне, запуск сразу в трей — после выхода Wails v3 из беты.
- Сначала интерфейс с выбранного сервера, позже — вшитый. Несколько серверов обслуживает Go-прокси к явно добавленным адресам; отключать защиту WebView нельзя.
- Своя рамка окна, постоянный профиль WebView2, сохранение выбранного сервера, явная настройка автозапуска и приём перенесённых человеком файлов.
- Не давать странице произвольное чтение локальных путей или запуск команд.
- Сначала согласовать оставшиеся кадры, затем продуктовый код.

## Кадры и правила

[Единый документ «Wynd для компьютера»](../visual/desktop.html), [исходник из Wynd UI](55-desktop-frames.svelte.txt). Все кадры ниже утверждены владельцем 2026-10-29.

| Кадр | Поведение |
|---|---|
| [ПК1 — первый запуск](../visual/desktop.html#pc1) | Одно поле «Адрес сервера или приглашение». «Дальше» доступно при непустом поле и начинает проверку. Приглашение сохраняет свой сервер и круг |
| [ПК2 — вход](../visual/desktop.html#pc2) | Вход выбранного сервера по почте и коду; стрелка возвращает к адресу. Плашка — имя, адрес, тип регистрации отдельными строками по [плану 56](56-server-cards.plan.md) |
| [ПК3 — сервер не отвечает](../visual/desktop.html#pc3) | Только когда сервер уже выбран, а сохранённого интерфейса нет: «Повторить» и «Другой сервер». До выбора нового прежние данные не стираются |
| [ПК4 — ошибка проверки адреса](../visual/desktop.html#pc4) | Ввод сохраняется. «Дальше» повторяет проверку, в том числе после восстановления сети; во время запроса недоступно. При изменении поля прежняя ошибка убирается |
| [ПК5 — автозапуск](../visual/desktop.html#pc5) | «Настройки → Приложение → Запускать при входе в Windows», по умолчанию выключено. При входе откроется окно. Настройка только этого компьютера |

Ссылки ПК2 утверждены отдельно:

| Регистрация | Без приглашения | Есть приглашение | Вход существующей учётки |
|---|---|---|---|
| Открыта | Есть | Есть | Есть |
| По приглашению | Нет | Есть | Есть |
| Закрыта | Нет | Нет | Есть |

Режим задаёт администратор. Приглашение на другой сервер вводится на ПК1. В действующем веб-клиенте правило 2/1/0 пока применено не полностью; исправление — план 56.

Ошибка ПК4 одна для опечатки, отсутствия сети, выключенного сервера и чужого сайта: «Сервер Wynd по этому адресу не отвечает. Проверьте адрес и сеть.». Надёжно отличить причины нельзя. При сохранённом интерфейсе открывается приложение с полосой связи 7.36–7.40, а не ПК3.

Автозапуск: запись текущего пользователя с точным путём exe в кавычках; выключение удаляет свою запись. Пока идёт изменение, переключатель недоступен; при отказе возвращается подтверждённое состояние и показывается «Не удалось изменить автозапуск. Попробуйте ещё раз.». После обновления или переноса exe проверяется актуальность команды.

Рамка — TitleBar Мастерской; остальные элементы — существующие компоненты Wynd UI. В кадрах окно 1000 × 660 и форма 390 px, настройки используют адаптивную ширину клиента. Размеры остальных состояний этим не заданы. Макеты не отправляют запросы и не меняют Windows. Превью — только в локальном dev/desktop-mockup/previews/, в Git остаются HTML и исходник.

## Проверки механизмов

Подробности, команды, контрольные суммы и исходники — [протокол C66](../testing/c66-desktop-probe.md).

| Механизм | Результат |
|---|---|
| Несколько серверов | Прямой запрос WebView блокируется CORS; через Go-прокси работает |
| Окно Wails v2 | Собранный образец открывает wails.localhost в защищённом контексте с отдельным профилем |
| Автозапуск | Временная запись Run прочитана обратно; команда запускает exe из папки с пробелами с рабочей папкой System32. Процесс и запись убраны |
| Получение файлов | CDP: один и два файла, доверенный drop, три callback Go; размер и SHA-256 совпали у источника, JavaScript и Go. Выбор файла также проверен |
| Ручные проверки | Перенос мышью из Проводника и настоящий вход Windows не проверены |
