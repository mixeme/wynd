# Дверь поиска в круге

**Тип:** механика 0.x
**Статус:** закрыт
**Экран / макет:** 5.5 · screens.html `#e5-5`
**После:** [screen-function-audit.md](screen-function-audit.md)

Фильтры «Этот круг / Все круги», «Период / С фото / С местом» — не здесь, а в [0x-tails](0x-tails.plan.md).

## Обязательство

Маршрут [`/circles/[id]/search`](../../web/src/routes/circles/[id]/search/+page.svelte) живой: запрос, метки «день»/комментарий, чипы автора из текущих попаданий. Из хрома круга на него попасть нельзя: `CircleBar` знает только четыре вкладки, `goto(/circles/{id}/search)` нигде не вызывается. С улочки поиск ведёт на глобальный `/search`.

Новых `$ui` не создавать. Иконка поиска уже есть в `AppBar`; в круге её нет намеренно (четыре вкладки). Дверь — существующий `IconButton` в `CircleBar` или строка в настройках — выбрать одно, не плодить пятую вкладку (макет 5.5 не вкладка).

- [x] Назад с 5.5 возвращает в круг, не на улочку (сейчас `CircleLayout` назад — улочка; проверить, что дверь не путает стек)
