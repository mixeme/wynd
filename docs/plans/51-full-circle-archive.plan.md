Записано 2026-10-15. Макет утверждён владельцем целиком (план 46, A1): 6.29–6.34, 6.40, 6.41, 6.43, 6.31, 6.36, 2.29, 9.12. Этапы 2 (оживление из файла, «Принять круг») и 3 (перенос по ссылке) — потом, но формат файла рассчитан на них.

## Файл `.wynd`

**Незашифрованный** — обычный ZIP (без сжатия у медиа, как у архива участника):

- `manifest.json` — `format: "wynd-circle"`, `format_version: 1`, версия Wynd и схема базы (`schema_version`), адрес сервера, круг (`id`, имя), момент снимка (`snapshot_at`), число записей и размер медиа;
- `data/<таблица>.json` — строки круга как есть, по колонкам: `circles` (одна), `identities`, `identity_names`, `memberships`, `membership_spans`, `events`, `posts`, `post_media`, `comments`, `comment_media`, `reactions`, `days`, `day_titles`, `day_covers`; плюс `accounts.json` — только `id` и `email` участников (почта нужна, чтобы позвать людей при оживлении: «имена, фото и почта каждого» на 6.29) и `blobs.json` — описания файлов (`id`, `sha256`, `size_bytes`, `mime_type`, `original_filename`). Колонки — как в схеме `schema_version`: оживление переводит старую схему в свою, а не угадывает;
- `media/<blob>.<расш>` — все файлы круга (`circleBlobIDsTx`: медиа записей и комментариев, обложки звука и кадры видео, обложки дней, аватары);
- `index.html`, `posts/` — читаемая лента, как в архиве участника, но целиком (без отбора по видимости): файл можно открыть и без Wynd.

Не попадает: приглашения, курсоры прочитанного, настройки уведомлений, ждущие входы, просьбы о месте — это жизнь круга на этом сервере, а не сам круг.

**Зашифрованный** — `wynd-encrypted/v1\n`, строка JSON с параметрами ключа, затем поток [age](https://age-encryption.org/v1) (X25519, куски по 64 КБ, ChaCha20-Poly1305) с тем же ZIP внутри.

**Пароль на сервер не уходит** (A1: «архив расшифровывает устройство, пароль на сервер не уходит»; 6.29: «пароль нигде не хранится»). Устройство выводит из пароля закрытый ключ X25519 — scrypt (N = 2^15, r = 8, p = 1: 32 МБ памяти, на телефоне около секунды), соль 16 байт — и отдаёт серверу только **открытый ключ и соль**. Не PBKDF2 из WebCrypto: WebCrypto нет вне защищённого контекста (Wynd по адресу в локальной сети), а к подбору на видеокартах scrypt стоек благодаря памяти (поправка 2026-10-15, до клиента). Сервер шифрует на открытый ключ и расшифровать файл сам не может; соль и параметры лежат в заголовке файла открыто. При оживлении устройство повторяет вывод ключа и расшифровывает. Размер зашифрованного файла считается заранее (заголовок + 16 байт на кусок) — браузер видит ход скачивания.

Новые зависимости: `filippo.io/age` (Go, BSD-3), на клиенте — `@noble/hashes` (scrypt) и `@noble/curves` (X25519), обе MIT; `npm run licenses`.

## Сервер

- Миграция `0034_circle_archives.sql`: таблица `circle_archives` (`id`, `circle_id`, `requested_by`, `requested_at`, `snapshot_at`, `delete_circle`, `encrypted`, `status` — `building`/`ready`/`failed`, `size_bytes`, `ready_at`, `expires_at`, `downloaded_at`, `removed` — `downloaded`/`expired`/`admin`/`owner`/`canceled`, `removed_at`); у `circles` — `frozen_at` (круг замер под архив с удалением); у `instance_settings` — `archive_retention_hours` (по умолчанию 72, 9.12).
- Файлы — `DataDir/archives/<id>.wynd` (не `tmp`: её чистит запуск). В бэкап не идут: временные.
- Сборка в фоне (`notifyWG`), снимок — одной читающей транзакцией: круг работает дальше (6.40). Перезапуск сервера посреди сборки — `failed`, владелец собирает снова (открытый ключ живёт только в памяти сборки).
- Место: готовые архивы входят в потолок сервера (9.5, решение 2026-10-13) и не входят в квоту круга. Перед сборкой — оценка размера; не помещается — 6.43, «Скачать сразу» потоком.
- Скачивание — одноразовая ссылка, как у архива участника; дошёл последний байт (`deliveredToEnd`) — файл стирается, `downloaded_at`. Оборванное скачивание файл не трогает.
- Срок — ежечасная работа рядом с `runArchiveJobs`: вышел — файл стирается (`expired`). «Удалить все» в панели — `admin`.
- Письма: архив готов — владельцу; круг замер — участникам (одно, 6.36).
- Замерший круг: писать нельзя никому (как без места, но причина своя), участники качают свой архив потоком; «Отменить — оживить круг» снимает `frozen_at`; «Убрать круг с сервера» — нынешнее удаление круга, доступно только после скачивания (6.30).
