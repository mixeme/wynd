# План 61. «Назад» — на экран, откуда открыли

Проблема обнаружена на сценарии владельца 9 ноября 2026: баннер переноса в ленте → «Перенос круга» → «Назад» ведёт в «Настройки» круга, а не в ленту. Полная ревизия всех входов каждого экрана (все `goto`/`href`, push-канал, окна Мастерской и подписанта) показала: правило плана 46 (C13, «Назад» на уровень вверх, и стрелкой, и системной кнопкой) выполняется нигде не нарушая истории, но у части экранов есть вторые входы мимо родителя, для которых объявленный родитель не место возврата.

## Решение

**Механику `up.ts` не переписывать.** Добавлен общий приём записи

`web/src/lib/navigation/up.ts`, коммит `28cae340`: `previousEntry()` — экран, откуда пришли на текущую запись истории (карта запоминается и восстанавливается из sessionStorage, так что работает и после перезагрузки вкладки); `goUpFromSpot(base, spots, parent)` — «Назад» на источник, если он в списке `spots` (пути после `base`, лента — `''`), иначе на объявленного родителя. Выбранный источник — предыдущая запись истории: шаг назад по ней сохраняет прокрутку родителя, как раньше.

Правило для новых экранов: экран, на который можно попасть мимо родителя (баннер, хит поиска, шаг мастера, переход из выхода), объявляет `spots` и родителя через `goUpFromSpot`, а не через `goUp`.

## В — решать по одному

1. **Глобальный поиск.** Хиты «день» и «запись»: решено владельцем 2026-11-09 — «Назад» возвращает в глобальный поиск с тем же запросом (запрос и место восстановит шаг назад по истории). Сделано в `4ce46dad` (день и запись; spots умеют абсолютный путь, у дней `DAY_SPOTS` дополнен `/search`). Остаток того же пункта: чипы «Этот круг» ↔ «Все круги» заменяют экран, источник теряется — вопрос владельцу в отдельном шаге.
2. **«Сетка» → тайл альбома.** «Назад» из альбома ведёт в запись (родитель альбома), из записи — в «Сетку» (`grid:143`). По уровням корректно; по «где был» — нет. Выбрать: запись или «Сетка».
3. **Имя и аватар в шапке вкладки** ведут в «Настройки» круга (`CircleBar`, `identitySettingsLink`): «Назад» из настроек — в «Круги», а не на вкладку, откуда открыли.
4. **«Уйти с сервера» → «Настройки» круга с одним участником** (`servers/leave`, ветка `c.members <= 1`): «Назад» из «Настроек» ведёт в «Круги», экран «Настроек» не читает `?back`.
