- **10.13.** Строка заявки: клик только на шевроне `TextButton`. Макет — тап по строке (`SettingsRow` `onclick`).
- **Скрин после выбора.** `AddPhotoButton` пропадает, заменить/убрать нельзя без перезагрузки.
