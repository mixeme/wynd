# 56 — Плашки сервера

**Тип:** согласованное изменение интерфейса.
**Статус:** ревизия и макеты утверждены владельцем 2026-10-29. В ServerRow добавлено необязательное поле detail; ПК2 обновлён в документе настольного клиента. Продуктовые страницы и общий эталон ещё не обновлены.
**Обновлено:** 2026-10-29.

## Утверждено

1. Имя — первая строка, адрес — вторая. Дополнительные сведения — третья. Межстрочный шаг 20 px без дополнительного отступа.
2. Тип регистрации нужен у входа, регистрации и добавления сервера: «Открыт для новых», «Только по приглашению», «Регистрация закрыта». Ссылки — по правилу 2/1/0; существующая учётка входит при любом режиме.
3. После входа третья строка относится к действию: круги при выборе сервера; квота, одобрено или свободно при приёме круга. Версия остаётся в технических сведениях, панели и Мастерской.
4. Значок GDPR — у имени по подтверждённому allow_name_erasure; это свойство стирания имени/фото, а не обещание иных возможностей. Неизвестность не равна false.
5. Шеврон означает рабочий выбор/переход; галочка в списке — выбранный сервер. Ограничение регистрации не отмечается как поломка.
6. У известного недоступного сервера третью строку заменяет «Сервер не отвечает», при явной проверке — «Проверяем связь…». Имя и адрес сохраняются, плашка не краснеет. Доступность действий определяется отдельно.
7. До первого успешного определения сервера показывается ошибка под полем, как ПК4. При неизвестном имени адрес не дублируется двумя строками.

## Источники данных и проверка макетов

/instance даёт имя, версию, режим и allow_name_erasure. Приглашение — имя, host и allow_name_erasure, без версии и режима: дополнительный запрос ради одинаковой подписи не нужен. Сессия даёт адрес, сохранённое имя и учётку; свежие свойства и число кругов запрашиваются отдельно. Все сведения одной плашки относятся к одному origin.

roomCaption уже различает «свободно», «квота по умолчанию», «одобрено» — это нужно сохранить. Объём для принимаемого круга не равен свободным байтам по SSH из Мастерской.

Макеты проверены в браузере: загрузка шрифтов, шаг трёх строк по 20 px, одинаковая ширина карточек. Существующие слепки rows.test.ts без detail сохранены: 6 тестов пройдены; check:ui — OK, svelte-check — 0 ошибок и предупреждений. Это проверки макетов и необязательного поля, не готовых продуктовых сценариев.
