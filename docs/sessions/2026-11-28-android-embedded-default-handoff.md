# Передача сессии 28.11: Android — вшитый интерфейс по умолчанию

Сессия по слову владельца «Переключай Android приложение на вшитый интерфейс».
Передача написана до выпуска: переключение реализовано, кадры показаны,
живой прогон и 0.1.12 впереди.

## Сделано

- **Переключение на вшитый интерфейс** (план 50, схема Настольного 27.11,
  [протокол](../testing/android-embedded-default-2026-11-28.md)): источник —
  поле `source` в `interface-servers.json`, `embedded` по умолчанию (старые
  файлы без поля — тоже вшитый), `server` — явный откат через «Настройки →
  Приложение → Интерфейс». Выбранный сервер — источник данных в обоих
  режимах; общие входы (C127), IndexedDB и очередь не переезжают. В списке
  «Встроенный» первый; выбранный сервер подписан «Данные с этого сервера» и
  без крестика. Клиент вшит в каждую сборку: `wyndEmbeddedUi` в
  `android/app/build.gradle` теперь `true` по умолчанию; сторож пути без
  клиента — `-PwyndEmbeddedUi=false` в CI и `-NoEmbeddedUi` в
  `scripts/build-android.ps1`. При смене источника и при обновлении APK один
  раз снимается Service Worker и CacheStorage origin.
- **Код:** `InterfaceCatalog` (`source()`, `selectEmbedded()`,
  `select()` пишет серверный источник), `InterfaceBridge` (операция
  `embedded` протокола 1 + busy + перезапуск), `MainActivity` (вшитые ресурсы
  по источнику, общий сброс воркера), веб-клиент
  (`$lib/android/interfaces.ts` + два экрана настроек).
- **Ворота (все зелёные):** Android `testStandardDebugUnitTest`,
  `lintStandardDebug`, `lintStandardRelease`, `assembleStandardDebug`
  (403 файла клиента в APK) и сторож `-PwyndEmbeddedUi=false` (0 файлов);
  web `svelte-check` 0/0, `check:ui`, vitest 783 теста (159 файлов),
  prettier/eslint по своим файлам, production-сборка клиента внутри gradle.
- **Кадры (настоящий рендер)** — `dev/screens/shots/android-embedded-default-2026-11-28/`
  + сценарий `scripts/render-android-embedded-default.mjs` (в git; PNG и
  галерея gitignored): «Настройки → Приложение» во вшитом режиме, список с
  выбранным «Встроенным», список после отката на сервер; 390×780 и 360×640,
  светлая тема, DPR 1 — как в принятых кадрах 17.11. Галерея для владельца:

- **Документы:** план 50 (статус и раздел «Вшитый интерфейс»), протокол,

## Принято и отклонено

- **Принято (смысл):** слово владельца 28.11 «Переключай Android приложение
  на вшитый интерфейс» — решение о переключении, по схеме Настольного

  приняты формально; их вёрстка была показана). Отдельно придуманного

## Грабли

- `npm run lint` в `web` красный на **чужом закоммиченном**
  `web/src/lib/components/workshop/RawSheet.svelte` (коммит
  `4172372c` другой сессии) — prettier. Не правилось (чужой путь);
  `svelte-check` и `vitest` зелёные. Перед выпуском весь lint должен пройти
  на чистом дереве.
- `scripts/build-android.ps1 -Tasks` — PowerShell-скрипту список задач
  передавать только с запятой **в -Command**: из bash `& '.\scripts\...'
  -Tasks a,b,c`. `-File` и пробелы не работают (задачи уходят в чужие
  параметры).
- Кадры: `waitText` по капители (Label) требует сравнения без регистра —
  `innerText` учитывает `text-transform`.
- Gradle-сборка теперь всегда гоняет полный `vite build` клиента
  (`prepareEmbeddedWeb`) — нужен `npm ci` в `web`; первый прогон ~+2 мин.
- Порты: `:8906` — чужой python-каталог (не гасить), галерея поднята на
  `:8905`. Vite кадров — 5273 (strictPort, гасится скриптом).
