## Грабли

- **CDP и origin.** Для same-origin сессия в IndexedDB должна иметь `origin: ''`, а не `http://127.0.0.1:7676`: с полным URL приложение показывает «Нет доступа».
- **Демо-фото.** `dev/screens/dacha.jpg` и `jars.jpg` — схематичные рисунки, не фотографии. Picsum и Unsplash из этой среды недоступны (403/reset), Wikimedia Commons доступен; использованы только CC0/public domain.
- **Стенд.** `dev/wynd-stand-new.exe` на 7676 использует `dev/data`; в нём создан демонстрационный круг «Наш дом» (`01a20e64-5cfc-75b3-9b84-b4d7d210a6d1`) с записями и фото. Это dev-данные, в git не входят; чужой процесс не гасился.
- **Edge.** Headless Edge для съёмки (`--remote-debugging-port=9345`, профиль `dev/readme-shots/edge-profile`) остановлен; профиль и скрипты остались в `dev/readme-shots`.
- **HTML-документы.** `docs/about.html` и `docs/visual/screens.html` не рендерятся как страницы на GitHub/Gitea; README это учитывает.
