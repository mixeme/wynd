# Передача сессии 28.11. Ядро установки Wynd Push

После «Дальше» выполнена часть шага 2 плана 76, отвечающая за Go-план и файлы установки со своим Caddy.

## Сделано

- `b7dc61ce` — `Wizard.MakePlanWithPush` проверяет DNS Push-поддомена против адресов осмотренного сервера и сохраняет его при смене источника сборки. Установщик создаёт `push.json`, `ntfy.yml`, `push.yaml`, дописывает `COMPOSE_FILE` в `.env`, добавляет выделенный блок Caddy и ждёт `/v1/health` по HTTPS. Основной `compose.yaml` совпал с прежним. При повторном запуске файлы не переписываются, конфликтующие настройки Compose останавливают запись.
- Прошли `go test ./internal/config ./internal/workshop/...` и `go test -tags desktop ./cmd/wynd-workshop`. Go-тест установки использует подставной SSH-сервер. Интерфейс окна не менялся.
- Официальный Windows-бинарник ntfy 2.38.3 проверен по контрольной сумме и запущен на loopback. Подтверждены 404 веб-корня, 403 обычных тем, 507 до UP-подписки, 200 и получение сообщения после подписки. Встроенный шлюз Matrix обнаруживается. [Протокол и первоисточники](../testing/wynd-push-ntfy-local-2026-11-28.md).
- Обновлены [план 76](../plans/76-wynd-push.plan.md) и [CHANGELOG](../CHANGELOG.md#unreleased). Сборок выпуска, тегов, развёртываний и проверок устройства не было.

2. Подключить одобренные кадры к мосту Wails и ядру. Сверить настоящие рендеры установки, пульта и настроек с [принятыми кадрами](../plans/76-wynd-push.plan.md).
3. Пройти Docker Compose, Caddy, TLS, обновление, откат, удаление и доставку на отдельном пробном стенде. Локально Docker и дистрибутив WSL отсутствовали. Сценарий проверок остаётся в [плане](../plans/76-wynd-push.plan.md#шаг-3-проверка-контейнера-ntfy) и [реестре](../testing/pending-device-checks.md).

## Решения

- Кандидат для Docker — `binwiederhier/ntfy:v2.38.3`. Начальный срок 12 ч. Для выбранной архитектуры нужен Caddy самой Мастерской. C70 про внешний прокси ведётся отдельно.
- В Go-ядре есть необязательный сценарий установки. Поле в рабочем окне подключается вместе с пультом управления.

## Грабли

- Для проверки UP-лимита у ntfy 2.38.3 нужны UP-запрос и тема из 14 символов, включая `up`. Обычная публикация на разрешённую тему без UP-признака проверяет другой путь.
- При `web-root: disable` запрос `GET` темы с `?up=1` возвращает 404, обнаружение шлюза Matrix на отдельном маршруте работает. [Протокол](../testing/wynd-push-ntfy-local-2026-11-28.md).
- Caddyfile и `ntfy.yml` примонтированы отдельными файлами. При изменении атомарным переименованием проверить обновление bind mount при применении настроек.
