## Решения

- Принято: сервер — минорно (миграция схемы 3), клиенты — патчами;
  Android перевыпускается, потому что вшитый стартовый клиент собирается из
  `web` и изменился вместе с C154.
- Отклонено: ничего в этой сессии. Вёрстка C152 принята владельцем 27.11
  («Принимаем»); C152 из плана 46 убран.

## Грабли

- **Android-тег и `paths`.** `android.yaml` перечисляет `paths`; для тега
  GitHub сверяет изменения коммита тега. Тег на docs-only коммите сборку не
  запускает — `android-v0.1.9` пришлось переставить на `0e4247f7`, где
  меняются `android/version.properties` и `android/whatsnew.md`.
- **Перестановка тегов.** v0.58.0/desktop/workshop сначала указывали на
  `0e4247f7`; до старта tag-прогонов переставлены на `9169da3b` после
  правки выписки. Перед перестановкой проверять `gh release view` — после
  появления черновика тег не двигать.
- **Чужая несохранённая правка на воротах.** Ворота шли, когда другая
  сессия держала несохранённый `web/src/lib/styles/ui.css`; в выпуск он не
  вошёл (pathspec-коммит), позже закоммичен отдельно (`c64e4bd6`).
- **`docker compose up -d` на wynd2** долго не отдаёт вывод по SSH
  (буферизация); состояние проверять отдельной сессией: `docker ps`,
  `docker logs`. Хост wynd2 — `firstbyte1.mixdep.ru`, `45.144.64.241`.
- **`## [Unreleased]` в середине CHANGELOG** — старый долг, не путать с
  текущей волной.
