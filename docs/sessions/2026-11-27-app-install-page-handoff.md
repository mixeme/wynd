## Решения

- Принято: пять строк «Что даёт», верхнего пояснения нет, внизу только быстрый вход ссылкой, зазоры 16/16.
- Отклонено владельцем: QR в нижней подсказке («qr-код ему читать будет неудобно, а вот ссылка пригодится»); обычный путь входа (адрес, почта, код из письма) — «лишнее»; «Видео сжимается на телефоне» — не отличие приложения, в браузере тоже сжимается страницей (заменено на «в фоне»).
- «Место со снимков» и «Поделиться в Wynd» — реальные отличия приложения: `ACCESS_MEDIA_LOCATION` (координаты снимка из системной галереи) и системные SEND-намерения; в браузере ни того, ни другого нет.

## Грабли

- Кадр с CDP: `{viewport}` и `{dark}` ставить **до** `{nav}` — смена метрик посреди прогона после HMR дала белый PNG 12 КБ; пересъёмка «метрики до навигации» правильная.
- `check:ui` (GUI-4) не пропускает инлайн-стили в экранах: для отступа — служебный класс `mt-16` из конца `ui.css` (`.hint` даёт 8, `.btn` — 16; класс идёт позже и перебивает).
- Prettier переформатирует перенос строки внутри `<Hint>`; рендер не меняется.
- Галерея: `python -I -m http.server 8904 --bind 127.0.0.1` из `dev/frames-gallery`, страницы `plan73-app-fix*.html`; чужой/занятый порт проверять `netstat` и `curl`.
- В рабочем дереве параллельная сессия держала правки плана 76 (`web/src/routes/+layout.svelte`, `circles/+layout.svelte`, `search/*`, `docs/reference/ui-components.md`, новые `SearchPane`/`wideSource`) — коммитил только свои пути.
