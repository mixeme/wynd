## Решения

- **Другой каталог установки — доделан.** Поддержка выпущена в 0.4.3/0.4.4;
  незакрытые галочки плана были проверочным хвостом, а не недоделанной
  функцией. Подтверждённое ограничение: имя Compose-проекта берётся из
  последнего сегмента каталога, две установки в папках с одинаковым именем
  не различить.
- **C117/C118 — не «потом вообще», а сразу после каталога.** Запись «отложены»
  исправлена; в плане 46 оба закрыты.
- **Запасной скрипт подписи Android удалён.** Не возвращать: подпись — только
  через окно «Wynd Подпись»; `new-android-signing-key.ps1` остаётся запасным
  для создания ключа. Отклонён вариант «оставить скрипт ручным путём» — был
  выбран до слова владельца «Скрипт удали» и отменён.
- **Галерею не оставлять с битыми ссылками.** Если чистка удаляет снимки,
  ссылки в `docs/visual/*.html` проверять и либо чинить, либо возвращать файл.

## Грабли

- Планы могут отставать от протоколов и тегов: перед докладом «не сделано»
  сверять `docs/testing/install-*.md`, `docs/DEVELOPMENT.md` и `git log`.
- Чистка 22.11 удалила снимки 12а–12д, но `workshop.html` продолжал на них
  ссылаться; восстановление — `git show 5f8cc4d3^:путь`. После чисток
  проверять `<img src>` в галереях.
- Windows PowerShell 5.1 читает UTF-8 без BOM как ANSI: кириллица в `.ps1`
  ломает разбор. `pwsh` на машине нет; проверка — `Parser::ParseFile`.
- `workshop.html`: `.wrap` становится одной колонкой при ширине ≤1450 px
  (медиазапрос) — это не дефект. Headless Edge требует абсолютный путь
  `--screenshot`; для проверки секции удобен временный iframe с `#якорем`.
- Параллельные сессии коммитят в то же дерево: коммитить только свои пути
  (`git commit -- <paths>`). В дереве на конец сессии — чужая работа Android
  (архив): `MainActivity.java`, `MediaChromeClient.java`, новые
  `ArchiveBridge.java`, `ArchiveStore.java`, `ArchiveStoreTest.java`,
  `web/src/lib/android/archive.ts` и тест, `servers/accept/+page.svelte`,
  правки CHANGELOG/ROADMAP/плана 50/реестра/передачи — не трогать.
- `gofmt -l cmd/wynd-signer/main.go` показывает файл из-за CRLF окружения;
  правка была только в комментарии, форматирование не менялось.
