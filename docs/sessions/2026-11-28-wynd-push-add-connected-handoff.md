  из `a8aefc2e` («Принимаем»). Пульт (`bd66f71b`) и форма домена
  (`118a9dcd`) приняты ранее. [Приёмка](../visual/reviews/wynd-push-add-2026-11-28/README.md#приёмка-плана-2811).

## Решения

- Для добавления нужен работающий Wynd со своим Caddy. План проверяется
  без записи, подтверждение перед изменениями проверяет условия снова.
- Если добавление оборвалось, повтор используют для того же домена.
  Пометка операции хранит хеши исходных файлов. Расхождение блокирует
  автоматическую перезапись настроек.

## Грабли

- Сценарий галереи `7a-server` теперь работает без `push-add-preview`.
  Патч и снимки сохранены для истории. Локальные Docker и Podman в этой
  среде недоступны. Тесты SSH не исполняют команды в реальном Docker.
