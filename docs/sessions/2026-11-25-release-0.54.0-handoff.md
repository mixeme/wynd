## Грабли

- Android lint: `MonochromeLauncherIcon` валит сборку, если в adaptive-icon нет
  `<monochrome>`; слой — тот же `wynd_icon_foreground`.
- Тег `android-v0.1.4` переставлялся force до черновика; зеркало GitHub
  обновило тег, прогоны перезапустились. Второй прогон того же тега остаётся
  лишним («Release already exists») — это ожидаемо.
- Gradle требует JDK 17 из `D:\android-env\jdk\jdk-17.0.21.0.3` и переменные
  `ANDROID_HOME`, `ANDROID_USER_HOME`, `GRADLE_USER_HOME`.
- Зеркало GitHub синхронизирует main и теги с задержкой ~1–2 мин; image workflow
  идёт на push main, клиентские — на теги.
- `gh api` иногда отдаёт HTTP 500 на списки прогонов — повторить или смотреть
  по `databaseId`.
