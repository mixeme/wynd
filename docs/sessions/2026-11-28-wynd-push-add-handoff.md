## Решения

- Предложено «Добавить» в строке под переездом. Поле поддомена открывает
  план, а применение начинается отдельным действием. На плане показан
  возможный краткий перезапуск Wynd и Caddy.
- Предпросмотр воспроизводится патчем галереи. Решение о вёрстке
  добавления владелец ещё не давал.

## Грабли

- Браузерный профиль для CDP должен лежать за пределами корня Vite.
  Иначе файловый наблюдатель Windows может остановиться на базе cookies.
- Параллельная работа над C70 в `docs/visual/workshop-servers.fragment.html`
  относится к другой задаче. Для этой сверки использованы закреплённый
  коммит основы и рендер Svelte.
