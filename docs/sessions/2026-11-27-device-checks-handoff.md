## Грабли

- `adb` в PATH нет: `/d/android-env/sdk/platform-tools/adb.exe`. `export PATH`
  в Git Bash не срабатывает на этой машине — звать по абсолютному пути.
- **Пути в adb:** Git Bash конвертирует `/sdcard/...`; для `pull` и
  `screenrecord` включать `MSYS_NO_PATHCONV=1`, а локальный путь давать
  `D:/...` (Windows-формат).
- **OPPO:** `screenrecord` запрещён (`Permission denied`), запись экрана —
  только планшет; экран засыпает за ~2 мин, `svc power stayon true` не
  помогает; `settings put system screen_off_timeout` — SecurityException.
- **Планшет:** приложение из `adb install` попадает в профиль `user 10`,
  запуск — `am start --user 10 -n mixeme.wynd.debug/mixeme.wynd.MainActivity`;
  батарея 1 % (USB-зарядка), запись экрана при этом идёт ~4,5–5,6 fps вместо
  30 — для вспышек 0,3–0,7 с хватает, для более коротких нет.
- **Лимит кодов входа:** 30 мин на почту и на IP; на локальном стенде он в
  памяти процесса (рестарт сбрасывает), **на wynd2 — в БД
  `code_request_log`**: рестарт `docker compose restart wynd` его не снимает,
  чистить строки адреса в окне (sqlite3 на хосте). Клиент дополнительно
  держит свой отсчёт и не даёт нажать «Получить код» — перезапуск приложения
  снимает клиентский.
- **Выпускная 0.1.6 не пускает http** (cleartext разрешён только debug) —
  для входа выпускной сборки только https (wynd2 или VPS).
- **Метки устройств в БД** при чтении Python в Git Bash выглядят как
  «Firefox эр Android» — это кодировка консоли, в базе и интерфейсе текст
  верный.
- **Чужие вкладки:** Vivaldi на устройствах — личный браузер владельца; для
  проверок открывалась отдельная вкладка, чужие вкладки не закрывались.
  Случайное нажатие по полосе вкладок переключало на чужую вкладку — вернуть
  на Wynd через `am start -d`.
- **Параллельная сессия:** в репозитории одновременно шла работа по плану 76
  (`docs/plans/76-wide-sections.plan.md` и `docs/testing/wide-sections-2026-11-27/`
  не закоммичены на момент передачи) — свои пути коммитить pathspec'ом,
  сверять diff перед коммитом.
