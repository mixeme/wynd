# Передача сессии 27.11: мигание диалога удаления круга (C156)

Сессия по двум записям владельца (13:45 и 13:50) с подписью «Опять мигает»:
на телефоне диалог «Удалить «Мигание»?» появляется и исчезает, а «Отмена» и
«Удалить» уходят под клавиатуру.

## Сделано

- **Разбор записей** (cv2, 43–48 кадров/с): диалог при открытии получает фокус
  в поле (`modal` → `focusFirst`), клавиатура выезжает через 0,2 с и накрывает
  нижнюю часть карточки (видимая высота тёмной кнопки 47 → 5 CSS px). Чтобы
  убрать клавиатуру, владелец дважды жмёт «Назад»: первый шаг прячет
  клавиатуру, второй закрывает диалог (C13), после чего он открывается снова —
  за 13 с три цикла, со стороны это и есть мигание. Геометрия сходится с CSS:
  верх карточки (688−88)/2,4 = 250 CSS = `top: 250px`; верх клавиатуры
  (1195−88)/2,4 ≈ 461 CSS.
- **Правка** (`4e7377ef`): `web/src/lib/styles/ui.css` — `--dialog-top`,
  `max-height` и `overflow-y` перенесены из исключения `dlg-fit-viewport` в

- **Сторож** (`5fe80bcf`): `web/scripts/dialog-guard.mjs` в `check:ui` +

  `docs/testing/dialog-keyboard-2026-11-27/` с четырьмя настоящими кадрами,

## Системно (почему больше не чиним «мигания» по одному)

Класс «мигает» сводится к трём границам, и у каждой теперь правило и проверка:

- **Клавиатура и видимая область.** Один источник высоты — `--app-h` из
  `visualViewport` (C144); диалоги вписаны в неё (C156). Сторожа:
  `viewport-guard` (нет `resizes-content`), `dialog-guard` (диалог без
  `--app-h` не пройдёт).
- **Переходы и первый кадр.** Петли истории отменены (C154, тесты `up.test.ts`),
  экран не показывает «Загрузку» вместо уже нарисованного (снимки C100/C105,
  правило «первый кадр = конечный»).
- **Оболочка рисует вне страницы.** Холст `html` в бумагу (C144), в окне
  Настольного `body` — бумага (C155); `chrome-guard` и `viewport-guard` в
  `check:ui`.
- **Измерение вместо поиска на глаз.** `python docs/visual/flash-report.py
  <запись>` (`760cf483`) — единый разбор записи: белые кадры, пустые кадры,
  рывки, кадры-улики и `report.md`. Правило записано в
  `docs/testing/ui-review-protocol.md`: любое «мигает» начинается с отчёта.
  Обе записи владельца разобраны им: v1 — три рывка (4,09; 7,88; 11,97 с),
  v2 — шесть (три цикла диалога).

## Решения

- Принято: вписывание диалогов в видимую область — общее правило `body .dlg`,
  а не флаг у отдельного диалога; сторож в `check:ui`.
- Отклонено: оставлять `fitViewport` исключением для выбора файлов — дефект
  касается всех диалогов с полем (удаление круга, уход с сервера, имя в
  приглашении).
- Не менялось: автофокус поля при открытии диалога (клавиатура по-прежнему
  выезжает сразу; теперь диалог следует за ней вверх). Снимать автофокус — не
  просили.
