## Решения

- Принято: память экрана — общий модуль `search-memory.ts`, а не локальное
  состояние страницы; ключ включает сервер и круг, чтобы чужие строки не
  показывались даже одним кадром; выход из входа очищает память (как улочку,
  C97).
- Принято: при шаге по истории поле поиска не фокусируется (`noteArrival` в
  `beforeNavigate`), обычный вход в поиск фокусирует как раньше.
- Не менялось: вёрстка экрана и автофокус при входе в поиск; в APK дефекта не
  было (слово владельца), поведение APK от правки не меняется.
- Отклонено: чинить только Firefox-веткой — причина общая (пересоздание
  экрана), клавиатура лишь проявляла её в Firefox.

## Грабли

- `flash-report.py` по порогам «белое/одноцветный/рывок ≥ 35 %» мигание не
  нашёл: на тёмной теме смена содержимого даёт меньше 35 % сменившихся
  пикселей. Для таких записей смотреть покадрово область приложения (mean/std
  и bbox изменений), а не только отчёт.
- Node-fetch в этом окружении не ходит на `http://127.0.0.1:<порт>` Edge
  («other side closed»), а на `http://localhost:<порт>` — ходит. В копии
  `cdp.mjs` для стенда заменён хост; Edge на машине один, второй
  `--remote-debugging-port` поднимается не всегда — проще переиспользовать
  уже запущенный браузер.
- Сборка стенда: `cd web && npm run build`, затем `go build ./cmd/wynd`
  (клиент вшивается из `web/dist` через `web/embed.go`). Для «до» временно
  откатывал свои файлы `git checkout --` по списку, диф сохранял в
  `dev/stand-search-back/my.patch` и возвращал `git apply`.
- Данные стенда — копия `dev/data` (круг «Наш дом», 6 записей с фото;
  токены `dev/stand-seed.json` действительны, сессия кладётся в IndexedDB
  `wynd`/`sessions` с `origin: ''`).
- Клавиатуру в headless-браузере не вызвать: вывод о ней — из записи
  владельца и кода; `activeElement` показывает только фокус.
