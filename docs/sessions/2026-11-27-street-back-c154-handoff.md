# Передача сессии 27.11: «Назад» с улочки без мигания (C154)

Сессия — ответ на замечание владельца: «Круги → Круг → Назад → Круги → Назад →
Экран мигает.»

## Сделано

- **Правка C154** (`c39c0dcb`, в Gitea): улица — дом вошедшего приложения, но в
  истории за ней оставалась запись `/` от запуска: корневой экран переводит
  вошедшего на `/circles`, а «Назад» шагал на `/`, где вход снова видел сессию и
  уводил на `/circles`. Петля с кадром «Загрузка…» (17 → 620 мс на стенде).
  Теперь шаг с `/circles` на `/` (и на запись-копию улицы с тем же поиском) не
  делается: `blockedHomeBack` в `web/src/lib/navigation/up.ts`; `navigateBack`
  не уходит на родителя `/`, системный «Назад» отменяется в
  `interceptHistoryBack`, SvelteKit сам возвращает запись истории. Назад на
  настоящий прошлый экран (настройки, поиск, шлюз «Доступ закрыт» с `?closed=`)
  не тронут.
- **Проверено:** стенд 412 × 915 с сохранённым входом — после правки адрес
  уходит на `/` и возвращается внутри отменённого шага, «Загрузки» нет ни в
  одной пробе, строки улицы всё время 3. Собранный клиент (`npm run build` +
  бинарник, 127.0.0.1:7676) — шаг 11 мс, возврат 14 мс, 205 проб без «Загрузки».
  Тесты `up.test.ts` — 29 (8 новых для C154). svelte-check 0/0, `check:ui`, lint,
  build — зелёные; полный web-прогон — см. «Состояние дерева».
- **Записано:** C154 в [плане 46](../plans/46-open-questions-and-debt.plan.md);
  протокол с трассами до/после — [street-back-2026-11-27](../testing/street-back-2026-11-27.md);
  живая проверка — [реестр](../testing/pending-device-checks.md), §21.

## Решения

- Принято: у улицы нет экрана выше; шаг на `/` (вход) и на запись-копию улицы
  не делается ни стрелкой, ни системной кнопкой.
- Отклонено: оставлять петлю `/circles → / → /circles`; подменять шаг на
  `history.go(-2)` через фантомную запись — не делать без слова владельца.
- Вёрстка не менялась, кадр для приёмки не требуется. Приёмка смысла (что
  «Назад» на улице ничего не делает) владельцем отдельно не подтверждена —
  проверка в §21.
