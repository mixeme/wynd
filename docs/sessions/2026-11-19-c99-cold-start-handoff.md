## Числа замера

Стенд 7676 + vite dev, Edge 412×915 DPR2, CPU×6, задержка **только API** 150 мс
(`Fetch`), модель установленного PWA: оболочка из кэша воркера, данные из сети.
Сравнение с worktree на `18fe8d4a` (C97 без C99), медиана прогонов 2–7:

| Сценарий | до C99 | после C99 |
| --- | --- | --- |
| `/` → строки улочки | 1825 мс | **1306 мс** (−28%) |
| `/` → смена маршрута | 1565 мс | 1054 мс |
| `/circles` → строки | 1249 мс | **1097 мс** (−152 = один RTT) |
| первый прогон `/` без снимка | 3569 мс | 2803 мс |

Чистый эффект — один снятый сетевой круг на вход; на `/` больше (~0,5 с),
потому что в «до» дублирующий вызов `initSession` не делил промис. После смены
маршрута до строк — те же ~0,2–0,3 с (это C97). При N серверах сверка была
последовательной (N × RTT), теперь вне критического пути.

## Грабли метода (для следующего замера запуска)

- **`wynd.exe -h` — не справка:** сервер молча стартует с каталогом данных по
  умолчанию. Поднимать с `WYND_DATA_DIR=dev/c92/data` и
  `WYND_LISTEN=127.0.0.1:7676`; иначе `/api/v1/instance` отдаёт
  `bootstrapped:false`, токены — 403, логин — 404.
- **`Page.addScriptToEvaluateOnNewDocument`** должен наблюдать `document`, а не
  `document.documentElement` (на старте документа он `null` — скрипт падал, и
  метки не ставились).
- **Browser-level WebSocket** для `Browser.bringToFront` на Edge 157 может
  зависнуть без `onopen`; надёжнее `Page.bringToFront` +
  `Emulation.setFocusEmulationEnabled`.
- **Полное `Network.emulateNetworkConditions` для запуска не годится:** dev-клиент
  не бандл, загрузка сотен модулей по 1,5 Мбит даёт 5–18 с и шум в секунды.
  Для запуска задерживать только `/api/*` через `Fetch` (кроме `/api/v1/blobs/`).
- **Чистый origin** — `Storage.clearDataForOrigin`; сессию класть в IndexedDB
  только после того, как приложение создало базу со сторами: `indexedDB.open`
  без версии создаёт пустую базу и мешает апгрейду приложения.
- **Выбросы ~50 с** (зависшая вкладка/перезагрузка vite) отбрасывать и
  повторять; первый прогон без снимка в медиану не входит.
