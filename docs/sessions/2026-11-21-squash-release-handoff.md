  (тернарник ломал 12–14 и 21–24); тест `summary-badge.test.ts`.
- **C110-остаток** `7fe251af` — `claimRoute` в `auth/invites.ts`: после
  `claimInvite` экран приглашения заменяется в истории (`replaceState`),
  обе кнопки после прямой ссылки больше не ведут на «Приглашение не

- **C104-хвост** `1953ade8` — `resolveCircleOrigin` сперва снимки списков
  (`loadCirclesCached`), сеть после; тест `origin.test.ts`. Прямой адрес

  запуск — проверка против HTTPS-сервера (реестр §10; параллельная сессия
  уже грелась на HTTPS — `3a9eb1ec`).
- Ворота web: 593 теста / 127 файлов, svelte-check 0/0, prettier, сборка

## 4. Свёртка миграций C115 (владелец: «Делай свёртку») — в main, ждёт выпуска

- `234a77b9` + отметка `2e2e7c10`. Базовая `0001_schema.sql` = вся структура

  `instance_settings` id=1 с `bootstrapped = 0`); форма сверена тестом
  `TestSquashSchemaMatchesFormerChain` (объекты, столбцы, строки).
  **Грабля: INSERT из старых миграций не попадает в дамп sqlite_master —
  первый вариант без засева ломал Bootstrap («auth: invalid»).**
- Прежняя цепочка 0001–0017 — в `migrations/legacy/`, свежая установка её не
  видит, тесты поднимают ею старые базы (embed в `_test.go`).
- `migrate.go`: маяк — отметка **0** (её ставит только базовая схема);
  база прежней нумерации на 17 переводится одной отметкой {0, 1} без
  изменений таблиц (`TestMigrateRenumbersPrevNumbering`); остановившаяся
  раньше и базы разметки 1 (отметки 30–36) — отказ с Wynd 0.53.4
  (`squashPrevRelease`), который доведёт их до точки свёртки; «версия 1» без
  маяка — тоже отказ (маяк отличает свёртку от старой базы версии 1).
- Разметка архива **3** (`chronicle.ArchiveFormatVersion`):
  `ReviveSchemaVersions` = {1}, `RevivePrevSchemaVersions` = 1–17, разметки
  1 и 2 продолжают оживляться; split и полный архив штампуют 3 + схему 1;
  пересчёт записей — `FormatVersion > 2`.
- CHANGELOG «Оператору» (Unreleased): бэкап до деплоя обязателен, откат
  старым бинарником на переведённой базе не работает, перенос между

- Ворота: фаза [test] — журнал ворот, фаза [desktop]

## 6. Правила и грабли сессии

- Gitea-push при отказе auth — просто повторить (несколько раз за сессию);
  зеркало GitHub синхронизируется ~5–8 минут, тег появляется не сразу.
- sum.golang.org / storage.googleapis.com флапали (VPN?): локальные прогоны
  спасают `GONOSUMDB=golang.org/toolchain` или `GONOSUMDB=*`; CI проверяет
  как положено.
- «Подпись»-опубликованные выпуски: тело черновика заполнять
  `gh release edit --notes-file` до подписи (заглушка CI:
  «что нового — дописать до публикации»).
- План 46 и реестр правит и параллельная сессия — выборочные коммиты своих
  хунков через `git apply --cached` с отфильтрованным патчем.
