## Грабли и правила, добытые в этой сессии

1. **wynd2 — машина проверки Мастерской, не прод** (владелец 22.11): портовые сценарии гонять окнами с остановленным `wynd-caddy-1`; после — `docker compose up -d --force-recreate caddy` (простой `up`/`restart` после чужих портов оставляет контейнер без маппинга портов).
2. **Порты для контейнеров закрываются в `DOCKER-USER`**, правила `INPUT` на Docker-NAT не действуют (сертификат выделялся «сквозь» INPUT-DROP).
3. `Spec.TestCert` = **staging Let's Encrypt** + пропуск проверки TLS на «Проверке» — настоящий ACME-путь без боевых лимитов.
4. apt-пакеты (apache2/caddy/nginx) стартуют при установке и занимают 80/443 — порядок сценариев строить от «портов свободны»; детекция чужого прокси идёт по **занятым портам** (установленный, но не запущенный сервер осмотр не видит).
5. **wynd3**: рядом живёт чужой selfpost (порты 25/465) — не трогать; certbot-хуки `stop/start-wynd-caddy.sh` — история машины вне репозитория (post-hook стартует Caddy стенда на certbot-операциях).
6. **Prettier в `cmd/wynd-workshop/frontend` не запускать** (правило из памяти подтвердилось): переформатирует `.ts` целиком; правствовать вручную в стиле файла, иначе огромный diff — откатывать и переносить только содержательные правки.
7. Кнопка в пульте вне flex растягивается на всю ширину — ставить в `.ins-svcbar`, как сервисные кнопки; каскад проверять замером (`CSSStyleRule.cssRules` всегда существует — при обходе правил проверять `rule.style` до рекурсии).
8. «Бэкап на компьютер»: локальная папка `/srv/...` на Windows ложится в `D:\srv`; `MSYS_NO_PATHCONV=1` для проб с путями.
9. Кадры владельцу отдавать по **уникальным адресам** (при перезаписи файла браузер держит старый PNG).
