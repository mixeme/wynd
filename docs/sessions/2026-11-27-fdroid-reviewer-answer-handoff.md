## Грабли

- **Обсуждение MR анонимно недоступно:** состояние читается через API v4
  (`state: closed`), `notes`/`discussions` — 401; текст ответа фиксируется
  только со слов/скриншота владельца.
- **fdroidserver 2.4.5** — в `%LOCALAPPDATA%\Temp\fdv` (переживает сессии, но не
  гарантированно). `fdroid lint` требует `config/categories.yml` из fdroiddata и
  иконки категорий — годятся пустые файлы; без категорий ругается «Categories
  'Internet' is not valid».
- **`fdroid checkupdates`** запускается только внутри git-репозитория (делает
  `git status`), клон 169 МБ на Windows занимает ~3 минуты, вывод буферизуется —
  не считать зависанием. `file://` с кириллицей в пути лучше не использовать:
  песочницу делать на ASCII-пути.
- **Локальный lint 2.4.5 не знает правил master** (запрет `cd … &&`/`;` в
  скриптовых полях) — `pushd/popd` обязателен, проверять по мастеру вручную.
- **Чейнджлог живёт в теге:** добавить в main после тега бесполезно; нужен новый
  выпуск с файлом в коммите выпуска.
- **Параллельная сессия активна:** в дереве чужие правки
  `web/src/lib/journal/search-*` и другие; в коммиты этой сессии не входили.
