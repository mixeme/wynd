## Грабли

- **CI окон:** `web/embed.go` (`all:dist`) требует готового `web/dist` до
  tagged Go vet/test; `test-desktop.bat` теперь собирает его до Go. Теги
  окон можно переставлять до подписи — черновиков ещё нет.
- **Зависший runner:** Desktop client может встать на шаге Desktop gate;
  отмена не сразу, повторный push тега запускает свежий прогон.
- **Параллельные сессии:** коммитить только свои пути (`git add <paths>`),
  не забирать чужие незакоммиченные правки; перед коммитом сверять
  `git status`/`git diff --stat`.
- **gofmt и CRLF:** `gofmt -l` ругается на CRLF-файлы; не переформатировать
  чужие файлы целиком.
- **Выпуск:** после смены `VERSION` Image workflow собирает ghcr; деплой —
  бэкап БД, `docker pull`, смена `image:` в `compose.yaml`, `compose up -d`,
  проверка `GET /api/v1/instance` и `schema version`.
- **C119:** SHA нельзя считать одним крупным `crypto.subtle.digest` после
  загрузки; считать потоком по отправленным порциям.
