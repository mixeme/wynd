## Решения

- Принято: имя автора — часть текстового поиска, в том числе в общем поиске по всем кругам; результаты группируются по кругам и показывают автора, поэтому одноимённые люди в разных кругах различимы.
- Принято: фильтр-чип `author` остаётся только в поиске круга (концепция: «автор — только внутри круга»); текстовый поиск по имени это не ограничивает.
- Принято: подсветка — жирным, без ёлочек; у многословного запроса каждое слово; первое вхождение каждого слова (как раньше — первое найденное).
- Не менялось: имя автора и название дня в строке результата остаются полужирными (600) без отдельной подсветки внутри — они уже «жирные», это и есть выделение найденного.
