# Передача сессии 27.11: вшитый интерфейс Настольного по умолчанию

Сессия завершена по просьбе владельца «Завершай сессию»; работа велась по
слову «Переходим в Настольном приложении на вшитый интерфейс».

## Сделано

- **Вшитый интерфейс — основной** (`73a66e5e`): источник интерфейса вынесен
  в поле `source` файла `servers.json` (`embedded` по умолчанию, в том числе
  для старых файлов; `server` — явный откат). Выбранный сервер остаётся
  источником данных. Серверный режим включается в «Настройки → Приложение →
  Интерфейс» → «Сменить источник интерфейса» или ключом `--server-ui` (на один
  запуск, без записи настройки); прежний `--embedded-ui` принимается для
  совместимости.
- **Список источников** (`73a66e5e`): первой строкой «Встроенный / Интерфейс
  приложения / Сейчас открывает интерфейс»; сервер, с которого идут данные,
  подписан «Данные с этого сервера» и не имеет крестика; выбор сервера
  открывает его интерфейс, выбор «Встроенный» возвращает вшитый клиент с тем
  же сервером данных. Заголовок экрана — «Источник интерфейса».
- **Раздел «Интерфейс» в клиенте** (`73a66e5e`): мост `window.__wyndDesktop`
  получил признак `"embedded":true`; строка источника показывает «Встроенный»,
  строка смены называется «Сменить источник интерфейса»; на пустых «Серверах»
  подсказка «Интерфейс открывается из приложения».
- **Исправлен дефект моста после C143** (`73a66e5e`): в `web/src/app.html` есть
  проверка `if (window.__wyndDesktop)`, а вставка моста искала голое имя и
  считала мост уже вставленным. С появлением этой проверки и вшитый, и
  серверный интерфейс могли открыться без настоящего адреса сервера и
  локального порта API. Теперь ищется точный маркер `window.__wyndDesktop={`;
  тесты содержат HTML с упоминанием имени без моста. **В черновике Настольного
  0.5.6 этого исправления нет — подписывать и публиковать его нельзя.**
- **Живой прогон и настоящие кадры** (`3547c9fc`): локальный сервер 0.58.0,
  отдельный профиль, собранный exe; проверены вшитый клиент, вход, раздел
  «Интерфейс», смена на сервер и обратно, запись `source` в `servers.json`,
  `--server-ui` без перезаписи настройки, перезапуск. Кадры PrintWindow
  1060×780 — [протокол](../testing/desktop-embedded-default-2026-11-27.md) и
  [галерея](http://127.0.0.1:8903/).
- **Ворота:** `[desktop] OK` (`scripts\test-desktop.bat`, финальный прогон),
  `go test -tags desktop ./cmd/wynd-desktop ./internal/desktop` (включая новый
  `TestInterfaceSourceSwitch`), `npm run check` web и оболочки, `check:ui`,
  `lint`, `npm test` (741 тест). Полный `scripts\test.bat` не перезапускался:

- **Собран `dist\wynd-desktop.exe`** (27.11, 15:46) из чистого исходника, без

## Решения

- Принято владельцем 27.11: «Встроенный» — отдельная строка в существующем
  списке источников; выбор сервера временно открывает его интерфейс, выбор
  «Встроенный» возвращает вшитый. Выбранный сервер остаётся источником данных.
- Принято: откат доступен и в интерфейсе, и ключом `--server-ui`; ключ не
  переписывает настройку.
- Не переносить решение на Android без отдельного слова.

## Грабли

- **Мост и C143.** Не искать мост по голому `__wyndDesktop`: в `app.html` уже
  есть проверка имени. Точный маркер — `window.__wyndDesktop={`.
- **CDP и изолированный мир.** `Page.createIsolatedWorld` имеет свой `window`;
  `window.__wyndDesktop` там всегда `null`. Читать мост из главного мира:
  `iframe.contentWindow.__wyndDesktop` со страницы оболочки.
- **Windows curl и UTF-8.** `curl --data-binary @file` с кириллицей на этой
  машине искажает тело (сервер получал CP1251-моджибейк). Для проверок
  использовать Python `urllib`/`requests` с UTF-8 или ASCII-имена.
- **Single instance и WebView2.** Диагностический запуск рядом с настоящим
  окном требует другого `UniqueID`; после `Stop-Process -Force` профиль
  WebView2 может не подняться — удалить `webview` и запустить снова. Временная
  ветка CDP/изоляции была в `platform_windows.go` и `main.go`, после прогона
  убрана.
- **Порты.** 9333 был занят другим процессом; CDP слушал не наше окно.
  Свободный порт проверять `Get-NetTCPConnection`.
- **Параллельная сессия.** Она закоммитила наш подготовленный индекс вместе со
  своим C157 (`b24a352f`); коммит разделён без изменения содержимого: наш
  `73a66e5e`, её C157 — `a99cc300`. Старый хеш `b24a352f` больше не
  существует. Общие файлы `CHANGELOG` и реестра содержали её строки C154/C157 —
  они вошли в `3547c9fc` вместе с файлами.
- **Локальный сервер для живого прогона.** Первый запуск: токен bootstrap в
  логе; админ-пароль; инвайт через `POST /api/v1/admin/invites`; письмо-код —
  `dev-auth-codes.log`; сессия участника — в `/__secrets` локального порта окна
  (`PUT /__secrets/session`, origin — абсолютный адрес сервера). После проверки
  сессия удалена, временные каталоги `%TEMP%\wynd-embedded-profile` и
  `%TEMP%\wynd-embedded-live` удалены.
