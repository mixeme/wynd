Для C75 добавлен `openDownloadAfter` в `web/src/lib/navigation/openDownload.ts`: резервируется `about:blank`, сразу обнуляется `opener`, после ответа делается переход по одноразовой ссылке. При отказе окно закрывается, блокировка окна передаётся существующей обработке ошибок Wynd. Закрытое пользователем окно не открывается повторно. Архив не собирается в Blob в памяти страницы.

В `streamFullArchive` ключ можно передать функцией. Страница полного архива передаёт `key`, а не `await key()`: иначе пользовательская активация может потеряться ещё до открытия окна. Не возвращать ожидание ключа в обработчик перед вызовом скачивания.

Эти исправления **не проверены на телефоне после изменения**, поскольку на сервере прежний выпуск. C74 и C75 остаются открытыми до повторов. В тестах C74 моделируется история переходов, а не настоящий жест Safari.

**C73 — чтение архива Android.** На realme 8 распакован ZIP и открыт `index.html` в Vivaldi по `content://`: нет аватаров и фотографий, не играет медиа. Opera даёт тот же результат. Данные указывают на доступ к соседним ресурсам HTML через `content://`. Решение для автономного чтения Android **не выбрано и не реализовано**; отдельное воспроизведение аудио/видео из папки не проверяли. Не подменять обещание автономного архива предложением открыть его на сервере. Не встраивать весь большой архив в память страницы без отдельного разбора.

**Правка записи в очереди.** Владелец видел только корзину и не нашёл редактирование. В коде касание карточки открывает `compose?queue=<id>`, карандаша у записи нет. Этот путь на телефоне не проверяли. Наблюдение добавлено в C44; новый карандаш не добавлен и не утверждён.
