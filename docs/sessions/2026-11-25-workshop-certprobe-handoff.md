# Передача 25.11: Мастерская 0.4.8 — каталог и «Убрать сертификат»

Сессия — живой прогон открытых проверок Мастерской на wynd3 по слову
владельца «Бери». Код не менялся; найдены три дефекта, заведены C130–C132.

## Сделано

- **Опубликованы выпуски 25.11** (параллельная сессия): Настольный 0.5.0
  (Latest), 0.4.5, 0.4.4; Мастерская 0.4.8; Android 0.1.3 и 0.1.2.
- **Живой прогон окна 0.4.8 на wynd3** (82.114.228.93, Debian 13):
  - старый стенд 0.43.3 (`schema 11`) отодвинут, его Caddy остановлен,
    хуки certbot временно обезврежены;
  - установка в `/srv/wynd-certprobe` за nginx 1.26.3 через окно:
    план назвал пробный каталог, сертификат `wynd3.mixfed.ru` выдан,
    сайт 200, контейнер healthy;
  - удаление с сохранением данных: сайт убран, данные и сертификат
    оставлены, `certbot renew --dry-run` — 1 failure;
  - находка «Сертификат wynd3.mixfed.ru не продлевается — истечёт
    23.02.2027», кнопка «Убрать сертификат» удалила только этот
    сертификат; чужой `selfpost2` не задет;
  - уборка: проба удалена, nginx снят, хуки восстановлены, старый стенд
    возвращён, `wynd-wynd-1` healthy, сайт 200, selfpost healthy.
- **Найдены дефекты:** C130 (окно удаления называет `/opt/wynd` вместо
  фактического `/srv/wynd-certprobe` и не называет дату), C131 (сырой
  `RuntimeError` при смене каталога на сервере с известным корнем), C132
  (установка поверх базы `schema 11` падает «не отвечает», журнал требует
  сначала 0.53.4).
- **Документы:** протокол
  [workshop-certprobe-2026-11-25](../testing/workshop-certprobe-2026-11-25.md);
  обновлены план 46 (C130–C132), план 45, план пробы каталога, реестр §7,
  ROADMAP. Коммит `fcdc6703`, отправлен в Gitea.

## Открыто и дальше

1. **C130–C132** — решения и правки за владельцем; предложения в протоколе
   и плане 46. C130 возвращает окно к принятому кадру (каталог и дата),
   C131 — к человеческому объяснению, C132 — к предпроверке схемы.
2. **Остались в настоящем окне:** A25 (полоса обновления), C71/C90,
   «Загрузить начало» на большом журнале — после публикации 0.4.8.
3. **Остались отказы каталога:** чужая непустая папка, несовместимый
   Compose, старые профили со своим Caddy/чужим прокси, проход
   безопасности — план пробы.
4. **Linux-приложение Мастерской** — нужен рабочий стол; wynd2/wynd3
   headless. **AAAA** — нужен рабочий IPv6 и DNS; у wynd2 IPv6 без
   маршрута, у wynd3 нет. **Переезд за чужим прокси** — возможен парой
   wynd3 → wynd2 с освобождением приёмника; C70 (прокси на другой машине)
   — только с кодом.
5. **Старый хвост §6** — телефон снова не виден в `adb` (MTP без
   отладки); проход не начат. Как включите «Отладку по USB» — продолжу.

## Решения

- Новых решений по продукту нет. Владелец сказал «Бери» — прогон
  «Убрать сертификат» выполнен.
- Повторно не предлагать: C70 без кода, AAAA на этих двух VPS, Linux-
  Мастерскую без рабочего стола.

## Грабли

- **Старый стенд wynd3 — 0.43.3, `schema 11`.** 0.53.9 поверх него не
  мигрирует: нужен сначала 0.53.4. Стенд отодвинут в
  `/opt/wynd.stand-0433`, после пробы возвращён.
- **certbot-хуки wynd3** (`stop/start-wynd-caddy.sh`) поднимают Caddy на
  80/443; на время выдачи сертификата их права выполнения снимались,
  потом восстановлены.
- **nginx** на wynd3 до пробы не было; поставлен вручную, после пробы
  `apt purge`. Сайт `wynd-wynd3.mixfed.ru.conf` создаёт установщик.
- **Снимков окна удаления нет** — тексты C130 сняты деревом доступности;
  это проверка слов, не вёрстки.
- Параллельная сессия держит незакоммиченные правки
  `cmd/wynd-signer/frontend/src/App.svelte` и
  `web/src/lib/components/workshop/*` — не трогать; наш коммит pathspec.
