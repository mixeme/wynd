  перетегировать.

  разворачивается после готового образа.

## Грабли

- `image.yaml` срабатывает на push `main` с изменением `VERSION`, а не на тег:
  образ 0.55.0 — прогон `45841901826` ветки `main`.
- Тег Настольного запускает два прогона `desktop-client` сразу; оба зелёные,
  черновик один — это нормально, не гоняться за «дублем».
- В `compose.yaml` заменять только строку `image: ghcr.io/mixeme/wynd:<версия>`;
  замена по «wynd:» задевает имена сервиса и сети (грабля 0.54.1).
- Бэкап базы — вместе с `-wal` и `-shm`; без них копия неполная.
- Ворота шли ~20 минут; журнал `dev/gates-0550.log` в git не входит.
- В дереве untracked `.zcode/` — не наш, не коммитить.
