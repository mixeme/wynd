## Решения

- Принято: вход своего сервера в окне хранится абсолютным адресом, клиенту
  отдаётся пустым (как C127); `/__secrets` не менять.
- Принято: C143, C145, C146 живыми проверками не переоткрывать.
- Отклонено: чинить сжатый рейл — план 76 его убирает; C142 («поля» как рамки
  полей ввода) не восстанавливать.

## Грабли

- Сеанс Windows отключён (`query user` — «Диск»): физический ввод, drag и
  прокрутка CUA недоступны; Enter проверен CDP `Input.dispatchKeyEvent`,
  папка — нативным диалогом через UI Automation. Это не равно нажатию рукой.
- CDP к WebView2: временная env-ветка `WYND_DESKTOP_CDP_PORT` в
  `platformWindowsOptions`; без неё не подключиться. Показ меню трея —
  временная `WYND_TRAY_MENU_PREVIEW`; обе убраны, в коммит не входят.
- «Подпись» с изолированным `APPDATA` не видит `gh auth` — запускать с
  обычным профилем, иначе «gh auth login».
- Экран 1024 × 768: окно 1060 не шире 1044, окно Мастерской 1094 — 1044;
  высота 670 задаётся точно. Для C146 важна высота, линия y = 600.
- Порт 7680 занят `svchost`; стенд — 7684. Параллельная сессия правила план 76
  и реестр: перед правкой документов перечитывать, коммитить только свои пути.
- Тестовая учётная запись `Wynd.Desktop/http://127.0.0.1:7684` удалена;
  запись схемы `wynd:` и `IconUri` возвращены к значениям до прогона.
