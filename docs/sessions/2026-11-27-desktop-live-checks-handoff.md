## Решения

- Новых решений по продукту не принималось. Проверки подтвердили выпускной
  0.5.7; вёрстка вшитого интерфейса по-прежнему предложена, а не утверждена.
- Отказ проверки подписи при обновлении не воспроизводился (нет выпуска с
  неверной подписью) — записано в протоколе, не выдавать за проверенное.

## Грабли

- **RDP-сеанс без переднего окна** (`GetForegroundWindow = 0`): физические
  клавиши, Enter и мышь не доходили. Поля — `ValuePattern.SetValue`, кнопки —
  `InvokePattern`, мышь — posted-сообщения в `Chrome_RenderWidgetHostHWND`;
  так и названо в протоколе. `SetForegroundWindow` и `SendInput` бесполезны.
- **Голый `127.0.0.1:7691`** клиент дополняет до `https://` и показывает
  «Сервер не отвечает»; для локального стенда нужен явный `http://`.
- **Сессия окна живёт в Credential Manager** (`Wynd.Desktop/<origin>`), а не в
  `APPDATA`: чистый профиль всё равно входил. Перед «чистым входом» удалять
  `cmdkey.exe /delete:Wynd.Desktop/http://127.0.0.1:7691`.
- **Локальный стенд отвечает быстрее кадра.** Для значка загрузки — временный
  прокси `7691 → 7693` с паузой 2 с на GET данных круга
  (`dev/ld2711_delay_proxy.py`, gitignored), иначе `?loading` в окне не поймать.
- **Самообновление скачивается < 1 с.** Кадры 40 %/100 % сняты серией по
  0.015 с, запущенной до нажатия кнопки; иначе окно уже закрыто.
- **Параллельная сессия и индекс git (повтор грабли 27.11).** При коммите
  документов в индекс попали подготовленные другой сессией файлы Android/Share.
  Коммит сразу снят `reset --soft`, чужие пути сняты с индекса, свой коммит
  `7651e75b` содержит только документы; чужая работа осталась на диске и была
  закоммичена соседней сессией (`b54ef3cd`) поверх. **Всегда проверять
  `git show --stat` сразу после коммита.**
- **`git status` и staging:** чужие файлы могут быть уже в индексе; `git commit`
  без путей забирает весь индекс. Для общих файлов (реестр, план 46) свои хунки
  ставились фильтрованным патчем `git apply --cached --unidiff-zero`.
