## Грабли для следующей сессии

- `adb shell input text` не умеет кириллицу. Пароль архива с кириллицей перешифрован тем же кодом под ASCII: `dev/c92/reencrypt.go` (`archive.Decrypt`/`archive.Encrypt`), файл `A12.wynd`.
- Телефон засыпает через 2 минуты (`screen_off_timeout=120000`, ADB не может изменить) — каждый батч начинать с `keyevent 224` + свайп.
- Замена адреса в Firefox: тап по строке, 90 × `keyevent 67`, `input text`, `keyevent 66`; «выделить всё» ненадёжно.
- Выбор файла в DocumentsUI: одиночные тапы по строкам не срабатывают — DPAD (`keyevent 20`) и Enter.
- Инструменты к концу сессии отвечали с задержкой больше часа на вызов — UI-проход приостановлен, не считать пункты «непроверенными навсегда».
- Стенд погашен, `adb reverse` снят, `svc power stayon` выключен. Данные стенда сохранены в `dev/c92` (оживлённая «Семья» у Carol, «Дача» у anya).
- Параллельная сессия правит `docs/plans/45-workshop.plan.md` и Android-файлы — в свои коммиты не включать.
