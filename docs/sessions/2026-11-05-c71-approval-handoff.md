## Решения владельца

- Выделен **текущий шаг Docker**: строка вывода моноширинная, `strong.w`; название этапа «Собираем образ Wynd» обычное. Выделение названия этапа вместо Docker было отклонено.
- Принятое пояснение C71.2: **«Последняя строка вывода — 2 минуты назад»**. Формулировка «Новых сообщений нет… Связь с сервером есть» отклонена. «Последний ответ» не использован, чтобы не смешивать вывод Docker с проверкой связи.
- C71.3 сохраняет ошибку Docker и полный журнал, объясняет нехватку места и то, что работающий Wynd не меняли. Действие — возврат к плану обновления после освобождения места; перед повтором проверяется состояние сборки.
- Основная компоновка сохранена. Никаких ручных перерисовок или принятых офлайн-эскизов нет.

## Настоящий рендер

Работает штатный HTTP-предпросмотр: `node docs/visual/serve-workshop-review.mjs <свободный-порт>`. Сервер слушает только `127.0.0.1`, отдаёт известные кадры без доступа к каталогам: `/` — C71.1, `/quiet` — C71.2, `/error` — C71.3, `/baseline` — исходный 7в. Файлы владельцу вручную открывать не потребовалось.

Снимки получены во встроенном браузере при viewport 1024×760, devicePixelRatio 1, светлой теме, масштабе 100%. После снимков временный viewport сбрасывался. При таймаутах помогали штатное переподключение к тому же браузеру и отдельные последовательные вызовы получения вкладки, перехода, установки viewport и снимка. Не делать из таймаута вывод, что HTTP запрещён. Прямой `file://` был отклонён; его ограничения не обходить. Prince и WeasyPrint исказили контролы и **не годятся для этой приёмки**.

Подробные протоколы: [первый кадр](../testing/c71-render-2026-11-05.md), [C71.2](../testing/c71-quiet-review-2026-11-05.md), [C71.3](../testing/c71-error-review-2026-11-05.md). Там сохранены история отклонений, ответы владельца и привязка снимков к SHA исходника.
