## Открыто и дальше

1. **Подписи и судьба черновиков.** 0.5.0 перекрывает 0.4.4/0.4.5 (сборка
   позже, включает их изменения). Решить: подписывать 0.5.0 и удалить старые
   черновики или сначала публиковать 0.4.5.
2. **Описание выпуска 0.5.0 — заглушка** («что нового — дописать до
   публикации»). В `whatsnew.md` раздел 0.5.0 говорит только о Linux и строке
   автозапуска, без пунктов 0.4.4/0.4.5 (копии по расписанию, меню трея).
   Дописать до подписи, иначе пользователь 0.4.3 не увидит этих изменений.
3. **Серверный хвост C128.** Правка `5f9116e5` в main после тега `v0.53.8`, на
   VPS не развёрнута. Нужен следующий серверный выпуск; наблюдение повторить
   по журналу.
4. **Дефекты без решения:** C126 (выход с одного сервера гасит уведомления
   всех — исправления в коде нет), C127 (смена сервера интерфейса теряет
   многосерверный вид — нужно решение владельца), C91 (нужен конкретный
   переход окна Мастерской), C102 (голос с часами на realme 8).
5. **Решение владельца по уведомлениям:** встроенный канал или форк
   доставщика (план 50), опциональный push-сервер в Мастерской (план 45);
   без слова владельца не начинать.
6. **Проверки:** реестр — OPPO (C119, C125, «Отклики» 0.53.8, C99/C100, C98
   при 1,35, C120), realme 8 (C57, C102, QR/GPS/автозаполнение, фоновая
   доставка), iPhone (§4), Linux (§12, после публикации 0.5.0), Настольный
   (§7: трей живой рукой, перетаскивание, Ctrl+Alt+W, C121, самообновление
   после 26.11), Мастерская (после 0.4.8: сертификат, журнал сборки, A25,
   C71/C90, каталог).
7. **Документы:** README и `docs/OPERATOR.md` ждут прочтения владельцем;
   живой проход OPERATOR на чистом VPS не делался.
8. **Перед первым публичным выпуском:** повторный проход безопасности по
   изменениям с прошлого аудита и закрытие плана 43.
