## Решения

- Закрытие §6 по свидетельствам — по слову владельца 28.11. Ветки, не
  упомянутые в протоколах, оставлены закрытыми: это формулировки старых
  выпусков, те же пути 0.53.x–0.58.x проходили живьём; при дефекте —
  «C» в плане 46.
- A4 слит с §27/§31, отдельный пункт не заведён.
- C119 закрыт без ветки ПК/Firefox: исходная среда дефекта (OPPO)
  пройдена на выпущенном исправлении.

## Грабли

- Системный выбор файла на OPPO не реагирует на тапы по строкам — файл
  выбирается клавишами: DPAD «вниз» до строки, Enter (совпадает с записью
  прогона 5.4 от 24.11).
- `DOM.setFileInputFiles` по CDP не пробивает file input обёртки
  (оболочка перехватывает выбор) — вложение шло через настоящий пикер.
- `adb input text` режет пробелы (IME) и смешивает раскладки — длинные и
  кириллические строки вводить через CDP (`Runtime.evaluate` + событие
  `input`).
- Лимит кодов входа wynd2: окно 30 мин; два запроса за вечер прошли без
  блокировки.
