## Грабли

- **CRLF из буфера Windows** ломает `rewritemeta`: вставка в GitLab сохраняет CRLF. Правильно — загружать файл («+» → Upload file) из `dev/fdroid-upload/`, там LF-копии (`mixeme.wynd.yml`, `summary.txt`).
- **GitLab `/-/new/<ref>/<path>`**: путь — это папка, поле Filename — только имя. Дважды создали вложенные пути (`.../mixeme.wynd.yml/mixeme.wynd.yml`, `.../summary.txt/summary.txt`).
- **API комментариев MR требует логина** (`notes`, `discussions` — 401 анонимно); лог job читается без логина: `https://gitlab.com/mixeme/fdroiddata/-/jobs/<id>/raw`.
- **lint fdroidserver master** запрещает `cd … &&`/`;` в скриптовых полях (`CD_CHAIN_REGEX`) — в выпуске 2.4.5 этого правила ещё нет.
- **В сборочной ВМ F-Droid нет npm** — ставить через `sudo` (Debian-пакет тянет nodejs 18+; Vite 6 требует ≥18).
- **Порядок полей в метаданных важен**: `sudo` канонически до `gradle`.
- **Gitea push иногда отказывает по auth** — повторить; прошло со второго раза.
- **Параллельные сессии**: HEAD ушёл на `55b2664d` (правка «Сетка и Дни»), мои коммиты перемешаны с чужими; коммитил только свои пути.
