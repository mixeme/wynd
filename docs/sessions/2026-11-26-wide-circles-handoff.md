## Решения

- Принято: две колонки от 720 px; 720–1059 px — рейл 80 px (только аватары, имя в подсказке), от 1060 px — полный список 340 px и круг 720 px; общая ширина 800/1060 px по центру.
- Принято: открытый круг отмечен подложкой и полоской цвета; без выбора справа «Выберите круг», первый круг сам не открывается; стрелка «Назад» в шапке круга остаётся; `/circles/new` и `/circles/{id}/join` одноколоночные.
- Принято: в рейле баннеры, заголовки разделов и группы скрыты; пустая улочка расширяется до 340 px; меню плюса и карточка долгого нажатия временно расширяют рейл; красные число и точка непрочитанного, центры совмещены на верхнем углу аватара, шаг 10 px.
- Принято: поиск — одна лупа в шапке правой панели (шапке круга), поле открывается там же, «Все круги» внутри; слева лупы нет; в пустой правой части поиска нет.
- Отклонено, не предлагать снова: сжатый вид строками с именем и временем (260 px); кнопка «Поиск по кругам» в пустой правой части; возврат лупы в левую шапку; поиск по кругам отдельной кнопкой/полем в пустой части. Причина: в рейле нет места полю, а кнопка ломает бесшовный переход к поиску.
- Отклонено: отлёжка обновлений здесь не менялась; не путать с C144/планом 74.

## Грабли

- **Параллельная сессия.** В дереве одновременно шли C144 и правки баннеров плана 74; `StreetLayout`, `+layout`, реестр и журнал правились с двух сторон. Коммитить только свои пути (`git commit -- <paths>`), перед правкой документов перечитывать файл. Не трогать worktree `D:/Local/Git/wynd-play` — он чужой.
- **Сборка стенда.** Клиент `web/dist` вшит в `dev/wynd-stand-75l.exe`. После правок `web` — `npm run build`, затем `go build -o dev/wynd-stand-75l.exe ./cmd/wynd` (или новое имя). Стенд: `WYND_DATA_DIR=dev/frame75-data WYND_LISTEN=127.0.0.1:7678 ./dev/wynd-stand-75l.exe`. Данные — копия `dev/data`; вход `anya@example.com`, коды в `dev/frame75-data/dev-auth-codes.log`.
- **Лимит кодов.** 5 запросов кода на почту за окно; при повторных съёмках чистить `code_request_log` в копии БД. Для точки откликов — `dev/seed75-dot.py` (добавляет запись Ани и отклик Боба в «Семью», отмечает прочитанным).
- **Съёмка.** `dev/capture75.mjs` (после, стенд 7678), `dev/capture75-before.mjs` (до, старый клиент через vite 5181 из worktree — worktree удалён, при необходимости создать заново), `dev/probe75.mjs` (замеры). Headless Edge, CDP, DPR 1; галерея — `dev/frames-gallery`, сервер `python -m http.server 8899` из этой папки (оставлен запущенным для владельца). Системная подсказка `title` в снимок не попадает — проверять DOM.
- **Полоса прокрутки.** Причина была не в числе кругов: margin-collapse верхнего баннера сдвигал обёртку на 8 px; Edge рисует полосу и без переполнения. Лечение — `display: flow-root` + `class:fit`; не убирать.
- **Пороги.** 720 и 1060 продублированы в `$lib/session/layout.svelte.ts` и CSS `.ph.app.split`/`.rail`; менять только вместе. В полном списке значок непрочитанного остаётся цветом круга — красный только в рейле.
- **Рейл.** `:has` используется для меню/карточки и пустой улочки; групповые карточки скрыты. Кнопка поиска в пустой части удалена — не возвращать.
