# Передача сессии 28.11. Действие удаления в настройках Wynd Push

Владелец спросил, где будет кнопка удаления. Это продолжение [показа компактного меню](2026-11-28-wynd-push-cache-width-handoff.md).

## Сделано

- `67a92fcd` — «Удалить сервер уведомлений» предложено справа в нижнем ряду панели «Настроить». На стенде действие открывает отдельное подтверждение в той же панели. [Кадры, патч и протокол](../visual/reviews/wynd-push-cache-2026-11-28/README.md#удаление-push-сервера).
- Проверены три размера, выравнивание справа, отмена и переход к пульту после удаления на тестовых данных. В сравнении закрытых кадров 1024 × 760 изменились только пиксели нового действия. Прошли `npm run check:ui` и проверка применимости патча.
- Выпусков, тегов, развёртываний и действий на сервере не было.

## Открыто и дальше

1. Получить решение по [актуальному кадру панели](../visual/reviews/wynd-push-cache-2026-11-28/cache-settings-remove.png) и расположению удаления. Утверждённые кадры шага установки и пульта сохраняются.
2. Продолжить по [плану 76](../plans/76-wynd-push.plan.md#порядок-работ) с `WYND_PUSH_SERVER` и `GET /api/v1/instance` после согласования. Проверка удаления на пробном Docker входит в работу Мастерской.

## Решения

- Удаление относится к серверу уведомлений. В предложенном подтверждении названы настройки Push и ожидающие доставки сообщения.
- Действия «Сохранить» и «Отмена» расположены слева, удаление справа. Ширина поля хранения 144 px, вариант во всю ширину ранее отклонён.

## Грабли

- При 680 × 501 нижний ряд виден после прокрутки. Работа проверена в Chromium с тестовыми данными, Wails и Docker предстоит проверить после реализации.
- Патч настроек применяется после патча принятого пульта. Порядок указан в протоколе.
