# Передача сессии 25.11: запуск Android на Android 11 (C133)

## Сделано

- **Дефект C133 найден и исправлен** (`a6192845`): на Android 11 приложение
  закрывалось сразу после запуска, без сообщения. Причина — `SystemBarsFrame`
  строит рамку полос до `setContentView` и в конструкторе вызывает
  `Window.getInsetsController()`; на API 30 `PhoneWindow.getInsetsController()`
  разыменовывает ещё не созданный decor → `NullPointerException`; `MainActivity`
  ловит и молча вызывает `finish()`. На 12+ вызов создаёт decor сам, на <30
  другая ветка — поэтому не воспроизводилось на OPPO (Android 10) и телефонах
  Android 13. Не регрессия 0.1.3: путь общий, Android 11 не проверяли.
  Правка: контроллер берётся у `window.getDecorView()`, оформление повторяется
  в `onAttachedToWindow`.
- **Проверено на планшете** Samsung Galaxy Tab S5e (SM-T725), Android 11,
  отладочной сборкой из этого дерева: первый запуск (стартовый экран) и путь
  интерфейса с выбранным сервером (стенд 7676 через `adb reverse`) — процесс
  жив, страницы отрисованы, ошибок в журнале нет. OPPO (Android 10) — без
  изменений. [Протокол](../testing/android-11-launch-2026-11-25.md).
- **Документы** (`4a469a0c`): план 46 — C133; реестр — пункт C133 (живая
  проверка подписанного 0.1.5); протокол проверки.
- **Выпуск Android 0.1.5** (`21db0743`, тег `android-v0.1.5`): версия,
  «Что нового», запись CHANGELOG. Ворота: `testStandardDebugUnitTest
  testFdroidDebugUnitTest lintStandardRelease lintFdroidRelease
  assembleStandardRelease assembleFdroidRelease` — зелёные, локальный
  release-APK: `versionCode=1005`, `versionName=0.1.5`.
- **CI по тегу** (GitHub-зеркало, прогон `45696866686`) — success. Черновик
  `android-v0.1.5`: `wynd-android-unsigned.apk` 6 101 133 байта, SHA-256
  `1ae9cd18bd78fcdff2a5371cc137d0327d2e2a835599f542cb6bf54d27a1a4d1`
  (сходится с asset `.sha256`), `aapt`: `mixeme.wynd`, 0.1.5/1005; запись
  удостоверения сборки есть (1 шт.).
- **Приёмка:** код и поведение проверены на планшете; подписанный APK 0.1.5

## Решения

- Принято: правка точечная (одна строка + комментарий), без переделки рамки;
  перенос оформления на `onAttachedToWindow` уже был в коде и достаточен.
- Принято: `CHANGELOG` — запись Android 0.1.5 под верхним `[Unreleased]`
  (второй, устаревший `[Unreleased]` ниже по файлу не трогали; см. «Грабли»).
- Отклонено: автотест класса на JVM — в проекте нет Robolectric, а
  `SystemBarsFrame` — Android-представление; охранник — живая проверка
  Android 11 и комментарий в коде.

## Грабли

- **`CHANGELOG.md` содержит два `## [Unreleased]`**: верхний (строка 9) и
  устаревший ниже 0.53.6, где лежат записи Android 0.1.2–0.1.4 и продуктовых
  выпусков. Новые записи добавлять в верхний; дубль стоит разобрать отдельно.
- Android 11 — единственная ветка, где `Window.getInsetsController()` падал до
  создания decor; любые обращения к окну до `setContentView` проверять на API
  30 (эмулятора нет, есть планшет SM-T725 по USB).
- Git Bash: пути вида `/data/local/tmp/...` в `adb` требуют
  `MSYS_NO_PATHCONV=1`; `adb devices` — `D:/android-env/sdk/platform-tools/adb.exe`.
- Планшет уходит в сон с закрытой обложкой — `screencap` чёрный, `am start -W`
  висит; для проверки страниц использовать CDP (`webview_devtools_remote_<pid>`)
  и `run-as` для подкладки каталога интерфейса.
- Сборка: `JAVA_HOME=D:/android-env/jdk/jdk-17.0.21.0.3`,
  `ANDROID_HOME=D:/android-env/sdk`,
  `GRADLE_USER_HOME=D:/android-env/gradle-user-home`,
  `WYND_ANDROID_ENV=D:/android-env`.
