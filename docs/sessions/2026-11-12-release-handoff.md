## Правила и грабли

- **Коммиты и теги — только в Gitea (`git push origin`).** Прямой push в GitHub запрещён: зеркало перетирает. При `Failed to authenticate user` просто повторить команду; повтор проходил.
- **Зеркалирование может вернуть серверный выпуск GitHub в черновик** после синхронизации. После отправки в Gitea проверить `draft=false` и страницу выпуска; при необходимости опубликовать снова (`gh api -X PATCH repos/mixeme/wynd/releases/<id> -F draft=false`).
- Полные ворота: `scripts\test.bat`; desktop отдельно — `scripts\test-desktop.bat`. Если в `cmd/wynd-desktop/frontend/node_modules/.bin` нет `svelte-check`, остановить старые Vite/esbuild и выполнить `npm ci` в desktop frontend.
- `scripts\build-desktop.bat` требует закрытого `dist\wynd-desktop.exe`; иначе собрать и сохранить под другим именем.
- Перед тегом синхронизировать часы (`w32tm /resync`): расхождение ломает удостоверение/подпись.
- Номер сервера поднимается в шести файлах: `VERSION`, `internal/version/version.go`, `web/package.json`, `web/package-lock.json` (два места), оба `internal/api/openapi-*.yaml`. Номер Настольного — `internal/desktop/version.go`, `cmd/wynd-desktop/wails.json`, раздел в `cmd/wynd-desktop/whatsnew.md`.
