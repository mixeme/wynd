## Решения

- **Выпуск 0.58.3 — патч**, хотя в CHANGELOG есть «Изменено» (форма метки):
  миграций и новых API нет; Настольный — 0.5.8.
- **Форма метки включена в выпуск.** Параллельная сессия закоммитила квадрат в
  белой рамке (`2594c040`) с пометкой «ждёт приёмки», но это слово владельца
  28.11 и правка уже в `main`; откатывать без прямого слова не стали. Точные
  пиксели формально ждут приёмки; правка — одно правило в `map.css`. Вопрос
  владельцу задавался, ответа не было.
- **Android и Мастерская не перевыпускаются:** правок в их коде нет; C160/C161
  приходят в APK с серверным интерфейсом.
- Отклонённого в этой сессии нет.

## Грабли

- **Параллельная сессия:** HEAD сместился с `59eb51c3` на `d31eefc5` во время
  ворот, `map.css` изменился в 08:19 — в разгар прогона. Выпуск закоммичен
  только своими путями; форма метки попала в дерево ворот и в web-сборку, но
  `check:ui` на ней отдельно прогнан сессией C161.
- **Два прогона Desktop client на один тег** — зеркало отправило тег дважды;
  оба success, черновик один. Проверять суммы после завершения обоих.
- `wynd-desktop.exe.sha256` — голая сумма без имени файла, `sha256sum -c`
  ругается; сравнивать вручную или через `SHA256SUMS`.
- `go test ./...` локально захватывает untracked-пакеты `dev/*` — без тестов,
  не мешает.
- VPS: каталог `/opt/wynd`, бэкапы в `backups/`, контейнер `wynd-wynd-1`;
  на wynd2 рядом `wynd-caddy-1`.
- Галерея кадров формы метки на `127.0.0.1:8902` оставлена параллельной сессией
  запущенной для владельца.
