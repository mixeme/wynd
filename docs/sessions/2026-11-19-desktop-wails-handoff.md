### C66 — работа и дозагрузка при скрытом окне (`8bade3d2`)

Три реальных дефекта:
1. Прокси отвечал `502` при недоступном сервере, и клиент считал это ответом API — очередь не включалась. Теперь соединение рвётся (`internal/desktop/proxy.go`, `TestProxyAbortsWhenServerUnreachable`).
2. CORS локального порта не разрешал и не открывал `Upload-Offset` — браузер блокировал `PUT` загрузки. Добавлено в allow/expose (`TestCORSOnlyForWindowOrigins`).
3. Очередь повторяла только по внешнему событию — теперь планирует повтор сама, включая прерванные отправки (`nextRetryDelay`, 12 тестов queue).

Таймеры скрытого WebView2 не троттлятся (три browser flags). Живьём: скрытое окно переподключилось за 11 с; фото из очереди загрузилось (`post_media` 2→3); запись отправлена при спрятанном окне (`posts` 35→36, очередь пуста). Протокол — [desktop-background-upload-2026-11-19.md](../testing/desktop-background-upload-2026-11-19.md).
