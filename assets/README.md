# Файлы марки

Правила: знак — в [docs/visual/mark.html](../docs/visual/mark.html), логотип — в
[docs/visual/logo.html](../docs/visual/logo.html). Здесь только файлы.

Эталон — [`icon.svg`](icon.svg). Все растровые размеры, `.ico`, `.icns` и maskable-варианты
выводятся из него; править растр руками нельзя, правится эталон.

| Файл | Что это | Где применять |
| --- | --- | --- |
| `icon.svg` | эталон, 1024×1024, чернила на бумаге | всё от 48 px и выше: сторы, PWA-манифест, рабочий стол |
| `icon-small.svg` | то же поле, перо утолщено | 16, 24, 32 px: favicon, трей, вкладка |
| `mark.svg` | знак без подложки, `currentColor` | интерфейс: шапка, твой отрезок, начало журнала, обновление, пустой круг |
| `logo.svg` | лок: знак плюс слово в кривых | лендинг, сторы, письма, презентации; от 48 px по высоте знака |

## Логотип

`logo.svg` — знак и слово «Wynd», переведённое в кривые: шрифта в файле нет.
Чернильные высоты знака и слова равны, чернильные центры совмещены, зазор между
чернилами 0.35 высоты. Габарит 2.91 : 1, поля в файле нет — оно задаётся при
вёрстке и не меньше того же зазора. Ниже 48 px по высоте знака лок не набирается:
там ставится `mark.svg` без слова. Построение и разбор — в
[docs/visual/logo.html](../docs/visual/logo.html).

## Геометрия

Знак взят из `docs/wynd.html` (шапка, единственный `<svg>`) один в один: масштаб 12.29786,
сдвиг (514.71, 506.61). Контур — не обводка, а залитая форма пера, поэтому он не зависит
от того, как рендерер трактует `stroke-width`.

- Холст 1024, знак 491 × 756 — портретный прямоугольник иконочной сетки Apple.
- Оптический центр знака совмещён с центром холста; сам контур несимметричен, перо
  утолщается книзу.
- Знак укладывается в круг диаметром 756 при safe zone 819 — maskable-иконка Android
  ничего не срежет.
- Подложка сплошная и во всё поле: iOS не допускает прозрачности, углы платформы
  скругляют сами. Своё скругление в эталон не зашивать.

## Цвет

Бумага `#F4F0E9`, чернила `#2B2724` — те же переменные, что в интерфейсе. Знак не
перекрашивается под площадку и не выворачивается на тёмном: бумага — часть марки.
Цветным знак бывает только внутри продукта, через `mark.svg` и цвет круга.

`mark.svg` берёт цвет из `currentColor`, а это работает, только если файл вставлен
в разметку инлайном или через `<use>`. В `<img>` и в favicon наследования нет — там
знак выйдет чёрным, для этих мест берётся `icon.svg` или `icon-small.svg`.

## Мелкие размеры

Перо эталона режется от 0.62 к 2.38 единицы исходника — на 16 px тонкий конец линии
исчезает совсем. В `icon-small.svg` тот же ход оси и то же поле, но перо поднято до
5.0–7.0: на 16 px это примерно 1.0–1.4 px, линия доживает до растра. Наклон пера при этом
почти теряется — это осознанный размен, поэтому файл не годится крупнее 32 px.

## Экспорт

```bash
rsvg-convert -w 512 -h 512 assets/icon.svg -o icon-512.png
```

```bash
rsvg-convert -w 32 -h 32 assets/icon-small.svg -o favicon-32.png
```

Inkscape: `inkscape assets/icon.svg -w 512 -o icon-512.png`. Без CLI под рукой — любой
конвертер, файлы самодостаточны: ни шрифтов, ни внешних ссылок, ни фильтров.
